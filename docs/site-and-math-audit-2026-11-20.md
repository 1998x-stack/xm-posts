# 全站信息架构与数学排版审计（2026-11-20）

## 审计边界

- 以 `content/categories.json`、`content/posts.json` 为唯一数据源；检查所有标为 `published` 的文章源 HTML，同时检查 `scripts/build_site.py` 生成的首页、分类、归档、文章索引、RSS、Sitemap 和 SEO 元数据。
- 不把 Skill 的五份相同模板当作五篇独立文章；模板已经支持 MathML，并由镜像一致性检查覆盖。
- 线上首页已独立确认存在分类、归档与文章卡片；站点视觉与公式几何检查仍以 CI 对真实构建产物运行 Chromium、离线检查及截图 JSON 为准。未完成的真实浏览器检查不得宣称通过。

## 发现与改进

1. **数学排版不一致**：初始审计时 18 篇中 SVM 已使用 MathML，其余 17 篇主要用 Unicode 字符、HTML `<sub>`/`<sup>` 和 CSS 假公式展示，容易出现求和上下界、分式、根号与手机端溢出问题。逐篇迁移 17 篇旧文的核心公式容器，保留 SVG、代码、原论文引用和交互脚本。此后主分支新增的 AlexNet 已自带 MathML，保留其数学结构。RoPE 的二维旋转矩阵另用真正的 `mtable` 行列结构。
2. **学习路径不足**：现有分类对检索有用，但缺少跨分类的循序阅读入口。首页新增从表征到架构、训练优化、推理系统、对齐优化四条路径；仅引用 manifest 中实际已发布的文章。
3. **原始论文入口不够直接**：文章卡片只有解读页入口。新增“原论文”链接，直接使用 manifest 中已经登记的 `paper` URL，不伪造外部资料。
4. **README 信息遗漏**：新增 PagedAttention 的已发布文章列表项，并补齐 Reasoning 分类说明。
5. **文章元数据不统一**：部分作者页缺失 canonical / Open Graph / Twitter card。构建时仅为缺失项补充来源于 manifest 的信息，避免二次编辑原作者页和重复标记。
6. **时间索引的语义**：较多文章同日发表，排序可能由 slug 决定而非真实时间顺序。首页标题由“最新解读”调整为“全部论文解读”；归档保留真实元数据日期，不推测精确发布时间。

## 质量门禁

- 静态测试覆盖每一篇已发布文章的 MathML、公式块、SVG 不嵌套 MathML、无障碍描述、分式子节点数量与滚动区域语义。
- 使用真实 Chromium 分别验证 1440 / 768 / 390 / 360 像素宽度下的 MathML 命名空间、非零几何尺寸、分式上下布局、页面不溢出、无远程依赖和交互。
- 构建测试检查首页四条阅读路径、各卡片的原论文链接、全部生成文章的 canonical / Open Graph 和 README 注册完整性。
- 若编排器发现与原论文公式的数学意义不符，应对具体公式人工修订，而不是通过宽松化校验掩盖问题；迁移不应被误称为原论文复现。

## 进一步编辑方向

保留 Multimodal、Evaluation 两个尚无已发布文章的分类作为规划中主题。未来可添加明确的概念依赖图、对比文章系列（如 Pre-LN / RoPE / FlashAttention）、PDF 的 Evidence ID 级细化链接；这些属于内容建设，不应通过空文章或虚构实验填充。

学习路径增补至 7 条，覆盖经典学习、视觉/序列、优化与微调、数据语料、对齐、Serving、强化学习；这些是跨分类阅读建议，不是新一级分类。数学静态门禁对全部已发布文章生效，但数学语义仍需要原论文逐式比对，不能由结构性检查替代。
