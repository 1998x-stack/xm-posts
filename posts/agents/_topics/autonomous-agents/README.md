# Autonomous Agent Systems & Frameworks

> **规划占位 / Planned topic** — 不是文章，也不代表已发表或已完成研究。

- **一级分类**：`agents`（以 `content/categories.json` 为准）
- **研究范围**：以开放式目标为输入，组合 LLM 决策、任务分解、工具调用、环境观察、状态与记忆、执行预算、权限门禁、恢复和终止机制的完整 Agent 系统。
- **代表性案例**：AutoGPT Classic、AutoGPT Platform、BabyAGI，以及后续具备类似系统边界的自主 Agent 框架。
- **与相邻主题的边界**：
  - `react` 解释 Thought / Action / Observation 交互范式。
  - `planning` 研究任务分解、计划选择与重规划算法。
  - `tool-calling` 研究工具 schema、参数生成和调用接口。
  - `memory` 研究状态、历史和跨会话记忆机制。
  - 本主题研究如何把这些模块组合成可执行、可观察、可恢复和可治理的系统。
