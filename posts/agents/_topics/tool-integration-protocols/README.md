# Tool Integration & Interoperability Protocols

> **规划占位 / Planned topic** — 不是文章，也不代表所有候选协议已经完成研究。

- **一级分类**：`agents`（以 `content/categories.json` 为准）
- **研究范围**：Host / Client / Server 架构、工具与资源发现、跨应用互操作、协议版本、传输、身份认证、授权与安全边界。
- **核心专题**：Model Context Protocol（MCP）；后续可研究 A2A 等 Agent-to-Agent 互操作协议。
- **与 Tool Calling 的边界**：Tool Calling 研究模型如何选择工具并生成参数；本专题研究 Host 与外部能力提供方如何通过共同协议发现、描述和执行能力。
- **正式文章位置**：`posts/agents/<article-slug>/index.html`（不要把正式文章放到 `_topics/`）。
- **发布规则**：先完成 HTML、独立 SVG、`evidence.json`、可运行示例和真实 QA，再由 `content/posts.json` 控制 `draft` / `published`。

此目录仅保留专题规划，不作为站点文章或 RSS 条目发布。
