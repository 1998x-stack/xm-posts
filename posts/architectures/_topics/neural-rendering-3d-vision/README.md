# Neural Rendering & 3D Scene Representations

研究如何从图像或视频学习可查询的三维场景表示，并从未观测过的相机视角生成图像。

## 核心问题

- **场景如何表示？** 连续神经场、隐式函数、显式点/高斯基元与混合表示各自保存什么信息？
- **图像如何生成？** Camera Ray、采样、体渲染、可见性与 rasterization 如何把三维表示投影为二维像素？
- **如何学习？** 相机内外参、重投影误差、多视角一致性和可微渲染如何形成训练闭环？
- **如何加速？** 位置编码、分层采样、多分辨率哈希网格、空间裁剪与 GPU 并行分别解决什么瓶颈？

## 术语边界

NeRF 是一种连续神经场表示与体渲染方法。Mip-NeRF、Instant-NGP 等工作改进其抗锯齿或计算效率；3D Gaussian Splatting 则以显式各向异性高斯和可见性感知 rasterization 建模场景，是同一新视角合成任务下的重要对照方法，不应误称为 NeRF 的网络变体。
