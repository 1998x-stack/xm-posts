Understanding AlexNet

一张图片如何从像素变成可学习的层级表示？为什么 2012 年的卷积网络既是一个模型突破，也是一场计算与训练方法的突破？

Krizhevsky · Sutskever · Hinton / NeurIPS 20125 Conv · 3 FC · 2 GPU约 34 分钟
核心观点：AlexNet 的贡献不是一个孤立的卷积公式，而是让深层视觉表征在 ImageNet 规模上成功训练的系统组合：ReLU、GPU 实现、正则化与足够的数据共同发挥作用。

01 · 为什么是 2012 年的 AlexNet？

如果一个系统只会看手工提取的纹理、梯度和形状，能否让它直接从像素中学出合适的特征？2012 年的关键突破不是“第一次有人想到卷积”，而是让深层卷积网络在百万规模 ImageNet 视觉任务上成为一种真正可训练、可竞争的系统。

ILSVRC-2012 的高分辨率图像分类包含 1000 类。Alex Krizhevsky、Ilya Sutskever、Geoffrey Hinton 把大数据、较深的 CNN、ReLU、GPU 卷积实现与正则化技术结合。最终参赛系统 Top-5 test error 为 15.3%，而第二名为 26.2%；但 15.3% 来自七模型集成，细节在 §10。[A1]

全篇区分三种语境：论文原始网络、为理解公式而设计的教学简化、现代库里的后续实现。把三者混成一张图，容易让结构与指标同时失真。

02 · 问题不是少一个分类器，而是如何学习表征

传统识别系统常把特征提取与分类分开优化。一个局部边缘本身并不是“猫”；它必须与邻域中的轮廓、纹理等共同构成多层表征。CNN 的局部连接与权重共享，使这种层级组织可以从训练数据中学习，而无需为每个像素位置单独学习一套滤波器。

局部性

一个卷积核只看相邻小块，适合捕捉局部空间结构。

参数共享

相同卷积权重在多个位置使用，减少空间维度带来的参数开销。

层级组合

浅层响应供深层继续组合，不预先保证每个特征都可解释。

规模与计算

大数据和高效 GPU 运算，使得足够宽、足够深的网络训练成为可能。

值得强调的是：层级表征不意味着每个通道都是人类可命名的“边缘检测器”；这只是理解结构的直觉，不是逐通道的实证结论。

03 · 一张图看懂八层可学习网络

AlexNet 的 8 层指的是 5 个卷积层和 3 个全连接层，不把池化与局部响应归一化算进“有参数层”。从输入一路向前，空间分辨率整体降低、通道数增长，最后在 4096 维隐藏层中汇聚为 1000 类分数。[A2]

04 · 卷积做了什么？为什么 224 和 227 都能出现在资料里？

把一张特征图视为高度 H、宽度 W、通道数 C 的张量。每个输出通道有一个覆盖全部相关输入通道的空间核；核以 stride S 移动，并按 padding P 补齐。忽略膨胀系数时，一个轴的输出长度是：

Hout=⌊H+2P−KS⌋+1
(1)

第一层论文正文写 224×224×3，同时 Figure 2 标注首层 55×55；使用 K=11, S=4, P=0 直接代入 224 只得到 54。因此，常见教材和部分现代实现用 227 输入、0 padding 得到 55；也可用 224 输入、padding 2 得到 55。两种约定的数值输出相同，但这并不证明二者都严格复制了原始 CUDA 实现。[A3]

边界说明：不能悄悄将“224/padding 未说明”和“227/padding 0”当作同一历史事实。本文图中保留论文所示 55→27→13→6 的 feature map 序列；交互与代码独立检验这两种明确约定。

卷积通常在深度学习框架中实现为 cross-correlation（不翻转核），该细节不影响此处的输出尺寸。真正要牢记的是三件事：局部空间窗口、跨通道求和、不同输出核学习不同特征。跨 GPU 时哪些通道可见还要看 groups。

05 · ReLU：为什么减少饱和比复杂激活更重要？

当神经元在正方向上饱和，反向传播梯度可能很小。ReLU 在正半轴上保持斜率 1，负半轴输出为零，形式非常简单：

f(z)=max(0,z)
(2)

论文 Figure 1 用一个四层 CNN 在 CIFAR-10 上比较 ReLU 和 tanh：达到 25% 训练错误率，ReLU 所需迭代对应约六倍训练速度优势。它说明非饱和激活有助于实验速度，但不是整套 AlexNet 端到端吞吐提高六倍的测量结果。[A4]

ReLU 不解决所有训练难题：若某些单元长期落在负半轴，它们也可能持续输出零；这与正区间不饱和是两回事。

06 · LRN 与重叠池化：两项原始设计如何起作用？

AlexNet 在 Conv1 与 Conv2 后使用 Local Response Normalization（LRN）。归一化在同一空间位置、相邻输出通道的响应间比较，并非现代 Transformer 常用的 LayerNorm，也不是 BatchNorm。设激活为 a，归一化值为 b，邻近通道集合为 𝒩(i)：

bi=ai(k+α∑j∈𝒩(i)aj2)β
(3)

论文使用 k=2、n=5、α=10⁻⁴、β=0.75，并报告 LRN 在其对照下使 Top-1/Top-5 错误率分别降低 1.4/1.2 个百分点；这是原论文实验条件下的比较，不是所有数据集的普遍规律。[A5]

池化使用 3×3 窗口、stride 2，相邻窗口重叠（因为 2 < 3）。论文与 2×2 / stride 2 的同输出尺寸池化对照，报告 Top-1/Top-5 错误率分别改善 0.4/0.3 个百分点。池化减少空间位置，而卷积通常保留或提高通道表达能力。[A6]

07 · 双 GPU：为什么是分组连接，而不只是数据并行？

2012 年单块 GTX 580 只有 3GB 显存。原始网络将不同 feature maps 放在两块 GPU 中，但并非每一层都完全隔离：Conv2、Conv4、Conv5 主要连接同 GPU 的前层通道；Conv3 允许跨 GPU 连接；FC 层最终融合全局信息。[A7]

在现代深度学习接口中，groups=2 是一种可以表达原始部分卷积分组连接的实现选择。它和数据并行有本质差别：数据并行通常让两块设备拥有同一份模型，处理不同样本；这里的两块设备在同一个模型内部承担不同通道子集的计算。

原论文还指出，与一块 GPU 上较窄的比较模型相比，双 GPU 版本的 Top-1/Top-5 错误率降低 1.7/1.2 个百分点；由于网络宽度和连接结构同时变化，这不是固定模型“加一张卡便自动提升准确率”的因果证明。

一个具体的 Conv2：分组让多少条通道连接消失？

只讨论 Conv2 的连接约束：输入 96 个通道、输出 256 个通道、空间核 5×5，输出位置 27×27。比较原论文中这一层的两组连接与一个假想的 dense 对照层；两者没有重新训练，也不能由参数少就推断准确率。

每个输出核看到的输入通道48
权重数量（不含偏置）307,200
MACs（27×27 输出）223,948,800

两组各自连接 48 个输入通道：256 × 48 × 5 × 5 = 307,200 个权重。dense 对照是 614,400；这层的权重和理论 MACs 都减半。若计偏置，则两种方案都另加 256 个偏置参数。

08 · 为什么百万张训练图片仍需要强正则化？

全连接层包含巨量参数。按卷积输出 6×6×256=9216 个数估算，第一层 FC6 的权重约有 9216×4096≈3775 万个，FC7 又有约 1678 万。与 5 个卷积层相比，它们占据了模型参数的绝大部分，因此过拟合风险真实存在。

随机裁剪、镜像与 PCA 颜色扰动

论文先把图像调整为 256×256，再从中随机抽取 224×224 patch，并进行左右翻转；训练时还对 RGB 主成分方向施加颜色扰动。测试时，从四角和中心取五块，再水平翻转成十块，平均十次 softmax 的预测概率。这不能误写为十张不同输入图片的独立预测。[A8]

Dropout：让隐藏神经元不能互相形成固定依赖

原论文使用 0.5 的丢弃概率，作用于前两个全连接隐藏层。它采用训练时置零、测试时保留所有单元并将输出乘 0.5 的说明方式。今天常见的 inverted dropout 则在训练时缩放保留的激活，推理时不额外缩放；两种约定在期望上对应，但实现语义不能对调。[A9]

09 · 优化目标与训练协议

最后一层输出 1000 个 logits，softmax 把它们转成类别分布；训练最大化正确类别的对数概率，等价于最小化交叉熵。

p(y=c∣x)=exp(zc)∑kexp(zk)
(4)
ℒ(x,y)=−log(py)

论文使用 minibatch 128、momentum 0.9、weight decay 0.0005 的 SGD；学习率从 0.01 开始，在验证集错误率不再改善时手工降低十倍。文中还说明使用两张 GTX 580 3GB GPU，完整训练约 5–6 天。所有数值都属于 2012 年论文设置，不应代替如今复现所需的环境和数据协议。[A10]

数字必须带上数据集、split、模型数量与是否预训练，否则一句“AlexNet 达到 15.3%”会误导读者。

论文还报告：移除中间任一卷积层会使 Top-1 指标恶化约两个百分点。这是特定架构与训练设置下的观察，支持“深度重要”，但并不自动说明继续无限增深一定更好。[A12]

11 · 交互：检查第一层卷积的尺寸约定

两个公开资料中经常出现的输入尺寸，若分别配合清楚的 padding，都能产生 55×55 的输出。这是算式演示，不是对原始 CUDA kernel 的逆向考证。

请选择输入与 padding 约定
H=227, P=0, K=11, S=4 → floor((227+0−11)/4)+1 = 55；输出 55×55×96。

有效宽度 227；可移动的距离 227−11=216；以步幅 4 取起点 0,4,…,216，恰好 55 个位置。

把同一输入继续送入 3×3 / stride 2 的 overlapping max-pool（padding 0），得到 27×27；Conv2 用适当边界约定保持 27×27，再池化为 13×13。要计算真实参数量与数值，应始终显式记录各层 padding 与 groups。

12 · 最小代码：不依赖框架，验证卷积形状与分组参数

下面的纯 Python 核心片段与仓库里的 mini_alexnet.py 对应。它只检查尺寸与参数预算，不是 AlexNet 训练代码，更不复现论文成绩。

def conv_out(n, kernel, stride=1, padding=0):
    return (n + 2 * padding - kernel) // stride + 1

assert conv_out(227, 11, 4, 0) == 55
assert conv_out(224, 11, 4, 2) == 55
assert conv_out(55, 3, 2, 0) == 27

def grouped_conv_params(cin, cout, k, groups=1):
    assert cin % groups == cout % groups == 0
    return cout * (cin // groups) * k * k + cout

# Conv2 中每个 kernel 只连接 GPU 同组的 48 个输入通道
assert grouped_conv_params(96, 256, 5, 2) == 307456

重点不是“能不能得到 55”，而是知道 groups 改变了连接图及参数数量，却不会单独改变 feature map 的高度和宽度。要复现原论文，还需要原始分组行为、数据预处理、训练日程、十裁剪推理与模型集成协议。

13 · 遗产与边界：AlexNet 开启了什么，并没有证明什么？

AlexNet 让“以大规模标注数据训练深层视觉表征”的工程路线变得可信。此后的 VGG、Inception、ResNet 等模型，在卷积核设计、宽度、深度与优化稳定性上继续推进；它们不是 AlexNet 原论文的组成部分。

可以带走的直觉

图像的局部性允许参数共享；端到端训练允许低层与高层特征共同优化。

容易误读的数字

单 CNN 的 18.2%（validation）与七模型集成 15.3%（test）不能混写。

历史因素

LRN、两 GPU 分组和 2012 年训练栈适用于原文；不代表现代最佳实践。

仍需谨慎

ImageNet 表现不等于鲁棒性、公平性、分布外泛化与计算效率的全面保证。

先读 CNN 理解卷积核如何逐位置复用，再读本篇 AlexNet 理解更深网络与通道分组。随后阅读 MobileNet：它将逐通道卷积与 1×1 逐点卷积组合，优化的连接形式与这里 groups=2 不一样；另见 ResNet 及 SGD。
