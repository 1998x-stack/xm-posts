Understanding DeltaNet

线性注意力已经把历史压缩成固定大小的矩阵记忆。为什么它仍然难以准确回忆？能否让记忆不只会相加，还会“纠错”，同时保留 GPU 友好的并行训练？

Songlin Yang, Bailin Wang, Yu Zhang, Yikang Shen, Yoon KimNeurIPS 2024 · arXiv:2406.06484约 34 分钟
一句话理解：DeltaNet 用当前 Key 检索记忆中的旧 Value；写入新 Value 时先计算目标与旧读出的差，再沿 Key 方向修正。2024 年论文进一步把这个递推改写成可分块训练的矩阵操作。[原论文]

01 · 把字典装进一块有限的记忆

假设一个序列先说“用户 A 的邮箱是 old@example”，后又明确更正为“new@example”。模型最后被问到 A 的邮箱时，需要的是最新绑定，而不是旧值和新值的模糊混合。

标准 Softmax Attention 可以用当前 Query 显式比较历史每个位置的 Key；但随上下文增长，参与计算的历史项和缓存也增长。线性注意力尝试把历史压缩为固定大小的状态矩阵 S：每一步只需更新状态，再用当前 Query 读取。这样生成阶段不必保留整条历史的注意力 K/V 缓存，但固定容量的状态也带来了冲突问题。

关键问题并非“能不能表示过去”，而是：当新旧信息竞争同一记忆方向时，怎样替换而不是叠加？

02 · 普通线性注意力：能累积，却没有显式改写

为明确形状，设单个 Head 的 Key/Query 维度为 dₖ，Value 维度为 dᵥ；列向量 kₜ,qₜ ∈ R^{dₖ}、vₜ ∈ R^{dᵥ}，状态 Sₜ ∈ R^{dᵥ×dₖ}。这里暂时省略特征映射、归一化和多头拼接，先看核心递推。

St=St−1+vtkt⊤
(1)

外积 vₜ kₜᵀ 会把 Value 写到 Key 所指向的记忆方向。取 S₀=0，读取 Sₜqₜ 等价于对历史所有 Value 按 kᵢᵀqₜ 加权求和。这个重排使自回归解码每步能用固定尺寸状态完成读取，但它也说明：没有针对旧绑定的删除项。

例如两个非正交的 Key，后者会影响前者的读出；即便完全同 Key，直接把两个 Value 相加也不能自然体现“后一条覆盖前一条”。模型可以在训练中学习不同表示缓解干扰，但单纯加法没有显式误差校正机制。[作者解释 I]

03 · Delta Rule：先问记忆知道什么，再写入差异

给定当前 kₜ，先从旧状态读取 v_old = Sₜ₋₁kₜ；然后比较训练中由当前 token 投影得到的目标 vₜ。DeltaNet 不再简单累加 vₜkₜᵀ，而写入误差 (vₜ−v_old)kₜᵀ。标量 βₜ 控制本次改写的强度。

St=St−1+βt(vt−St−1kt)kt⊤
(2)

这可以直接看成对局部平方预测误差执行一步梯度下降：把矩阵 S 当作当下可更新的快速权重，kₜ 是输入，vₜ 是回归目标。这里的“在线更新”是前向传播期间的状态更新，并不等于部署时用标注数据改动整网参数。

Lt(S)=12‖Skt−vt‖2
(5)

对 S 求导得到 (Skₜ−vₜ)kₜᵀ，代入学习率 βₜ 就回到公式 (2)。这解释了“Delta”的含义：写入量正比于预测误差，而非原始目标本身。

如果 ‖kₜ‖₂ = 1，新状态沿当前 Key 的读出是旧读出与新目标的凸组合；若 Key 没有单位归一化，这个简化不成立，不能把 β=1 解释为普遍的完全覆盖。

Stkt=(1−βt)St−1kt+βtvt
(3)

04 · 从“读—比较—写”到结构化矩阵转移

把公式 (2) 展开并整理，可将一次写入写成对旧状态的右乘变换，加上一项新的外积：

St=St−1(I−βtktkt⊤)+βtvtkt⊤
(4)

令 Mₜ = I − βₜkₜkₜᵀ，则 Sₜ = Sₜ₋₁Mₜ + βₜvₜkₜᵀ。Mₜ 不是任意稠密矩阵，而是单位阵减秩一矩阵。这让状态更新能以矩阵—向量乘法和外积执行，单头每 token 的算术成本为 O(dᵥdₖ)。

归一化键向量使几何直觉尤其清晰：在 kₜ 方向上，Mₜ 的特征值为 1−βₜ；垂直方向特征值为 1。若 β=1，就移除当前 Key 方向的旧信息，同时写入新的目标；对不同 Key 方向仍可能有干扰，不是无损可寻址字典。

术语边界：当 β∈(0,1) 且 Key 单位归一化时，以上矩阵是收缩/投影型更新。论文将相关乘积和广义 Householder 结构联系起来以建立 WY 表示，但不要据此把每一步都误称为严格的 Householder 反射（经典反射对应另一参数范围）。

05 · 递推有了，训练为什么还需要 WY？

如果训练时只能像普通 RNN 一样沿时间顺序一个 token 一个 token 更新状态，即使总算术量不高，GPU 的海量并行单元也很难吃满。看似可以对仿射矩阵递推做 parallel scan，但若显式构造并组合所有 dₖ×dₖ 转移矩阵，会带来昂贵的矩阵乘法与中间状态存储。

NeurIPS 2024 的主要算法贡献是把矩阵乘积写成紧凑低秩表示（WY representation），并在序列块内构造可批量计算的伪值向量。设初始状态为 0，原本看似不可分的递推可以重写成：

St=∑i=1tuiki⊤
(6)

其中 uᵢ = βᵢ(vᵢ − Σⱼ<ᵢ uⱼ(kⱼᵀkᵢ)) 是由前面 Key 的相似度和伪值共同修正的写入量，而不是原始 vᵢ。在长度为 C 的块内，利用严格下三角的因果关联矩阵和等价的三角运算，可以集中执行矩阵乘法；块与块之间仍传递边界状态。[§3.1–3.2 / Eq.3–11]

因此 DeltaNet 同时具有两种有用的执行形态：解码时使用固定大小的递推状态；训练长序列时使用专门的分块并行 kernel。二者在数学上服务同一个更新规则，但性能结论依赖块大小、Head 大小、GPU 和 kernel 实现，不能只凭时间复杂度推断绝对速度。

06 · 论文里的完整 DeltaNet，不只有一个公式

2024 年架构并不是直接拿原始 Delta Rule 替换整网。论文 §3.3 以 LLaMA 风格的残差 Transformer Block 为骨架：每个 Block 使用归一化、DeltaNet token mixing 和 SwiGLU channel mixing。Query、Key、Value 有各自的线性投影，加入短深度卷积与 SiLU；Query/Key 进行 L2 归一化，β 由可学习投影经 Sigmoid 得到，DeltaNet 输出再经过 RMSNorm 和线性投影。

为什么 Key 归一化重要？它让更新方向具有受控的长度，避免矩阵转移在 Key 方向发生不易解释的放大；论文 §3.3 指出 L2 归一化相较早期 L1 方案更有效。为什么短卷积重要？它补充局部 token 信息；其收益不能归因于 Delta Rule 一项。

本篇的极简 Python 演示故意不实现卷积、SwiGLU、RMSNorm 或全部训练参数，也不复现论文模型；它只验证状态更新的形状、数值和覆盖边界。[§3.3, Figure 2]

07 · 论文到底证明了什么？先看实验条件

主实验在相同 SlimPajama 子集与 Mistral tokenizer 设置下对比不同模型；340M / 15B tokens 与 1.3B / 100B tokens 是两组不同规模，不能交叉比较。同样要注意是否配备短卷积：Mamba 自带卷积，而部分 GLA/DeltaNet 行有卷积与无卷积两种设置。下表只摘录作者 Table 1 的 1.3B 主要结果，便于控制范围。[Table 1, p.8]

上述数值表明：在这组报告条件下，纯 DeltaNet 的 WikiText PPL 略高于 Transformer++（16.87 vs 16.85），但其综合 zero-shot 指标更高（51.6 vs 50.9）；加入少量 Softmax Attention 后可进一步改善若干指标。不能把混合模型的结果等同于纯 DeltaNet，也不能声称全面战胜 Transformer。

对 340M 的消融也很有信息量：同为 1+ELU 特征图，L1 Norm 的 WikiText PPL 为 31.12，换为 L2 Norm 后为 28.03；这支持“归一化设计很重要”，并不等于证明所有提升都来自 Delta Rule。论文还报告了合成记忆任务、训练吞吐 Figure 6，以及更大规模 3B 实验；不同训练预算的 3B 基线不能做严格同条件结论。

证据阅读方法：对任何“更快 / 更准”的表述，先检查具体指标、模型规模、卷积配置、训练 token、序列长度与硬件；性能从来不是一个脱离实验设置的常数。

09 · 最小可运行代码：不要只相信图

源码位于 mini_deltanet.py，仅依赖 Python 标准库。测试包括 β=0 不改写、单位 Key 且 β=1 的目标覆盖、垂直 Key 不受影响、非单位 Key 不能误称完全覆盖，以及两步递推与矩阵转移形式一致。

def delta_step(S, k, v, beta):
    old = [sum(row[j] * k[j] for j in range(len(k)))
           for row in S]
    return [[S[i][j] + beta * (v[i] - old[i]) * k[j]
             for j in range(len(k))]
            for i in range(len(v))]

# unit key; old readout = 0.2
assert abs(delta_step([[0.2, 0.0]], [1.0, 0.0], [1.0], 0.5)[0][0] - 0.6) < 1e-12

本实现将 S 组织为 dᵥ × dₖ 的行列表；生产 kernel 可以采用不同布局，但必须满足同一代数式。若应用了实际模型的多头投影、卷积、激活、归一化与混合精度，还需单独考虑数值稳定性和真实性能。

10 · 边界与后续：Gated DeltaNet 不是这篇论文的别名

  • 有容量上限。固定形状的矩阵记忆不可能在任意长序列无损保存任意数量的独立键值绑定；相关 Key 之间仍然会产生干扰。
  • 训练没有免费加速。虽然 chunkwise 重排提高了训练并行性，2024 论文 §5.3 明确指出它的训练速度仍落后于 GLA；Head 内的依赖与 GPU SRAM 限制会妨碍状态尺寸继续扩大。
  • 长度外推有限。该工作在 §5.3 报告了较弱的长度泛化，并推测与缺少显式衰减有关；这不是所有数据集、所有长度上的统一定理。
  • 不同迭代不可混淆。Gated Delta Networks: Improving Mamba2 with Delta Rule 是后续的 ICLR 2025 工作，加入显式门控衰减并有其独立实验。它不是 NeurIPS 2024 DeltaNet 的同名修订。

将本篇放在 Architectures → Efficient Attention 之下，也可以与 State Space Models / Linear RNNs 交叉阅读：它的注意力式读取与矩阵递推正处在这两条研究路线的交汇点。系统层的 Triton kernel 优化是相关延伸，但不宜直接把 DeltaNet 的架构研究归入 Serving 分类。
