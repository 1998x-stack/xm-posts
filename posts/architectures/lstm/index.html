Understanding LSTM

一句话开头的线索，为什么在一千步之后还可能被记住？不是让循环网络一味「记得更多」，而是为记忆设计一条更容易训练的通路。

Hochreiter & Schmidhuber · Neural Computation 1997后续关键改进 · Gers et al. 2000模型架构 / Recurrent Networks约 32 分钟
核心思想：普通 RNN 每一步都重写隐藏状态；LSTM 在内部引入可跨时间加性传递的状态，使用门控制何时写入和对外输出。需要特别留意：今天常见的「遗忘门」不是 1997 年原论文的一部分。

01 · 为什么早期输入会被忘掉？

想象阅读一段日志：第一行记录某个任务的 ID，之后连续出现许多无关事件，最后一行问最初的 ID。模型要做的不只是处理当前字符，而是让与很早以前有关的信息跨越许多时间步。

普通 RNN 按时间递推隐藏状态：第 t 步把新输入 xₜ 和上一步 hₜ₋₁ 合成新的 hₜ。展开以后，从第 1 步到第 T 步形成一条很长的依赖链。它理论上能表达长期依赖，但“能表示”不意味着梯度下降容易学到。1997 论文第 1、3 节正是从这种长期信用分配困难展开论证。

02 · 梯度到底在哪里消失？

将更新写成 hₜ = φ(Wₕhₜ₋₁ + Wₓxₜ + b)。反向传播要对每一步的局部导数应用链式法则；对于很久之前的状态，梯度经过许多矩阵的乘积。

∂hT∂ht=∏k=t+1TJk

其中 Jₖ = ∂hₖ/∂hₖ₋₁。连乘的谱性质决定某条路径的梯度尺度，不可只用单个标量权重解释所有网络。

如果每一步相关方向持续缩小，连乘很快接近零；若某些方向被持续放大，则又可能产生梯度爆炸。举例说，每步的某个标量方向缩放为 0.9，跨 100 步就只剩约 0.0000266。这是示例计算，不是论文测出的 RNN 梯度。

1997 年作者讨论的是长期误差回传的训练困难，而非“普通 RNN 绝不能记住长序列”的表达能力定理。LSTM 采取的是修改状态结构与局部梯度路径，不是用一句“加一个门”直接解决问题。

03 · CEC：把记忆通路变成加法

如果一段记忆在没有新信息写入时能直接接续，而不是每次强迫它通过新的压缩非线性，反向的误差信号也就不必在这条内部通路上反复乘非线性导数。

1997 论文称这个固定自循环为 Constant Error Carousel（CEC）。核心是内部线性记忆单元的自连接权重固定为 1：上一状态可以原样传入下一步，另有一个可控增量加到它上面。

但一个永不受控的线性自循环容易被持续写入的新信号污染。原论文第 3 节还讨论了输入权重冲突、输出权重冲突：什么时候保护已有内容，什么时候允许把它交给后续网络读取？门控正是为此而来。

04 · 1997 年的两扇门

早期 LSTM 围绕每个 memory cell 设计两个可学习、可微的乘性门。输入门决定能否将新候选信号注入内部状态；输出门决定内部状态的内容是否会影响其他单元。门值不是“开/关”的硬布尔值，而通常通过 sigmoid 等激活连续控制。

输入门 · 何时写？

当前输入若与要长期保留的信息无关，可以抑制写入；从而减少状态被反复扰动。

输出门 · 何时读？

即使内部有记忆，也可以暂不将其暴露给下游输出；这有助于避免无关记忆干扰当前任务。

一个常见误解是把现代 LSTM 四门图直接当作 1997 原始架构。历史上不是这样：遗忘门的适应性清除机制由 Gers、Schmidhuber 与 Cummins 在 2000 年引入，解决持续序列预测中细胞状态需要复位的问题。

05 · 精读原始状态方程

用 s 表示 1997 原文的内部状态，用 iₜ、oₜ 表示输入门和输出门激活，aₜ 表示候选值的预激活。下面是原论文 Section 4 的向量化改写，而不是逐字复刻符号。

st=st−1+it⊙g(at)

1997 论文第 4 节内部状态记作 s，输入门负责写入；此处按向量形式书写，原文以记忆单元下标逐项定义。

yt=ot⊙h(st)

g、h 在原文中是可微压缩/缩放函数；它们不必与某个现代实现的 tanh 选择完全相同。

对“保持门值与外部输入固定、只沿固定自连接路径传播”的局部导数而言，∂sₜ/∂sₜ₋₁ = 1。这解释了名称中的 constant error flow。但原始方法也使用截断误差传播，不应将该局部导数扩展成“所有梯度都是 1”。

版本辨析：这一节没有 fₜ 或遗忘操作。把 sₜ = fₜ·sₜ₋₁ + iₜ·候选 写进 1997 原论文，会把 2000 年之后的改进回填到历史版本中。

06 · 遗忘门如何进入标准 LSTM

假如一个系统连续处理多段互不相干的任务：第一个任务的状态在第二个任务开始时不再有用。1997 的固定自循环让长期保存更容易，但对“什么时候主动清空”不够灵活。2000 年论文提出可学习的遗忘门 fₜ，使旧状态可以按比例保留或衰减。

因此，现代记忆更新分成两项：fₜ⊙cₜ₋₁ 控制留下多少过去，iₜ⊙c̃ₜ 控制写入多少现在。输出门则决定多少经过非线性变换的状态能成为 hₜ。这个分工比“遗忘门负责删除、输入门负责存储”更精确：门值连续、各元素独立，而且同一步可以同时保留和写入。

07 · 现代四门方程与张量形状

设输入维度 D、隐藏宽度 H、batch 大小 B。每步 xₜ ∈ ℝ^(B×D)，hₜ₋₁ 与 cₜ₋₁ ∈ ℝ^(B×H)。将 x 和历史隐藏状态按特征维连接得到 zₜ ∈ ℝ^(B×(D+H))，每个门的权重 W ∈ ℝ^(H×(D+H))，偏置 ∈ ℝ^H；公式按 batch 行向量右乘权重转置的等价记法表达。

it=σ(Wizt+bi) ft=σ(Wfzt+bf) c~t=tanh(Wgzt+bg) ot=σ(Wozt+bo) ct=ft⊙ct−1+it⊙c~t ht=ot⊙tanh(ct)

zₜ = concat(xₜ, hₜ₋₁) ∈ ℝ^(D+H)，各门与 cₜ、hₜ 均为 H 维；⊙ 表示逐元素乘法。

其中 σ 为 sigmoid，tanh 是双曲正切，⊙ 为逐元素乘积；输入、遗忘、输出三个 sigmoid 门和 tanh 候选都是 H 维。不同框架可能将权重写成 Wₓx + Wₕh 的两组矩阵，并在一次矩阵乘法中堆叠四路计算；这只是等价参数化，并非每个方向都需要独立进行四次 kernel 调用。

P=4H(D+H+1)

单层、单向、无投影、每门一份偏置的教学参数化。PyTorch 默认输入与递归分别存储偏置，因此实现中的张量参数数目为 4H(D+H)+8H。

计算参数量时应注明 bias 数量、层数、方向及可选 projection。对双向 LSTM，反方向的递归依赖使用未来位置；对 streaming 自回归任务则不可直接引入未来信息。

08 · 从写入、保持到读取

拿“第一个 token 决定最后答案”的任务作思想实验：模型开始时应允许关键线索写入；中间面对无关输入则倾向保持；到了输出节点再使用输出门将内部记忆映射为可观测状态。

这里也能看到 cell state c 和 hidden state h 的区别：c 是可跨时间延续的内部载体；h 是经过输出门、非线性映射后可被下一层和输出头直接使用的表征。二者维度通常相同，但含义与读取方式不同。

09 · 动手实验：记忆能保留多久？

暂时只考虑一个标量记忆单元：先令 c₀ = 1，随后每步遗忘门固定为 f，不再写入新候选，则 cₙ = fⁿ。选择不同 f 和步数观察直接保留比例；也可以切换到“每步有固定新写入”的教学情境，看到保持与覆盖如何共同作用。

f=0.980，N=40；旧记忆占比 0.4457，最终状态 cₙ=0.4457（只保留模式）。

此实验固定门值，完全不包含由输入、隐藏状态计算门值或梯度训练的过程；数值只说明状态更新公式的结构。若每步写入 0.02，最终 cₙ = fⁿ + 0.02(1−fⁿ)/(1−f)（f ≠ 1），f=1 时为 1+0.02N。

10 · LSTM 不等于梯度永不消失

在现代变体中，沿着细胞状态的直接保留通路，每步乘以 fₜ。这让网络有机会学到接近 1 的门值，但 fₜ 也可能显著低于 1；而且损失到参数的完整梯度还有其他通路与非线性。

(∂cT∂ct)direct=∏k=t+1Tfk

这是保持门值固定、仅跟踪 cₖ₋₁ → cₖ 的直接支路的局部导数；完整梯度还可能经门网络和 h 返回，因此不能把它误作全网络的唯一梯度。

举例：0.9¹⁰⁰ ≈ 0.0000266，0.99¹⁰⁰ ≈ 0.3660，0.999¹⁰⁰ ≈ 0.9048。差一个小数位的门值，长期保留表现就会非常不同。门偏置初始化、输入分布、数值精度和实际任务，都可能改变学习动态。CEC 是有利于长期信用分配的架构路径，而不是整个网络的无条件梯度保证。

11 · 最小代码：算出一个时间步

可运行代码位于 文章目录的 Python 示例（源码仓库）；它使用 Python 标准库，不依赖 GPU、PyTorch 或真实数据集。以下是最关键的更新，展示了门值如何组合，而非完整训练器。

i = sigmoid(a_i)
f = sigmoid(a_f)
g = tanh(a_g)
o = sigmoid(a_o)
c_t = f * c_prev + i * g
h_t = o * tanh(c_t)

为免将“一个 step”误作“训练了一篇论文的模型”，源码只提供确定性前向计算、维度断言和数值自检。它既不包含 BPTT，也不宣称复现 1997 实验。若迁移到 PyTorch LSTM，还需处理多层、dropout、双向、projection 和两个偏置张量等语义。

12 · 回到论文：证据与边界

原始研究应从 Hochreiter 与 Schmidhuber 在 Neural Computation（1997） 的论文阅读。摘要明确报告，在作者构造的人工长时间延迟问题中，LSTM 学到了跨越 1000 步以上的依赖；这不是对任意语言数据的普遍性能保证。

1997 原论文 · 摘要、§5人工 long-time-lag 任务可跨超过 1000 步；和同期方法比较模型、任务、成功判据由该论文定义；不外推为通用序列模型 SOTA

13 · 工程视角与历史版本

1997：解决可训练性

固定 CEC 通路，加上输入和输出门；原始方法配合特定误差截断策略。

2000：让记忆可复位

遗忘门按上下文衰减旧状态，适应连续预测与任务边界变化。

2002：门也观察内部状态

Peephole 连接为时间感知提供额外输入；与无 peephole 的标准式区分。

现代实现：算子与布局

通常拼接计算四门矩阵，按序列展开，训练有 BPTT；推理按时间步递推并保存 h 与 c。

与 Transformer 自注意力不同，标准 LSTM 存在逐时间步依赖：第 t 步必须得到上一步 h、c 才能继续。其单步状态内存可以独立于过去序列长度，而沿时间的递推限制了某些并行方式；训练仍需存储或重算中间激活。复杂度的实际优劣取决于维度、序列长度、硬件、吞吐模式和实现，不能仅由“线性 vs 二次”四个字断言。

最应记住的三个区别是：原论文与后续遗忘门、内部 cell state 与可见 hidden state、直接误差通路与完整梯度。掌握这三点，就能读懂很多历史论文、框架 API 和系统调优中的 LSTM 细节。
