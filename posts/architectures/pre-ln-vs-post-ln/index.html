ARCHITECTURE / NORMALIZATION & RESIDUAL PATHS

Pre-LN vs Post-LN：
LayerNorm 放在哪里，为什么改变训练？

同样是 Attention、FFN、残差连接，只把归一化移到加法的前后，网络的梯度路线与训练日程就可能截然不同。真正改变的不是“有没有 LayerNorm”，而是恒等捷径是否穿过它。

2026-11-20约 28 分钟阅读主要论文：Xiong et al., ICML 2020交互 · 数学 · 原始证据

01一件反直觉的小事：换个位置，就能省掉 warm-up？

原始 Transformer 使用 Post-LN。它不是不能训练，而是训练开始时对学习率日程常常更敏感。Xiong 等人提出并验证，在他们研究的设置中，改为 Pre-LN 可以不使用 warm-up，仍取得相近结果。[Xiong 2020, §1, §4]

这不是一个简单的“梯度消失 vs 不消失”故事。我们至少要分清三件事：激活怎么走、梯度怎么传、优化器在初始化附近如何更新参数。先把注意力的细节临时折叠成一个函数 F，只看一个子层。

问题拆解：如果同样的输入 x ∈ ℝ^d，两种结构在前向计算上已经不是同一个函数，那么它们的反向 Jacobian 也不可能完全相同。warm-up 只是这一差别对训练的一个后果，不是定义本身。

02把 Transformer 子层缩成两张路径图

Post-LN（原始 2017 Transformer）

先算残差和，再让整个输出过 LN。每一个块的输出都被规范化；但从输出到输入，LN 位于必经路径。

Pre-LN（后来的重要变体）

先规范分支输入，再把分支输出与未经 LN 的 x 相加。块内保留直接相加的恒等通路；堆叠末端通常另加 final norm。

Post-LN:xl+1=LN(xl+Fl(xl))
Pre-LN:xl+1=xl+Fl(LN(xl))
xₗ 与输出均是 d 维向量；这里将 dropout、mask、偏置、多个子层略去。真实网络是逐 token 应用这种结构。Vaswani 2017, §3.1；Xiong 2020, Figure 1。

特别要记住：Pre-LN 并不是“整个残差流每层都保持方差为一”。被归一化的是送入 F 的分支输入；残差流本身仍可能随着深度增长。这正是为什么常见 Pre-LN 实现会在输出头前提供最终归一化。

03LayerNorm 到底在规范谁？

一个批次的隐藏状态张量可以记成 X ∈ ℝ^{B×T×D}。标准 LN 为每个 batch、每个 token 单独计算 D 维特征的均值和方差；它不跨 batch，也不在序列长度 T 上求均值。[Ba et al. 2016]

μ=1D∑ixi,σ2=1D∑i(xi−μ)2
LN(x)i=γi·(xi−μ)σ2+ε+βi
i 遍历隐藏维；ε 是避免数值除零的常数。LN 的尺度与偏移是可学习参数。此文局部分析在说明时会使用简化的 γ=1、β=0。

“前 / 后”是相对于残差加法的位置，不是相对于整个模型的输入输出位置。RMSNorm 则是一种不同的归一化函数，不要把 RMSNorm 与 Pre-LN 混为同一个维度的选择。

04真正关键的差别在反向链式法则

令 J_F 与 J_LN 分别是 F 和 LN 对其输入的 Jacobian。在一个局部子层里，对两边求导便得到不同的结构：

Jpre=I+JF(LN(x))·JLN(x)
Jpost=JLN(x+F(x))·(I+JF(x))
按列向量约定书写。两者都含有 residual branch；只有 Pre-LN 在这个局部块上直接出现不被输出 LN 左乘的 I。

直觉可以这样抓住：Pre-LN 的梯度有一条不经过子层 F 和其前置 LN 的直接加法路径。Post-LN 的所有上游梯度都必须经过该块输出处的 LN Jacobian。不过，“存在 I”不等于学习一定更快或泛化一定更好；每层的实际梯度还要由损失、参数、数据和其他块共同决定。

05亲手移动输入：LN 到底消去了什么？

现在把输入向量整体加上相同常数 c：x′ = x + c·1。由于 LN 对逐特征一致的平移不敏感，LN(x′)=LN(x)。在无偏置的线性玩具分支 F 下，Pre-LN 与 Post-LN 的输出会呈现完全不同的平移响应。

交互：固定输入 [1, 2, 4, 6]，整体平移 +2

选择结构，观察输出每一维的变化。代码不请求网络，数值由同页 JavaScript 计算；这不是训练实验。

Pre-LN：对 x 所有维度加 2，输出也逐维增加 2。
因为 LN(x+2·1)=LN(x)，而残差 x 仍保留了这个平移。

这里的 F(v)ᵢ = 0.2vᵢ + 0.1vᵢ₊₁（循环索引）只是方便手算的线性变换。它没有 Attention、没有训练数据，也没有在模拟论文中的梯度统计。它能证明的仅是这些明确函数的局部输入输出性质。

06Xiong et al. 究竟证明了什么？

ICML 2020 论文研究的是初始化附近的参数梯度规模，不是笼统地说“Post-LN 所有层都会爆炸”。在该论文的简化初始化与集中性假设下，Theorem 1 针对最后一个 FFN 子层第二层权重 W²,L，给出梯度范数的上界量级：

Post-LN:O(d(lnd))
Pre-LN:O(d(lndL))
d 为隐藏维，L 为论文定义的层数；这里刻意保留它所分析的特定权重、初始化和渐近上界范围。不是任何模型的精确梯度等式。Xiong 2020, Theorem 1。

背后的一步是：Pre-LN 的残差流规模在该论文假设下随深度增长，因此最终的 LN 对回传梯度有不同的尺度影响；Post-LN 则在每个块后规范化。这个理论为“初始化时上层参数可能承受较大更新”提供了机制解释。但定理是有前提的量级界，不直接等同现代大模型的一条通用训练规则。

重要范围限制：论文的分析涉及特定初始化、网络与损失条件。不同宽度、深度、优化器、残差缩放、RMSNorm、混合精度和现代训练配方可能改变实际现象。不能把该上界当作逐层训练曲线或必然的泛化排名。

08更深一层：为什么“梯度不均衡”还不是全部？

Liu et al., EMNLP 2020 提醒我们：光比较梯度范数不足以解释所有不稳定。若层输出对残差分支 F(x) 的依赖过重，分支参数的一点变化，就可能把输出扰动放大。过轻的分支依赖则可能压低模型表达潜力。

branch dependency≈Var[F(x)]Var[x+F(x)]
这是 Liu et al. 对分支贡献的一种方差度量；这里省略索引并用近似号提示展示的是简化理解，详见论文 Figure 2 注释与 §4。不能把它等同梯度范数。

这产生了新的设计目标：初始化阶段不要让新分支太支配输出，训练后又要允许分支发挥作用。Admin 是该论文围绕此想法提出的初始化策略。因此，对“Pre-LN 和 Post-LN 谁更好”的严谨回答，必须明确是谈稳健性、收敛效率、最终质量，还是可扩展深度。

09不是二选一：后续研究如何改写设计空间

策略核心变化证据来源
Pre-LNLN 位于每个变换分支之前，残差加法出口不再经过 LNXiong 2020
Post-LN加法后 LN；原始 Transformer 的布局Vaswani 2017
DeepNorm类似 Post-LN 的规范化位置，增加残差增益与匹配的初始化Wang et al., DeepNet 2022
NormFormer在 Pre-LN 骨架中加更多规范化与 head scalingShleifer et al. 2021
Peri-LN将 LN 布置在子层周围，研究方差与梯度的平衡Kim et al., ICML 2025

这里应按两个正交问题组织知识：一是用什么归一化函数（LayerNorm、RMSNorm 等），二是把它放在残差加法的哪里（Pre、Post、Peri 或其他变体）。所以本主题属于架构分类的 Normalization & Residual Paths，而不是新增一个割裂训练和模型设计的一级类目。

10最小可运行代码：验证平移性质与数值 Jacobian

下面程序只依赖 Python 标准库，逐维使用总体方差（除以 D），对两个单子层函数做数值微分。它断言：在给定玩具分支下，Pre-LN 对全维相同平移保持等变，而 Post-LN 对这种平移不敏感；数值 Jacobian 的行和因此分别近似 1 和 0。

"""Minimal deterministic Pre-LN vs Post-LN experiment; standard library only.

This is NOT a paper benchmark and contains no attention or language model.
"""
from math import sqrt

EPS = 1e-5

def ln(xs, eps=EPS):
    mu = sum(xs) / len(xs)
    var = sum((v-mu)**2 for v in xs) / len(xs)
    return [(v-mu) / sqrt(var + eps) for v in xs]

def branch(xs):
    # Small linear, circularly coupled toy transformation.
    n = len(xs)
    return [0.2*xs[i] + 0.1*xs[(i+1) % n] for i in range(n)]

def pre_ln(xs):
    f = branch(ln(xs))
    return [x + fx for x,fx in zip(xs, f)]

def post_ln(xs):
    f = branch(xs)
    return ln([x + fx for x,fx in zip(xs, f)])

def jacobian(fun, x, h=1e-5):
    cols = []
    for k in range(len(x)):
        plus = x.copy(); minus = x.copy()
        plus[k] += h; minus[k] -= h
        cols.append([(a-b)/(2*h) for a,b in zip(fun(plus), fun(minus))])
    return list(map(list, zip(*cols)))

def check():
    x = [1.0, 2.0, 4.0, 6.0]
    shifted = [v+2.0 for v in x]
    pre0, pre1 = pre_ln(x), pre_ln(shifted)
    post0, post1 = post_ln(x), post_ln(shifted)
    # LN(v + c*1) = LN(v).  Hence Pre-LN preserves the shortcut shift.
    assert all(abs((b-a)-2.0) < 1e-8 for a,b in zip(pre0, pre1))
    # For this affine-free linear branch, Post-LN removes a uniform shift.
    assert all(abs(a-b) < 1e-8 for a,b in zip(post0, post1))
    jpre, jpost = jacobian(pre_ln,x), jacobian(post_ln,x)
    assert all(abs(sum(row)-1.0) < 1e-6 for row in jpre)
    assert all(abs(sum(row)) < 1e-6 for row in jpost)
    print("toy test passed; Pre-LN preserves constant shift, Post-LN removes it")

if __name__ == "__main__":
    check()

仓库文件：mini_norm.py（示例源码保存在 GitHub，站点本身只发布阅读页面）。可运行：python posts/architectures/pre-ln-vs-post-ln/mini_norm.py；独立测试见 tests/test_pre_post_ln.py。

和真实模型不同：真正的 F 包含 Attention / FFN、dropout、可学习参数与非线性，梯度还会与最终损失和 optimizer 耦合。因此数值微分测试只核对这段讲解的数学，不复现 ICML 的训练实验。

11工程实现时，究竟该检查什么？

  1. 核对 block 的精确 forward：x + F(norm(x)) 与 norm(x + F(x)) 不可互换；确认每个 Attention、MLP 子层的位置与 final norm。
  2. 不要只看名字：框架中的 norm_first、pre_norm 不一定涵盖所有残差缩放、并行分支、cross-attention 或额外 norm；读 forward 和 checkpoint 配置。
  3. 验证 LN 统计轴：标准 LayerNorm 在隐藏维归一化；同时检查 EPS、γ/β、RMSNorm、fp32 accumulate 与混合精度的实现差异。
  4. 记录训练初期的层级梯度与更新：记录 per-layer grad norm、参数更新比例、loss spikes，而非凭最终 loss 猜测是否需要 warm-up。
  5. 做公平对照：锁定数据、模型宽度/深度、batch、优化器、初始化与 token 预算，分离归一化位置和调度器的影响。

训练不稳定时，调整 LN 位置是一个结构选项，但也应审查学习率峰值、warm-up、初始化、残差缩放、数值溢出和梯度裁剪。不存在一条不依赖配方的万能切换规则。

12把它收束为三条可复用的判断

结构判断

Pre-LN 规范残差分支的输入；Post-LN 规范整个残差和的输出。

数学判断

Pre-LN 的局部 Jacobian 有显式 I；Post-LN 必经输出 LN。但这不是总网络梯度质量的判词。

证据判断

Xiong 解释初始化梯度与 warm-up；Liu 增加参数扰动放大这一视角。

工程判断

把 LN 位置、函数类别、残差缩放、初始化与优化调度当成需要共同检查的变量。
