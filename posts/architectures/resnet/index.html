Understanding
ResNet

如果网络越来越深，却越来越难训练，我们能不能让新增的层只负责“改变一点点”，而不是每次都从零开始？

01为什么更深，反而可能更差？

我们通常认为，更多层代表更强的表达能力：浅层学边缘，深层组合出纹理、部件和物体。照这个逻辑，34 层网络至少应该能模仿 18 层网络——让多出来的层什么也不做就行。

可是原始 ResNet 论文发现了一个反常现象：在可训练的实验设置中，加深普通网络不但没有降低测试错误率，甚至提高了训练错误率。这叫 degradation problem，即优化层面的“退化问题”。它不是简单的过拟合，也不能全部等同于梯度消失。[1]

关键问题于是变成：怎样保证新增的层即使暂时没学好，也不必破坏前面已经提取的信息？

02不要学习整个答案，只学习“差多少”

假设我们希望网络学习一个函数 H(x)。传统做法是让几层神经网络直接计算它。ResNet 换了一个目标：不直接让网络学整个 H(x)，而是学习它与输入之间的差值：

F(x)=H(x)−x
所以H(x)=x+F(x)

一个容易理解的类比是修改文档：我们不必每次重写整篇文章，只要保留旧稿，再提交一份“修改意见”。如果不需要修改，就提交空修改。

恒等映射（Identity Mapping）就是 H(x)=x。在残差形式里，如果残差分支得到 F(x)=0，那么相加之前的输出恰好是 x。这让“什么也不改变”变成一个自然选项。

03逐步拆开一个 Residual Block

和 Colah 文章逐步点亮 LSTM 门控结构一样，我们从最简单的残差块开始。下面是一种经典的 ResNet v1 基本块（Basic Block）：主分支经过两层卷积，捷径分支保留输入，之后相加并通过 ReLU。

相加究竟是什么意思？

它不是把两个张量拼接成更多通道，而是将相同位置、相同通道的数一一相加。

04为什么这条捷径有利于反向传播？

为了先看清关键数学结构，暂时忽略块末尾的 ReLU，并假设捷径是真正的恒等映射：

y=x+F(x;W)
对 x 求导：∂y∂x=I+JF(x)

使用链式法则，损失梯度中会出现来自 恒等路径的单位项 I，以及来自残差分支的雅可比矩阵 JF：

∇xL=(I+JF(x))T∇yL

可以把它理解为：梯度不必完全依靠一长串卷积层的乘积才能传回去。它有一条更直接的通道。

重要严谨性提醒：原始 ResNet v1 在加法后还有 ReLU，因此上述 I+JF 不是 v1 全部路径的完整导数。2016 年的 Identity Mappings 论文特别强调：当捷径和加法后的映射都接近恒等传递时，直接传播路径更清楚。这也是后来 pre-activation ResNet v2 的理论动机。[2]

05如果张量尺寸不一样，怎么相加？

在同一个 stage 内，输入与输出尺寸一致，可以直接 identity shortcut。但进入下一个 stage 时，网络经常一边减少空间分辨率，一边增加通道数。

例如 56×56×64 变成 28×28×128：如果捷径仍然原样输出旧尺寸，两个张量便不能相加。

y=F(x;W)+Wsx
当维度不匹配，Ws 可以用 1×1 卷积实现

06两种最重要的残差块

ResNet-18 和 ResNet-34 常采用两层 3×3 卷积的 Basic Block。ResNet-50、101、152 则使用三层卷积的 Bottleneck（瓶颈块）：先压缩通道，再做 3×3 卷积，最后恢复通道。

瓶颈块的意义并不是“压得越窄越好”，而是让计算量最大的空间卷积发生在较窄的通道上，使更深的网络具有可接受的计算成本。

07从残差块搭建整个 ResNet-50

现在我们已经理解最小单元，可以像搭积木一样，把它们连接成整张网络。标准的 ImageNet ResNet-50 在 stem 之后有四个 stage，Bottleneck 块数分别为 3、4、6、3。

08ResNet v1 和 v2 究竟不同在哪里？

如果你读过不同文章，很可能见过两张不一样的 ResNet block 图片。它们不一定谁画错了：最常见的原因，是一张在讲 ResNet v1（post-activation），另一张在讲 ResNet v2（pre-activation）。

这里很像 Colah 那篇文章中解释不同 LSTM 变体的方式：不是死记一张图，而是问哪条信息通路保持简单，哪部分负责可学习的变换。

09证据说明了什么？又没有证明什么？

原论文有三层论证。第一，深层普通网络出现训练退化；第二，保持相近深度和参数量，加入残差连接后更易优化；第三，Bottleneck 结构使更深的网络可以在合理计算成本下获得更低错误率。[1]

不要把结果读得过头。ResNet 并不保证网络越深越好，也不保证梯度一定不消失；2015 年的 CIFAR-10 结果里，1202 层网络的测试表现还不如 110 层网络，论文认为过拟合是可能原因。[1]

另外，历史上常见的“3.57% Top-5 error”是 ILSVRC 2015 ResNet 模型集成的测试集结果，而不是任意单个 ResNet-152 的结果。

10用 PyTorch 写出最小的 ResNet v1 残差块

现在你可以把上面的图几乎逐行翻译成代码。理解时请重点看 identity = self.shortcut(x)、out = out + identity 两行：它们就是捷径连接的本质。

import torch
from torch import nn

class BasicBlock(nn.Module):
    def __init__(self, in_ch, out_ch, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_ch, out_ch, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_ch)
        self.relu = nn.ReLU(inplace=True)
        self.conv2 = nn.Conv2d(out_ch, out_ch, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_ch)

        if stride == 1 and in_ch == out_ch:
            self.shortcut = nn.Identity()
        else:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_ch, out_ch, 1, stride, bias=False),
                nn.BatchNorm2d(out_ch),
            )

    def forward(self, x):
        identity = self.shortcut(x)       # 路径一：保留 / 对齐输入
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))  # 路径二：学习 F(x)
        out = out + identity            # 核心：逐元素加法
        return self.relu(out)           # v1 的后激活

# 相同尺寸：不需要投影
block = BasicBlock(64, 64)
x = torch.randn(2, 64, 56, 56)
assert block(x).shape == (2, 64, 56, 56)

# 下采样且通道改变：使用 1×1 投影
block_down = BasicBlock(64, 128, stride=2)
assert block_down(x).shape == (2, 128, 28, 28)

这是教育用途的 BasicBlock 代码，并非完整 ResNet-50；后者还要实现 Bottleneck、分 stage 组装、stem、GAP 和分类头。

11把 ResNet 记成四句话

① 问题：深度退化

网络容量更大，不代表优化器必然能找到更好的训练解。

② 思想：学习修正量

把直接学习 H(x) 改写成学习 F(x)=H(x)−x。

③ 结构：x + F(x)

一条恒等捷径保留原特征，另一条卷积支路学习变化。

④ 效果：更易优化深层模型

梯度获得直接路径的贡献，Bottleneck 帮助控制计算成本。

ResNet 的重要性，不仅在于把网络从几十层推向上百层，还在于它改变了我们设计深层网络的方式：让信息有路可走，让新增层专注于修改。
