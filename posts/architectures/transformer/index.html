Understanding
Transformer

我们已经有了能记住过去的 LSTM。为什么后来还需要一种不按时间步传递隐藏状态、而是让每个词直接“看向”其他词的网络？

Attention(Q,K,V)=softmax(QKTdk)V
这里先展示最基本的无 Mask 形式；稍后再引入因果 Mask 与多头结构。

01首先，为什么要从 LSTM 走向 Transformer？

人读句子时，不会在每个字出现后都把之前的理解全部清零。Colah 的 LSTM 文章用“记忆如何延续”开始讲解：RNN 沿时间更新隐藏状态，LSTM 借助门控结构改善长期依赖。

但循环结构还存在另一个限制：在单一方向的 RNN/LSTM 里，第 5 步的隐藏状态需要依赖第 4 步的结果。这使同一层的时间步计算存在顺序依赖，也可能让遥远位置之间的信息经过很多次状态更新。

Transformer 的办法不是继续优化这条链，而是改变信息流动的方式：在同一层 Self-Attention 中，多个位置可以同时计算各自应该读取其他哪些位置的信息。对标准全注意力来说，两个任意位置可在同一注意力层内建立直接交互。

重要边界：“同一层并行”不等于“生成答案时全部 token 并行”。原始 Encoder–Decoder Transformer 的 Decoder 在推理时仍然逐步生成目标 token；具体见第 13 节。

02Self-Attention 到底在做什么？

考虑一句话：

“书包里放着一本书，它很厚。”

我们看到“它”时，会从前面的词中寻找有助于理解“它”的信息。这里“书”是更相关的候选，而不是仅仅取“它”的前一个词作为全部上下文。

但模型不会直接存储一张固定的“它 → 书”指代词典。它会根据当前层的输入向量，计算每个位置与其他位置之间的匹配分数，将分数转成权重，再将被读取位置的信息加权组合。

于是每个 token 经过注意力后，会得到一个融合了上下文的新向量表示。这里强调的是信息混合机制，而不是宣称注意力权重天然等于人类可解释的语法关系。

03Q、K、V：三个看起来抽象，其实非常清楚的角色

假设输入是一个包含 n 个 token 的矩阵 X ∈ ℝn×d_model。网络利用三组不同的可学习权重，从输入生成查询向量 Q、键向量 K 和值向量 V：

Q=XWQK=XWKV=XWV
Query · Q

我现在要找什么？每个查询位置发起一次信息检索。

Key · K

我和这个查询匹配吗？Key 被拿来和 Q 比较。

Value · V

匹配后提供什么内容？最后被注意力权重加权求和。

可以把它类比为数据库检索：Q 是查询条件，K 是可匹配的索引特征，V 是被取回的信息。不过这只是记忆类比；真实 Q/K/V 是连续向量，既不要求为人工词义，也不保证一个头只做一种语法任务。

04一步一步拆解 Transformer 的核心公式

对于一个注意力头，假定 Q ∈ ℝn_q×d_k、K ∈ ℝn_k×d_k、V ∈ ℝn_k×d_v。计算过程如下：

① QKT：比较谁与谁相关

将每个查询向量与所有 Key 向量做点积，得到 n_q × n_k 的分数矩阵。注意：点积是可学习投影后的相似度，不是原始词向量的固定相似度。

② 除以 √dk：控制分数尺度

当向量维度增大时，未缩放点积的数值幅度可能变大，让 Softmax 太尖锐、梯度较小。原论文用 1 / √d_k 对分数进行缩放。

③ Mask：让不可读取的位置失效

在需要遮挡的位置，把分数加上一个足够大的负数（数学上记为 −∞）。这样 Softmax 后这些位置的注意力权重为 0。Encoder 典型情况下不需要因果遮罩，Decoder 自注意力需要。

④ Softmax：每一行变成权重分布

对每一个 Query 的 Key 分数沿最后一维 Softmax，得到非负、每行求和为 1 的注意力权重。训练中如果对权重施加 dropout，则 dropout 后的行和不再必然为 1。

⑤ 加权 V：真正合成新特征

将注意力权重矩阵乘以 V。注意 Q/K 负责算权重，V 才是被加权汇总的内容。每个 Query 输出一个 d_v 维向量。

Attention(Q,K,V)=softmax((QKTdk)+M)V
M 的允许位置为 0，禁止位置为 −∞；无须 Mask 时直接去掉 M。

05不靠比喻：手算一遍 3 个 Key 的注意力

我们用一个只有两维的小例子，省略 WQ、WK、WV 的投影训练过程，只观察注意力计算本身：

一个 Query

Q = [1, 0]
K₁ = [1, 0]
K₂ = [0, 1]
K₃ = [1, 1]

三个 Value

V₁ = [1, 0]
V₂ = [0, 1]
V₃ = [1, 1]

第一步，点积得分为 [1, 0, 1]。第二步，除以 √2，得到约 [0.707, 0, 0.707]。第三步，对三个得分进行 Softmax：

α≈[0.4011,0.1978,0.4011]

最后求和：

0.4011[1,0]+0.1978[0,1]+0.4011[1,1]
≈ [0.8022, 0.5989]，就是当前 Query 通过这个注意力头获得的新表示。

这里最值得注意的是，模型不是选出“最相关的一个词”就结束，而是以可微的权重组合多个 Value；训练时可通过反向传播更新 Q/K/V 投影。

07为什么一个注意力头不够？

一个头只有一组 Q/K/V 投影，它可以为每个位置构建一组注意力权重。多头注意力让网络在不同的投影子空间里并行计算多组注意力，再拼接结果并投影回模型维度。

headi=Attention(QWiQ,KWiK,VWiV)
MultiHead(Q,K,V)=Concat(head1,…,headh)Wᴼ

原始 Transformer base 使用 dmodel = 512、h = 8，每个头的 Q/K 与 V 维度均为 64。8 个头拼接后为 512 维，再经 WO 做一次输出线性变换。

不同头可以学到不同模式，但不要把“Head 1 一定理解主语、Head 2 一定理解宾语”当成模型的硬编码规则；它们是否形成特定功能是训练中涌现、也可能彼此冗余的现象。

08Mask：解码时为什么不能偷看未来？

假如我们训练网络根据“我 喜欢”预测“学习”，如果预测“学习”时直接让该位置读取未来目标词“学习”，模型就可能在训练时作弊。为维持自回归建模，Decoder 的 Self-Attention 必须阻断未来位置。

因果 Mask 在分数矩阵的上三角位置施加 −∞（对角线本身允许），使第 i 个输出位置只能注意到当前位置和之前的目标位置。

另一个概念是 Padding Mask：同一批句子长度不同，通常会补齐到相同长度。Padding Mask 负责不让注意力读取这些人为补齐的 Key；它可以与因果 Mask 同时使用。

09没有循环结构，模型怎么知道顺序？

“狗咬人”和“人咬狗”的 token 集合可以相同，但顺序改变了意思。没有位置信息时，标准全 Self-Attention 的关系计算具有置换等变性质：如果同步打乱输入顺序，输出也会相应打乱，它本身没有固定的绝对序列位置感。

原始论文把位置向量 加到词嵌入向量上，而不是按通道拼接。它选用不同频率的正弦与余弦函数：

PE(pos,2i)=sin(pos100002idmodel)
PE(pos,2i+1)=cos(pos100002idmodel)

这里 pos 是位置，i 是一对特征维度的索引。这种设计可以为不同位置提供有规律、可计算的位置特征。后来的 Transformer 变体也可能使用可学习位置嵌入、相对位置偏置、RoPE 等方式；它们不属于 2017 原始结构的同一套固定配置。

10Encoder Layer：信息如何混合，如何保留？

一个 Encoder Layer 包含两个主要子层：Multi-Head Self-Attention 与逐位置的 Feed-Forward Network（FFN）。每个子层之外还有残差连接与 Layer Normalization。

如果你刚学完 ResNet，会发现这里也出现了 x + F(x)：注意力和 FFN 都不是粗暴替换之前的表示，而是先添加残差，再进行归一化。

z=LayerNorm(x+Sublayer(x))
这是原论文的 Post-LN 表述；原论文对 Sublayer 输出还使用 dropout。

FFN 和注意力分工不同：注意力让不同 token 之间交换信息；FFN 通常在每个 token 的特征维度上完成非线性变换。原始 FFN 的结构为：

FFN(x)=max(0,xW1+b1)W2+b2
原始 base 模型中 512 → 2048 → 512；相同一层的所有位置共享 FFN 参数，不同层参数不同。

Post-LN / Pre-LN 不要混淆。2017 原论文给出 LayerNorm(x + Sublayer(x))（Post-LN）。很多后来的训练实现改用 x + Sublayer(LayerNorm(x))（Pre-LN）。本教程主体以原论文为准，示例代码也采用 Post-LN。

11Decoder：多出来的 Cross-Attention 到底做什么？

在原始机器翻译模型中，Encoder 处理源句，Decoder 负责逐步生成目标句。Decoder Layer 相比 Encoder 多了一个Encoder–Decoder Cross-Attention 子层。

Masked Self-Attention

Q/K/V 均来自 Decoder 侧的当前表示；Mask 防止看未来目标词。

Cross-Attention

Q 来自 Decoder，K、V 来自 Encoder 的输出。因此生成每个目标词时，可以检索源句信息。

例如翻译时，Decoder 为正在预测的目标词构造 Query，然后利用 Encoder 输出的 Key/Value 去读取源句中相关位置的表示。Cross-Attention 不是“第二次 Decoder 自注意力”，数据来源不同。

12把零件组装：原始 Transformer 完整架构

现在我们可以把整张“Attention Is All You Need”的经典架构图读懂了。左边 Encoder 将源句编码为上下文表示；右边 Decoder 接收右移后的目标序列，并利用 Encoder 的表示预测下一个词。

组件原始 Transformer base在模型中的作用
Encoder layers6编码源序列
Decoder layers6生成目标序列
dmodel512各子层输入输出的主表示维度
Attention heads8不同投影子空间的注意力
dk, dv64, 64（每头）Q/K/V 的单头维度
dff2048逐位置 FFN 隐藏维度
归一化Post-LN残差相加后执行 LayerNorm

这套原始设计不是今天所有 Transformer 的通用模板。Encoder-only（如 BERT）主要通过双向编码获得表征；Decoder-only（如 GPT 系列）常使用因果自注意力进行语言建模；Encoder–Decoder（如 T5）保留了两侧结构。具体模型还可能改变位置编码、归一化和 FFN 等实现。

13训练时并行，生成时为什么仍要逐词？

训练原始 Transformer 的 Decoder 时，通常提供真实目标序列的右移版本作为输入（Teacher Forcing），使用因果 Mask 防止看到未来目标词。因为训练时整段目标已知，可以同时计算许多位置的下一词损失。

例如目标为 我 爱 你 <EOS>，Decoder 输入是 <BOS> 我 爱 你；在同一次训练前向计算中，分别预测上述四个目标位置。

但推理时，我们不知道后面正确的词，只能从 <BOS> 开始，先预测第一个词，再把它送回模型预测第二个词，依次继续。实际工程会缓存先前位置的 K/V（KV cache），避免每次重复计算全部历史 Key/Value，但不会让尚未生成的未来 token 突然已知。

14Transformer 更强，也有代价

Transformer 的重要优势是摆脱逐时间步的循环依赖，允许同一层的大规模矩阵并行操作，也让远距离 token 在一层注意力里直接建立交互。然而标准全注意力在序列长度 n 上形成 n × n 的注意力分数。

维度RNN / LSTM（一般形式）标准全 Self-Attention
同层位置计算单向循环存在时间步依赖多位置可并行计算
远距离通信路径需跨越多个时间步单层即可建立直接交互
序列长度相关代价按时间步递增，依赖隐藏维度注意力分数数量为 O(n²)
长序列时并行度受循环依赖限制标准全注意力计算 / 存储可能昂贵

需要细分几个容易混淆的结论：O(n²)是标准稠密注意力中所有 query–key 对的规模，完整层的计算复杂度还取决于维度与投影；FlashAttention 等改进可以减少对显式 n × n 矩阵的内存读写，但并不意味着普通全注意力的所有成对关系计算自动变成线性时间。

四个常见误解

“注意力权重 = 解释”

权重描述信息聚合，不能直接等同因果归因或自然语言解释。

“Transformer 完全没有顺序”

注意力核心没有时间步递归，但位置编码、因果遮罩和生成过程都涉及顺序。

“Q、K、V 是 3 类 token”

它们通常是同一输入经不同投影得到的向量，不是人工标注的 token 类型。

“所有 Transformer 都有双塔”

双塔是 2017 年经典 Encoder–Decoder 结构；许多现代模型只有其中一侧。

15用 PyTorch 写出最小 Multi-Head Attention

下面的片段还原前文核心结构：Q/K/V 线性投影、拆分 heads、缩放点积、Mask、Softmax、加权 V、拼接与输出投影。它没有假装自己是一个完整 GPT 或原始 Transformer，而是容易核验的教学用核心组件。

import math
import torch
from torch import nn

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model: int = 512, heads: int = 8):
        super().__init__()
        if d_model % heads:
            raise ValueError("d_model must be divisible by heads")
        self.heads = heads
        self.d_head = d_model // heads
        self.q_proj = nn.Linear(d_model, d_model)
        self.k_proj = nn.Linear(d_model, d_model)
        self.v_proj = nn.Linear(d_model, d_model)
        self.out_proj = nn.Linear(d_model, d_model)

    def _split(self, tensor: torch.Tensor) -> torch.Tensor:
        batch, length, _ = tensor.shape
        return tensor.reshape(batch, length, self.heads, self.d_head).transpose(1, 2)

    def forward(self, query, key, value, allowed=None):
        """query [B,Lq,D], key/value [B,Lk,D]

        allowed: 可选 bool mask，可广播为 [B,H,Lq,Lk]。
        此教学版本要求每个 Query 至少允许一个 Key，以免 softmax(-inf,...,-inf) 得 NaN。
        """
        q = self._split(self.q_proj(query))
        k = self._split(self.k_proj(key))
        v = self._split(self.v_proj(value))
        logits = (q @ k.transpose(-2, -1)) / math.sqrt(self.d_head)
        if allowed is not None:
            if allowed.dtype != torch.bool:
                raise TypeError("allowed must be a bool tensor")
            logits = logits.masked_fill(~allowed, float("-inf"))
        weights = torch.softmax(logits, dim=-1)
        context = weights @ v
        batch, _, length, _ = context.shape
        context = context.transpose(1, 2).contiguous().reshape(batch, length, -1)
        return self.out_proj(context), weights


def causal_mask(length, device=None):
    """形状 [1,1,L,L]，True 表示允许当前位置读取该 Key。"""
    return torch.ones(length, length, dtype=torch.bool, device=device).tril()[None, None]

代码与最小测试也作为 mini_attention.py 文件收入压缩包；可以运行 python mini_attention.py 来检查形状、行归一化与因果 Mask。

16最后，把 Transformer 记住

① 核心问题

如何让一个词直接汇集上下文信息，同时降低同层逐时间步的顺序依赖？

② 核心机制

Q 和 K 算匹配；Softmax 得权重；对 V 加权求和得到新特征。

③ 核心结构

Multi-Head Attention + FFN + 残差 + LayerNorm + 位置信息。

④ 核心分工

Encoder 双向理解输入；Decoder 屏蔽未来，并通过 Cross-Attention 读取源序列。

ResNet 的捷径让信息有路可走；LSTM 的门控让记忆能够延续；Transformer 的注意力让不同位置之间直接交换信息。
