Understanding Decision Tree

为什么一连串简单的「是 / 否」能形成复杂的预测器？从 ID3、CART、C4.5 的不同选择出发，推导 Gini、熵、连续阈值、回归与剪枝。

论文主线 · 1984 → 1986 → 1993预计阅读 29 分钟分类 · 回归 · 泛化

01 · 为什么一个规则不够？

让机器判断一台设备是否有故障。只问「温度是否超过 70°C？」太粗糙：有些低温故障会漏掉，有些高温工作却完全正常。决策树的核心想法是：先问一个最有区分力的问题，再让不同答案进入不同的后续问题。

下面的设备故事与可视化均为独立设计的教学示意，并非历史论文的工业实验。

一棵树可解释，不意味着它自动泛化。把训练样本分对只是起点；复杂度控制和验证数据同样重要。

02 · 一次递归分裂，到底做了什么？

数据

输入表 X 的形状是 [N,d]，N 为样本数、d 为特征数。分类标签 y 有 N 个类别值，回归标签是 N 个实数。

寻找规则

在当前节点的样本里搜索特征与候选阈值，选择使分裂后加权不纯度最小的候选。这个局部选择是贪心的。

继续生长

递归处理每个子节点，直到达到纯节点、最大深度、最小叶样本数等停止条件。

预测

新样本沿决策路径到达一个叶。分类叶输出类别或叶内类别频率；回归叶通常输出目标均值。

03 · 数学上的「纯」是什么？

令 pₖ 表示某节点中类别 k 的比例。所有样本标签都相同时，纯度最高；两类各半时不确定性最大。常用的两个量是熵和 Gini，它们都只描述当前节点的标签分布。

分类熵(1)
H(D)=−∑k=1Kpklog2pk

信息熵以 bit 计，约定 0 log₂ 0 = 0。原始 ID3 通过熵差挑选属性；其思想可追溯到信息理论。

Gini 不纯度(3)
G(D)=1−∑k=1Kpk2=2p(1−p)

对于二分类，Gini = 2p(1−p)，当 p=0 或 p=1 时为 0，当 p=0.5 时为 0.5。它与熵不必在所有数据上选出相同分裂。

04 · ID3：先消除最多的信息不确定性

Quinlan (1986), Induction of Decision Trees 描述 ID3：把每个离散属性的可能取值作为分支，比较分裂后各分支的加权熵，选择信息增益最大的属性。

信息增益(2)
IG(D,A)=H(D)−∑v∈Values(A)|Dv||D|H(Dv)

D 是当前样本集；A 为候选离散属性；Dᵥ 是属性取值 v 的子集。注意 |Dᵥ|/|D| 不可省略：100 个样本的子集与 1 个样本的子集不应拥有相同权重。

Quinlan 原文 §4 的打网球示例中，父节点熵约 0.940 bit，以 outlook 分裂的信息增益约 0.246 bit。这是论文中的属性选择演算，不是本篇设备或一维玩具数据的结果。

ID3 的信息增益倾向于偏爱取值很多的离散属性：给每个训练样本一个唯一编号可以让训练叶非常纯，但几乎没有可推广的规律。

从 ID3 到 C4.5：为什么增益率不只是信息增益？

Quinlan (1993) 的 C4.5 将信息增益与属性取值引起的分支分布结合，改善对高基数离散属性的偏好，同时扩展到连续特征与剪枝。设 qᵥ 为属性 A 取值 v 的样本比例，分裂信息是各分支权重分布的熵。

C4.5：增益率与分裂信息(2a)
GainRatio(D,A)=IG(D,A)SplitInfo(D,A)SplitInfo(D,A)=−∑vqvlog2qv,qv=|Dv||D|

当 SplitInfo 很小甚至为零时，直接取比例是不稳定或未定义的；C4.5 的实际候选属性筛选和连续阈值策略还有额外约束。Quinlan (1996) 进一步修正了连续属性的选择偏差。因此上式解释核心度量，不等于完整 C4.5 训练算法。

05 · CART：一次 Gini 分裂的完整手算

与 ID3 的离散多路分支不同，Breiman 等人的 CART 专著（1984） 展开了二叉分类与回归树的方法。现代常见的 CART 式分类树以左右子节点的加权 Gini 衡量切分。

加权不纯度下降(4)
ΔG=G(D)−nLnG(DL)−nRnG(DR)

本篇自行构造 8 个样本 x=[1,2,3,4,5,6,7,8]，y=[0,0,1,0,1,1,1,1]，父节点正负例数量为 5/3，Gini = 0.46875。在 t=4.5 处分裂后，左子节点为 1 正 / 3 负（Gini 0.375），右子节点为 4 正 / 0 负（Gini 0）。

左分支 x ≤ 4.5

4/8 × 0.375 = 0.1875

右分支 x > 4.5

4/8 × 0 = 0

加权 Gini 为 0.1875；下降为 0.46875−0.1875=0.28125。这里所有数字都是公开的教学数据算出来的，不是 CART 原书的 benchmark。

06 · 连续值的阈值为何选在相邻样本中间？

对一个数值特征，先对当前节点样本排序。只要阈值没跨过任何观测值，切分后的左右成员就不变，因此可枚举相邻不同取值的中点作为候选。

数值特征阈值候选(5)
ti=xi+xi+12

这里 xᵢ 表示按升序排列后参与测试的相邻不同取值。对于 d 个特征，就针对每个允许的特征检索候选，再比较不纯度下降。数据量、样本权重、相同取值以及缺失数据的特殊路由都会影响工程实现。

标准 CART 式分裂形如 xⱼ ≤ t 与 xⱼ > t；这与原始 ID3 对离散属性逐取值分支不是完全相同的训练算法。

07 · 回归树：叶节点从投票改成预测均值

如果要预测温度、电量或连续风险评分，类别频率便不足以表达目标。常见的平方误差回归树用叶内目标均值预测，搜索让两侧平方误差之和最小的切分。

回归叶均值与平方误差(6)
ŷleaf=∑i∈leafyinleaf;SSE=∑i∈leaf(yi−ŷleaf)2

四个教学观测 (x,y)=(1,2),(2,2),(3,8),(4,8) 的父节点均值为 5，平方误差和 SSE 为 36；按 2.5 切分后，两侧均值是 2 和 8，SSE 为 0。这仅说明样本可被完美拟合，绝非真实测试误差保证。

08 · 为什么叶子越多，不代表模型越好？

生长一棵大树会不断降低训练集不纯度，也可能把偶然噪声做成规则。预剪枝用最大深度、最小叶样本数等限制生长；后剪枝先长树，再移除收益不足的子树。

代价复杂度剪枝（现代加权不纯度形式）(7)
Rα(T)=∑ℓ∈Leaves(T) nℓNG(Dℓ)+α|Leaves(T)|

这里 Rα(T) 采用现代 scikit-learn 文档所述的叶节点样本加权不纯度目标（以 Gini 为例），不是声称 CART 1984 原书所有风险定义完全等同。N 为训练样本总数，nℓ 为叶样本数，α≥0 为复杂度成本；α 越大，越鼓励更少的叶。

对刚才的两种候选树：不分裂时加权 Gini 为 0.46875，叶数 1；只保留根阈值 4.5 分裂时加权 Gini 为 0.1875，叶数 2。两者在 α=0.28125 时目标相等。这只是两棵玩具候选树的相等点，而非真实大树的完整 weakest-link 路径。

09 · 自己移动阈值：哪一刀最好？

让根节点阈值从 1.5 滑动到 7.5。比较两侧纯度时，必须乘上各侧样本比例；不能只看到一边“非常纯”就认定整次分裂最佳。

使用滑块方向键，或点击下面的候选阈值。此处只演示一层二叉切分。

切分后加权 Gini（越低越好）0.18750.1875
相对父节点 Gini 的下降（越高越好）0.28130.2813
左侧：1 正 / 3 负；右侧：4 正 / 0 负；加权 Gini = 0.1875；下降 = 0.2813（本例最佳）。

左节点 4 个样本，右节点 4 个样本。加权 Gini = (4/8 × 0.375) + (4/8 × 0) = 0.1875；父节点 Gini = 0.46875。

先点 2.5，再点 5.5：即使某侧“很纯”，也要考虑该侧人数所占比例。最后用「自动找最优」对照。

10 · 可以运行、可以质疑的最小 Python

仓库中的 mini_decision_tree.py 仅依赖 Python 3.11+ 标准库：它枚举一维切分，计算分类 Gini / 熵、回归 SSE 和剪枝成本。它是教学用 decision stump，不是 ID3、C4.5 或完整 CART 实现。

x = [1, 2, 3, 4, 5, 6, 7, 8]

assert model["threshold"] == 4.5

11 · 论文与实现：三条不同路线

1984 · CART

Breiman、Friedman、Olshen、Stone，Classification and Regression Trees：分类 / 回归二叉树、风险与剪枝的经典方法体系。本文不臆造其表格指标。

1986 · ID3

Quinlan，Induction of Decision Trees，Machine Learning 1:81–106：用信息增益进行离散属性选择，并讨论噪声和不完整样本。

1993 · C4.5

Quinlan，C4.5: Programs for Machine Learning：相对 ID3 扩展连续属性处理、增益率和剪枝。增益率涉及对高基数属性的偏好校正，简单“信息增益除分裂熵”不是完整实现，须处理候选选择与极小分母。

1996 · 改进

Quinlan，Improved Use of Continuous Attributes in C4.5，JAIR 4:77–90：针对数值属性分裂选择偏差提出修改。

现代实现

scikit-learn User Guide：CART 风格、Gini/entropy/log_loss、复杂度控制与工程限制；不能把其版本特性倒写成 1980 年代原论文默认行为。

12 · 哪些地方最容易误用？

  • 轴对齐边界：常见单特征阈值产生阶梯状区域；要表达斜向几何边界可能需要更多结点。
  • 类别、缺失与未知值：并非所有实现自动支持原生类别和 NaN。实际处理依赖算法、库版本、编码与数据泄露约束。
  • 深树过拟合：训练误差下降不代表独立数据误差下降；剪枝与交叉验证需要训练集外的数据。
  • 叶节点频率不是已校准概率：少样本叶尤其不稳定；重要的概率决策仍应验证校准与错判成本。
  • 单树不同于森林或 boosting：随机森林与梯度提升树会以集成机制改变方差、偏差与训练流程，不能把集成效果算到单树上。

作为经典基线，树能把非线性特征交互变成规则路径。但解释性不是免于质疑的通行证，必须核对训练划分、时间泄露、少数类错误和分布漂移。

13 · 把决策树压缩成一条思考链

提一个问题 → 衡量分裂前后的混杂 → 逐层递归 → 叶上做分类或回归 → 验证与剪枝控制复杂度。

回到最初的困惑：一连串简单的判断为什么有用？因为每个判断都改变下一步面对的数据子集；但局部“更纯”并不自动意味着未来数据上的预测更可靠。
