Understanding K-Means

为什么只做两件事——找最近的中心、重新求平均——就能发现数据中的簇？从 Lloyd 的交替最小化到 k-means++，把算法、数学与失效条件连成一条可计算的路径。

论文脉络 · 1967 / 1982 / 2007预计阅读 29 分钟无监督学习 · 聚类与向量量化

01 · 没有标签，如何发现结构？

想象有数百个二维点，却没有任何类别标签。你肉眼会看到几团密集的点：如果必须用 k 个代表位置概括整张图，你会把代表放在哪里？K-Means 的答案很直接：让所有点都找到最近的代表，并尽量缩短它们到代表的平方距离。

K-Means 是一个无监督划分方法：输入是样本矩阵 X，形状为 n × d，另给定簇数 k；输出为每个样本的簇编号和 k 个 d 维质心。它并不自动给簇贴上“猫”“狗”等语义标签，也不在训练时估计类别的概率。

历史上需要分清多个脉络：MacQueen（1967）讨论 k-means 方法与在线均值更新；Lloyd（1982；工作早于发表）从最小平方量化研究最近邻区域与质心条件；Arthur 与 Vassilvitskii（2007）提出 k-means++ 初始化。三者不能混同为同一篇论文。

02 · 真正被优化的是什么？

先不要把目标理解成“看起来分得像”。算法优化的是簇内平方和（within-cluster sum of squares，常称 inertia）。这与 k-median 最小化距离和、k-medoids 以样本作代表，是不同的目标。

平方距离和 / Inertia(1)
J(z,μ)=∑i=1n‖xi−μzi‖2

样本 xᵢ ∈ ℝᵈ；zᵢ ∈ {1,…,k} 表示簇分配；μⱼ ∈ ℝᵈ 表示第 j 个质心。这里使用平方欧氏距离，不是到质心距离的简单求和。

目标同时包含两组未知量：离散的标签 z 和连续的质心 μ。联合寻找全局最优一般困难；但若固定其中一组，另一组却很容易更新。这就是交替最小化的入口。

固定中心，优化分配

每个点独立找最近中心；这一步是“最近邻”，不会改变中心。

固定分配，优化中心

每个非空簇内部重新求算术平均；更新不是取最远点，也不是取中位数。

03 · Lloyd 算法：分配 → 更新 → 重复

分配步 / Assignment(2)
zi←argmin1≤j≤k‖xi−μj‖2

固定 μ 时，每个点可独立选择最近质心，平局需使用确定性规则。距离平方不改变最近中心的排序。

更新步 / Centroid update(3)
μj←∑i∈Cjxi|Cj|

其中 Cⱼ = {i : zᵢ = j}，且要求簇非空。对每一维分别求偏导并令其为零，即得到样本均值。

  1. 选择 k 个初始中心，或由改进的初始化算法生成。
  2. Assignment：固定当前中心，为每个数据点计算到 k 个中心的平方距离，按最小值分配。
  3. Update：固定这些分配，将每个非空簇的中心移到簇内样本平均位置。
  4. 若分配不再变化、中心移动足够小，或达到迭代上限，则停止；否则返回第二步。

关于空簇：若某个中心没有样本，均值公式的分母为零。实现必须明确处理策略：保持旧位置、重置到某个样本，或采用库的重分配逻辑。本篇教学代码选“保留旧中心”，不声称与 scikit-learn 的细节相同。

04 · 为什么更新中心一定是求平均？

固定某一个非空簇 Cⱼ，考察其中一维的平方误差：对 μⱼ 求导，得到负二倍的每个坐标残差之和；令导数为零，便有“样本值求和 ÷ 样本数量”。多维情况逐坐标成立，所以几何上的最佳平方误差中心就是算术均值。

从偏导数到均值(6)
∂J∂μj=2∑i∈Cj(μj−xi)=0

J 对 μⱼ 的 Hessian 为 2|Cⱼ| I，非空簇上严格正定，因此求得的是该子问题的唯一极小点。

这也解释了“为什么必须平方”：如果改成绝对值误差或欧氏距离和，最优中心一般不再是算术平均。K-Means 的更新规则与目标函数是一对，不能随意更换其中一半。

05 · 四个数字，手算一次完整收敛

考虑一维训练集 X = [0, 2, 8, 10]，令 k = 2，初始中心 (0, 2)，最近邻平局时选择编号较小的中心。这是独立设计的教学算例，不是某篇论文报告的 benchmark。

阶段中心成员J
初值 / 分配(0, 2){0} / {2, 8, 10}100
求均值(0, 20/3)分配保持不变104/3
重新分配(0, 20/3){0, 2} / {8, 10}152/9
再求均值(1, 9){0, 2} / {8, 10}4

最初的损失为 0² + 0² + 6² + 8² = 100。第一次更新使右簇的均值变为 20/3；随后点 2 改派左簇；下一次均值为 1 与 9，总平方误差为 1 + 1 + 1 + 1 = 4。分配步与更新步都不能增加同一个目标 J。

07 · 初始化不是小事：k-means++

如果随机选中的两个初始中心恰好挤在同一团点里，Lloyd 迭代可能收敛到较差的局部解。2007 年的 k-means++ 改变的是初始化，不是分配—更新的主体过程。

核心思路是：先均匀随机选一个中心，然后对每个候选点计算其到“当前最近已选中心”的距离 D(x)，按 D(x)² 成比例抽取下一个中心，直至选满 k 个，再运行 Lloyd。

k-means++ 的 D² 采样(4)
P(x)=D2(x)∑y∈XD2(y)

D(x) = min₍c∈已选中心₎ ‖x − c‖₂；按距离平方随机采样而非确定性挑选最远样本。

原论文证明的是期望近似质量的对数级保证：在其无附加数据分布假设的设置下，初始聚类目标的期望值具有 O(log k) 的近似因子；这不表示每次随机初始化都得到全局最优。现代 scikit-learn 使用的还是 greedy k-means++ 的实用改型：每轮尝试多个候选，再挑局部最有利者，不能简单写成原论文的逐点单次采样。[实现说明]

08 · 单调下降，为什么不代表全局最优？

每次“分配”在固定中心下取最近邻，每次“更新”在固定分配下取均值，因此 J 单调不增。对有限数据、固定平局规则、无额外重置的标准情形，可能的分配数有限，算法通常会到达不再改派样本的固定点。

但 J 对 z 与 μ 并不联合凸，不同初始化可能落入不同固定点。即使每次都严格完成了这两个子步骤，也只能得出局部稳定，而不能保证最好的全局划分。实践中常使用 k-means++ 与多次重启，选择最低 inertia 的结果。

确定成立

在固定分配/中心的单个子问题中，精确更新不增加平方误差。

不能由此推出

全局最优、真实语义类别、不同随机种子输出一致或下游预测表现最佳。

09 · k 如何选择？指标如何理解？

这里的 k 是预先指定的簇数，不是由普通 K-Means 自动学习的。随着 k 增大，最优训练 inertia 不会变大；特别是每个点单独成簇时可达到零（当 k 不小于不同样本位置数）。因此单靠训练 J 最小不能选择合理 k。

  • Elbow / 肘部法：观察 J 随 k 递减的形态，寻找收益递减的转折；并非总有清晰拐点。
  • Silhouette / 轮廓系数：比较样本在簇内与最近其他簇的距离；边界、簇形状和距离度量会影响结果。
  • 任务外部验证：对于压缩、检索候选或特征工程，应看下游任务与稳定性，而非只看几何指标。
  • 随机种子与稳定性：比较多次初始化的目标值、簇分配一致性与业务可解释性。

要特别避免把不同 k 的 inertia 当作一个已经正规化、可直接解释的统一“准确率”。

10 · 工程实现：复杂度、尺度与库接口

单轮距离计算(5)
T(n,k,d)∈O(nkd)

执行 t 轮的简单 Lloyd 实现约为 O(tnkd)，不含初始化、I/O 与额外加速结构；这是操作量量级，不是最坏迭代轮数保证。

最直观的实现每轮计算所有 n 个点到 k 个 d 维中心的距离，训练 t 轮约需 O(tnkd) 算术量；可通过向量化、三角不等式剪枝（Elkan）或 mini-batch 方式改进具体执行成本。要把每轮复杂度与完整求解器的最坏迭代次数分开。

下面是可运行的、只依赖 Python 标准库的教学核心。完整版本位于仓库 posts/classical-ml/k-means/kmeans_demo.py，包含单调下降断言和空簇策略。

points = (0.0, 2.0, 8.0, 10.0)
centers = (0.0, 2.0)
labels = tuple(
    min(range(len(centers)), key=lambda j: (x - centers[j]) ** 2)
    for x in points
)
updated = tuple(
    sum(x for x, label in zip(points, labels) if label == j)
    / sum(label == j for label in labels)
    for j in range(2)
)
assert updated == (0.0, 20 / 3)

如需工业代码，建议明确设置 n_clusters、random_state、n_init 和 algorithm。当前 scikit-learn 的 KMeans 支持 algorithm="lloyd" 与 "elkan"；n_init="auto" 对 k-means++ 与 random 初始化选择的运行次数不同，不能假定默认一定重复十次。[API 文档]

若各特征的量纲不同，平方欧氏距离会偏向数值范围大的维度；必要时先用训练数据拟合标准化参数，并在部署时保持相同的变换。可结合 PCA 做降维，但不能把降维后的可视化簇自动视为原始空间的真实结构。

11 · 哪些数据上 K-Means 会犯错？

  • 非凸或弯曲簇：欧氏最近中心形成的是 Voronoi 划分，无法沿月牙弯曲边缘自然分区；可考虑 DBSCAN、谱聚类等替代。
  • 大小、密度和尺度差异：平方距离目标倾向紧凑、近似各向同性的簇；极不均衡的数据可能被错分。
  • 离群点：平方误差会放大远处样本的影响，移动均值中心；应考虑稳健预处理。
  • 高维与非欧氏数据：距离集中、特征尺度与稀疏表示会影响几何意义；文本向量可能需要归一化和余弦相关方法。
  • 空簇与近似重复点：必须记录初始化、样本权重、平局和终止规则，避免“同一算法”在实现细节中发生分歧。

最后要区分 K-Means 与 GMM：GMM 通过概率密度与软分配表示混合分布；K-Means 使用硬分配与平方欧氏误差。两者有关联，但不是把 K-Means 直接称为“概率聚类”就能互换的。

13 · 带走这条推理链

一个目标：最小化点到所属中心的平方距离和。两个精确子问题：固定中心找最近邻、固定分配求均值。一个风险：对初始中心敏感，单调下降不保证全局最优。一个改进：k-means++ 让初始中心倾向彼此分散。一个边界：当真实簇弯曲、拉长、尺度差异巨大时，质心和欧氏几何可能不匹配。
