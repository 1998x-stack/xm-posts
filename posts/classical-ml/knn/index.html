Understanding KNN

如果不拟合一条直线、也不训练一棵树，只记住数据并向周围的样本提问，机器能学会分类吗？从 1967 年的最近邻理论，走向 k 个邻居的投票、距离尺度和高维检索。

Cover & Hart · 1967预计阅读 27 分钟实例学习 · 分类与回归 · 距离几何

01 · 没有训练出一条边界，也能分类？

假设我们收集了 10 台设备的两个数值特征：振动特征与温度特征。绿色代表正常，橙色代表异常。来了一台新设备，应该把它归入哪一类？

线性模型会学习一条规则，决策树会寻找阈值；k-nearest neighbors（kNN）先不学习全局参数，而是保留已标注样本，预测时直接查找附近的例子。「相近」并非自然事实，而由特征表示与距离度量定义。下面所有坐标均为本文教学构造，不是任何原论文数据。

此图最重要的不是圆，而是一个认识：判定边界由数据在局部的分布形成。kNN 不需要在训练时学到一套固定权重，但要承担保存样本和查询计算的成本。

02 · 从记忆到预测：四步才构成 kNN

输入

训练特征矩阵 X 的形状为 [n,d]，标签 y 的长度为 n；新样本 x 的形状为 [d]。本例 n=10，d=2。

定义距离

为每个训练样本计算 d(x,xᵢ)。距离由业务特征、缩放规则和度量共同确定。

找邻居

按距离排序，取最小的 k 个索引组成 Nₖ(x)。若第 k 与第 k+1 名同距，必须制定可复现的并列规则。

聚合

分类取多数类别或加权票数；回归对邻居的目标值取平均或加权平均。

先手算一遍：为什么 k=1 与 k=3 会不同？

新同学的特征是 (4.4, 4.1)。只看距离最近的三位同学，按“横、纵坐标差的平方和再开方”计算欧氏距离：

来自下文十点教学数据的前三名（距离保留三位小数）
名次已知样本类别距离与直观对比
1(3, 4)A1.404
2(6, 4)B1.603
3(6, 5)B1.836

例如第一位的距离是 √(1.4² + 0.1²) ≈ 1.404。k=1 只听 A，预测 A；k=3 时 A:B = 1:2，预测 B。这只是邻居投票，不涉及训练神经网络或更新参数。

传统「lazy learning」的意思是把主要计算推迟到预测时，并不表示预测天然快速。预测前也可能包含标准化、特征工程或索引构建，这些都可能发生在训练阶段。

03 · 距离不是细节，而是模型本体

在连续特征空间里，欧氏距离 L₂ 很常见。对于维度 d 的两个向量：

EQUATION 1
d2(x,z)=∑j=1d(xj−zj)2

曼哈顿距离 L₁ 是各维差的绝对值之和；Minkowski 的 p 参数把 L₁ 与 L₂ 连成一族。文本稀疏向量、归一化嵌入、图像像素未必适合相同距离。对一个变量做单位变换，例如「米」改成「毫米」，如果不缩放，它就会主导距离。

防止数据泄漏：StandardScaler 或其他特征变换必须只在当前训练折上 fit，再用于验证/测试折。不要在全数据集上预先求均值、方差，之后才做交叉验证。

04 · 多数投票和概率，是两种不同的说法

令 Nₖ(x) 表示按距离排序后的 k 个邻居索引，训练标签为 yᵢ，类别集合为 C。最简单的均匀投票为：

EQUATION 2
y^(x)=argmaxc∈C∑i∈Nk(x)1[yi=c]

如果 k=3、其中两位属于 B，那么 B 获得 2/3 的邻居占比。但邻居占比不自动等于经过校准的真实事件概率；类别分布、密度、样本量和度量选择都会影响它。

05 · k 太小与太大，分别失去什么？

k = 1：高度局部

一个标签就决定结果。决策边界可很曲折，容易受噪声与离群点左右；在某些复杂边界上却可能很有表现力。

k 接近 n：过度平均

预测更平滑，但很容易忽略局部结构，类别不平衡时退化为多数类偏好。

这体现了典型的偏差—方差权衡，但不是「k 越大越好」。比较多个 k 时，应在同一合理的预处理与度量管线内，使用交叉验证评估目标指标；最后保留独立测试集作最终评价。选择奇数 k 只能在二分类且没有距离并列等特定情形下减少计票平局，不能从根本上解决多分类并列。

06 · 最近的那位，是否应该更有话语权？

均匀投票给每一位同等票重。距离加权更重视接近查询点的样本，一种常用教学定义为：

EQUATION 3
wi(x)=1d(x,xi)+ε,ε>0

然后用每个类别所获权重之和决策。若查询点恰好命中某些训练样本，实际实现通常要先处理零距离样本，避免无限权重。下面交互实验使用 1/(d+10⁻⁹) 的教学约定；它和部分库在零距离上的处理不必完全相同。

07 · 标签变成数字，KNN 就成为回归器

如果每位邻居的目标不是类别，而是实数，例如维修时长，就可以直接取平均：

EQUATION 4
f^(x)=1k∑i∈Nk(x)yi

例如最近三台设备对应工时为 2、4、6 小时，则均匀 KNN 回归输出 4 小时。这是演示性的算术例子，不是一个从历史论文复制的实验。分类和回归共享「查邻居」步骤，却采用不同的目标聚合规则。

08 · Cover–Hart 1967 的结论，不是「所有 KNN 都最优」

Cover 与 Hart 的 1967 年论文研究的是最近的 1 位邻居的错误率，而非现代库默认采用的任意 k。它在大样本、适当的正则性与分布条件下比较最近邻错误率 R 和 Bayes 最优错误率 R*。对 M 类情形给出更精确的上界；一个容易记住的推论是 R 不超过 2R*。

EQUATION 5
R*≤R≤2R*

这是渐近错误率界，不是对有限训练集、任意距离、任意分布或任何验证样本都成立的性能承诺。原文还指出，Fix 与 Hodges 早于该文研究过 kₙ 最近邻多数规则：在相关一致性分析中 kₙ 随样本量增长，同时 kₙ/n 趋近 0。不要把这些历史来源和单点「1967 发明所有 KNN」混为一谈。

原论文 §III 讨论 1-NN 在该类决策规则中的 admissibility：存在某些分布，使其不会被任意其他固定 k 统一支配。这并不等于每个任务都应该选 k=1。

09 · 保存了所有数据，预测会不会很慢？

朴素的精确查询为每个样本计算一次 d 维距离，单个查询的距离成本约 O(nd)，完整排序约 O(n log n)；只需 top-k 时可用选择算法或大小为 k 的堆，避免不必要的全排序。这里忽略常数、缓存与索引构建成本。

路线什么时候值得考虑局限
Brute force数据较少、特征维度高或有向量化硬件查询成本随 n 增长
KD Tree / Ball Tree较低维、合适的空间结构与度量高维时树剪枝可能失效
ANN 索引大规模搜索对延迟敏感、允许近似需显式度量 recall、延迟与内存权衡

这里的 KNN 分类器属于 经典机器学习。若聚焦向量数据库、HNSW、倒排/近似索引与海量语义检索，则可沿 Retrieval & RAG → ANN 继续学习：两者共用「最近邻」操作，但问题设定与评估标准不完全相同。

10 · 维度升高，为什么「近」会失去区分力？

维度越高，要在局部收集足够密集的样本通常需要更多数据。许多常见分布下，最近与最远样本之间的相对距离差距可能缩小，空间划分索引不再像低维那样容易排除大量候选。这不是说所有高维距离都无效：经过良好学习的表示空间，余弦相似度和合适的度量仍然有用。

可尝试特征选择、PCA 等降维、距离学习以及合理的嵌入；同时单独测量类别表现、查询时间与空间成本。这里讨论的是数据几何和工程趋势，不把任何固定的「20 维阈值」当作普适定律。

12 · 用 10 行核心 Python 重做规则

这里使用 Python 标准库 math.dist，不依赖 scikit-learn；sorted 以样本索引作为距离并列时的稳定排序键，最后的类别并列规则也固定。完整可运行脚本与断言在仓库的 mini_knn.py，此处仅显示分类核心。

from math import dist

def predict(train, labels, query, k=3):
    assert len(train) == len(labels) and 1 <= k <= len(train)
    ranking = sorted(range(len(train)),
                     key=lambda i: (dist(train[i], query), i))
    votes = {}
    for i in ranking[:k]:
        votes[labels[i]] = votes.get(labels[i], 0) + 1
    return sorted(votes, key=lambda c: (-votes[c], str(c)))[0]

验证时至少检查三件事：同一查询点在 k=1 与 k=3 下翻转；距离加权的权重和符合逐笔手算；特征缩放只在训练折中拟合。真实评估可使用 scikit-learn KNeighborsClassifier，把预处理与模型放入 Pipeline，用分层交叉验证选择 k、距离与权重，并在留出集报告所关心的指标。

13 · 把论文、工程实现和教学示意分开

  1. Cover, T. M. & Hart, P. E. (1967). Nearest Neighbor Pattern Classification. IEEE Transactions on Information Theory 13(1): 21–27。原论文 Abstract、§II–III、§VI 的 1-NN 定义、可容许性与大样本风险界。
  2. scikit-learn User Guide: Nearest Neighbors. 现代 kNN 分类/回归、权重选项、KD/Ball Tree 与高维效率；不把该实现视为 1967 年论文的原始实现。
  3. scikit-learn Nearest Neighbors Classification example. 官方示例明确在欧氏距离前使用标准化。
  4. Stanford CS231n: Image Classification. 关于 k、L1/L2 与交叉验证的教学材料。

哪些情形要特别小心？

  • 特征单位不同、缺失值多、类别极度失衡或噪声标签明显时，邻居投票可能被错误邻域主导。
  • 选择 k 时只看训练准确率，会把模型推向过拟合；评估必须隔离验证和测试数据。
  • 预测分数来自邻居频率，不意味着可信度已经校准；涉及风险决策还需要独立校准与公平性检验。
  • 大型数据集上需单独报告查询延迟、内存占用；精确 kNN 与 ANN 近似检索的结果不能直接混为一谈。

带走一个模型：先定义「什么叫相似」，再选择「听几个人说话」，最后决定「每个人的声音有多重」。kNN 的力量来自局部数据，弱点也恰好来自局部数据。
