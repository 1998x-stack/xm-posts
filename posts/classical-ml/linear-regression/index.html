Understanding Linear Regression

一条直线为什么可以学会预测？从四个点的误差出发，沿着最小二乘的几何、代数与统计假设，理解这个看似简单却贯穿机器学习的模型。

2026.11.20约 30 分钟Least Squares · Geometry · Statistics

01 · 预测之前，先问：什么算「拟合得好」？

我们观察四组输入和目标值，想用一条直线预测未知样本。最自然的候选之一是永远预测平均值 2.25；另一条线会随着 x 增加而上升。哪一条更好？不能靠「看起来穿过更多点」回答，必须定义损失。

回归的核心不是保证直线穿过所有点，而是在明确的损失度量下，选择一组参数。预测函数、优化目标和数据生成过程必须分开理解。

02 · 「线性」指参数线性，不是世界只有直线

一元线性回归用一个斜率和一个截距，把输入映射成预测值。斜率表达 x 每增加一个单位时的条件均值变化；截距是 x=0 时的模型预测，不一定具有现实语义。

单变量线性预测(1)
y^i=β0+β1xi

记 xᵢ 为第 i 个输入，yᵢ 为观测值，预测为 ŷᵢ。多元回归可以对原始特征做变换，例如使用 x²、log(x)，只要预测对待估参数 β 是线性的，仍属于线性模型。参数的线性不代表因果线性。

关键区分： yᵢ = β₀ + β₁xᵢ + εᵢ 是含随机误差的统计模型；ŷᵢ = β̂₀ + β̂₁xᵢ 是已拟合模型的预测。观测噪声 ε 与训练残差 rᵢ 不是同一个随机对象。

03 · 为什么对残差平方，而不是把正负误差相加？

残差 rᵢ = yᵢ − ŷᵢ。若直接相加，正负误差可能互相抵消；平方可以避免抵消，并使较大的误差承担更高代价。最小二乘（OLS）就是最小化这些平方误差的总和（RSS）。除以 n 变为 MSE 不会改变最优参数。

普通最小二乘目标(2)
minβ0,β1J=∑i=1n(yi−β0−β1xi)2

平方损失连续可导、对参数是凸二次函数，因此可通过代数或迭代求解；但它也会放大离群点的影响。对异常值敏感是目标函数的性质，而不只是某种实现的 bug。NIST 的最小二乘指南给出了该方法在过程建模中的经典定位。

04 · 从微分到直线：不用优化器也能算

令 RSS 对截距和斜率的一阶偏导为零。由截距方程可得拟合线通过样本均值点 (x̄, ȳ)；将其代回斜率方程，就得到中心化协方差与方差之比。

一元回归斜率闭式解(3)
β^1=∑i=1n(xi−x¯)(yi−y¯)∑i=1n(xi−x¯)2
截距闭式解(4)
β^0=y¯−β^1x¯

这里 x̄、ȳ 是样本平均值，分母要求输入 x 不全相同。对四点教学数据，x̄ = 1.5、ȳ = 2.25；中心化乘积之和为 4.5，x 的中心化平方和为 5，因此斜率 = 4.5/5 = 0.9，截距 = 2.25 − 0.9×1.5 = 0.9。

样本

x = [0, 1, 2, 3]；y = [1, 2, 2, 4]。这只是教学数据，不来自历史实验。

最优结果

斜率 0.9、截距 0.9；RSS = 0.70。均值预测的 RSS = 4.75。

此时预测 [0.9, 1.8, 2.7, 3.6]，残差 [0.1, 0.2, −0.7, 0.4]；残差和为零，残差与 x 的内积也为零。这不是巧合，而是含截距 OLS 的正规方程在数值上的表现。

05 · OLS 的另一种直觉：将 y 投影到一个子空间

把 n 个观测 y 放在 n 维向量空间。设计矩阵 X 的每一列是一种可以线性组合的预测模式：全 1 的截距列、一列 x、乃至其他特征列。所有可表示的预测 Xβ 组成列空间 Col(X)。

残差与设计矩阵列正交(6)
X⊤(y−Xβ^)=0

距离最短的投影要求残差与每一列特征垂直。于是最小二乘可以同时被理解为：让梯度为零、求解正规方程、或将目标向量正交投影到特征空间。这三个视角描述的是同一件事。

06 · 从一条线扩展到矩阵：秩决定参数能否唯一

若 X 为 n×p 设计矩阵（包含截距列时 p 包括该列），y 为 n×1，β 为 p×1，则预测 Xβ 为 n×1。目标是最小化二范数平方。对 β 求导并令其为零，得到：

正规方程(5)
X⊤Xβ^=X⊤y

当 X 列满秩时，XᵀX 可逆，β̂ = (XᵀX)⁻¹Xᵀy 是代数表达；当特征重复或 p>n 时，参数解可能不唯一。此时不应强行套用逆矩阵；最小二乘仍可以用伪逆寻找最小范数解，或用正则化加入额外约束。

满秩

每列携带独立的线性信息；在给定样本设计下可唯一确定 OLS 参数。

共线与欠定

不同参数可能给出相同训练预测。预测可确定，不代表每个系数都能稳定解释。

07 · 已有闭式解，为什么机器学习仍学梯度下降？

闭式表达解释了极值在哪里，但不意味着要显式计算逆矩阵。样本量或维度变化、加权损失、约束和大规模训练场景，都会使迭代优化更有吸引力。对 MSE=‖Xβ−y‖²/n，梯度为：

均方误差的梯度(7)
∇βJ=2nX⊤(Xβ−y)

更新 β ← β − η∇J。对固定的正定二次目标，步长足够小时可以收敛；步长过大会震荡或发散。特征量纲悬殊时损失曲面狭长，标准化或更合适的求解器会使迭代更加稳定。

OLS 对应平方损失，而 SGD/Adam 是求解目标的优化方法；「线性回归」和「梯度下降」是两个不同层次的概念。继续阅读 SGD可以看到全批量与随机更新的差别。

09 · 「最小二乘」不等于「所有系数都值得相信」

OLS 始终可以在样本上最小化平方损失；但若要把系数理解为总体量并进行统计推断，就要讨论数据生成假设。常见充分条件包括模型在参数上线性、设计矩阵列满秩、误差条件均值为零（外生性），以及用于经典 Gauss–Markov 结论的同方差与不相关误差。

Gauss–Markov 定理说的是：在相应假设下，OLS 是线性无偏估计量中方差最小的（BLUE）。这里的「best」限定在线性无偏估计量类中，不等于预测误差全球最优。误差正态性不是 BLUE 的必要条件；经典小样本 t/F 推断通常还需要额外分布假设。可参阅 Berkeley 的回归理论说明。

识别风险：遗漏变量、反向因果、测量误差可能破坏 E[ε|X]=0。即便 R² 很高，也不能据此宣称「x 导致 y」。如有时间序列自相关或异方差，应检视残差结构，并使用恰当的标准误、模型或估计方法。

10 · 训练集拟合得好，为什么测试集可能更差？

加入更多特征通常不会增大训练集最优 RSS，但未必降低未见样本误差。训练与验证划分必须先于特征选择与调参；对时间顺序数据，要使用符合时间约束的切分。MSE 保留了目标量纲的平方，MAE 更直接但对大残差加权较轻。

决定系数与均值基线(8)
R2=1−∑i=1n(yi−y^i)2∑i=1n(yi−y¯)2

在含截距的同一训练集上，OLS 的 RSS 不高于均值基线，因而 R² 通常介于 0 与 1；在测试集或未含截距的模型上，R² 可能为负。对本例 R² = 1 − 0.70/4.75 ≈ 0.8526，但它仅描述这四个点。

Ridge 回归在平方损失上增加 λ‖β‖² 惩罚（通常不惩罚截距），让系数更小，以引入偏差换取可能降低的方差。scikit-learn 线性模型指南将 OLS、Ridge、Lasso 的目标和实现分开说明。正则化不是自动解决遗漏变量或因果混淆的工具。

11 · 工程实现：别把正规方程写成直接求逆

  1. 数值稳定性：显式构造 XᵀX 会平方条件数；优先使用 QR、SVD 或成熟的最小二乘求解器，而不是手写 inv(XᵀX)。
  2. 特征检查：对高相关特征查看秩、奇异值、条件数；必要时去除冗余列或加正则化。
  3. 输入与解释：明确训练/推理数据单位、缺失值处理、截距是否加入、特征变换是否只用训练集拟合。
  4. 诊断：看残差与拟合值关系、离群点、杠杆点和数据分布漂移；不要只汇报一个 R²。

现代 scikit-learn LinearRegression拟合的是普通最小二乘，它的不同输入与约束选项可能调用不同底层求解路径。以下纯 Python 教学程序仅演示一元且输入有方差的闭式解，不等价于生产级通用求解器。
