Understanding Logistic Regression

为什么一个线性模型能够输出类别概率？从 log-odds 的直觉走向最大似然、凸优化与稳定实现。

历史脉络 1944 → 1958 → 1972预计阅读 28 分钟二分类 / Softmax / 数值验证

01 · 为什么分类不该直接使用普通回归？

假设我们只想判断一封邮件是否是垃圾邮件：标签只能是 0 或 1。普通线性回归的输出可以是 −0.7 或 1.4，作为类别概率并不合适。逻辑回归不是对类别数字做最小二乘，而是用线性函数表达对数胜算，并通过 Sigmoid 映射到概率。

如果特征有 d 维，参数向量 w 也有 d 维。样本可被线性分开并不是使用逻辑回归的必要条件；它依然能拟合有重叠、有噪声的二分类数据。

02 · 线性打分在学习什么？

先计算一个未归一化的实数分数 z。它可以是任何实数，符号决定在阈值 0.5 下的类别，绝对值描述离该阈值的对数胜算有多远。

线性预测器(1)
z=w⊤x+b

x ∈ ℝᵈ、w ∈ ℝᵈ、b ∈ ℝ。对 n 个样本，将截距列并入设计矩阵 X ∈ ℝⁿˣ⁽ᵈ⁺¹⁾ 后，参数 θ ∈ ℝᵈ⁺¹，批量分数是 Xθ ∈ ℝⁿ。这里没有深层非线性特征提取；如果需要弯曲边界，先显式扩展特征（多项式、核特征等）。

03 · 为什么是 Sigmoid，而不是硬切一刀？

把硬阈值换成光滑函数，分数每变化一点都可传递学习信号。Sigmoid 输出严格位于 0 与 1 之间；即使分数很大，概率也只是接近端点而不是数学上达到端点。

Sigmoid / 逆 Logit(2)
p=σ(z)=11+e−z

Sigmoid 的导数是 σ(z)(1−σ(z))。但概率不等于事实上的校准保证：即便模型输出 0.8，也需要在独立验证数据上检查校准质量。

04 · 从 Log-Odds 看系数的统计含义

概率的胜算（odds）定义为 p/(1−p)。让它取对数后，就能把有界概率空间变成整个实数轴，并让每个系数以加法形式进入模型。这也是广义线性模型中 Bernoulli 分布的典型 Logit 链接。

对数胜算等于线性预测器(3)
log⁡p1−p=w⊤x+b
单特征增加 1 的胜算比(4)
odds(x+1)odds(x)=ew

固定其他变量时，wⱼ 增加一单位特征的条件 log-odds 变化；对应胜算乘以 exp(wⱼ)，不是概率直接增加 wⱼ。例如 w=ln(2) 表示胜算乘以 2，而概率的增加量取决于原来的概率。特征缩放会影响系数的数值解释。

05 · 从伯努利似然推导交叉熵

对每个独立训练样本，给定 xᵢ 假设 yᵢ ∈ {0,1} 服从 Bernoulli 分布。于是观测到正类时取概率 p，观测到负类时取 1−p，二者可以写在一个公式里。

Bernoulli 条件似然(5)
P(y|x)=py(1−p)1−y

对样本乘积似然取对数，再取相反数并除以样本数，得到平均二元交叉熵。最大化 log likelihood 和最小化该交叉熵是同一个优化问题；这里的“回归”并不是以 MSE 为主目标。

平均负对数似然 / BCE(6)
J(θ)=−1n∑i=1n[yilog⁡pi+(1−yi)log⁡(1−pi)]

一个样本算到底：分数、概率与惩罚

假设只有一个特征 x=1，权重 w=1、偏置 b=0，则 z=1×1+0=1，经 Sigmoid 得 p≈0.731。

若真实标签 y=1，二元交叉熵是 −ln(0.731)≈0.313；若真实标签 y=0，损失反而是 −ln(1−0.731)≈1.313。模型越自信地猜错，损失就越大。下文的交互实验会随着权重和偏置变化实时重算这两个数。

例如 y=1,p=0.8 的损失为 −ln(0.8)≈0.2231，而 y=1,p=0.01 的损失约为 4.6052；这是公式计算，不是论文实验数据。

06 · 为什么梯度意外地简单？

应用链式法则：∂L/∂p 与 ∂p/∂z=p(1−p) 的因子相消，得到单样本对 logit 的导数 p−y。所以梯度只是特征乘上“预测概率减真实标签”。

批量梯度(7)
∇θJ=1nX⊤(p−y)

这里 X ∈ ℝⁿˣ⁽ᵈ⁺¹⁾ 已包含首列 1，θ=(b,w)，p,y ∈ ℝⁿ。一次梯度下降更新是 θ←θ−η∇J。与 Stanford CS229 使用“最大化对数似然”的梯度上升符号恰好相反，但目标等价。

四点手算 · 非论文实验

取特征 x=[−2,−1,1,2]，标签 y=[0,0,1,1]，初始 w=b=0，每点预测 p=0.5。故 ∂J/∂w=−0.75、∂J/∂b=0；学习率 η=1，一步后 w=0.75,b=0。正类点 x=1 的预测从 0.5 升到约 0.6792。

07 · 损失为什么凸？为什么仍可能学不稳？

无正则化的二分类 Logistic BCE 关于线性参数是凸函数。Hessian 由一个非负对角矩阵夹在设计矩阵两侧，因此任意向量 v 满足 vᵀHv≥0。这是不存在非凸局部极小值的严格理由，不意味着参数总能唯一或有限。

Hessian 与半正定(8)
H=1nX⊤DX,Dii=pi(1−pi)

Dᵢᵢ=pᵢ(1−pᵢ)≥0；当设计矩阵列相关时，Hessian 可能不正定，参数不唯一。完美线性可分时，无惩罚 MLE 还可能沿某方向趋于无限大而没有有限最优解。实际算法需关注停止条件、缩放、正则化和求解器选择。

08 · L1、L2 与可分样本中的权重发散

引入 L2 可以抑制无穷大的系数，提高数值稳健性；L1 会促进部分权重精确为零，但不代表自动完成因果特征选择。实践中通常不惩罚截距，具体实现必须核对库的约定。

L2 正则化目标（本文采用的尺度）(9)
Jλ=J+λ2‖w‖22

本文用 λ 表示平均损失上的直接惩罚系数；scikit-learn 中常见的 C 是反向控制强度的 API 参数，不能忽略样本权重、损失归一化和 solver 差异而宣称 λ=1/C 普遍成立。特征需要合理标准化才能公平比较正则化的各维影响。

09 · Softmax 多分类与 One-vs-Rest 不相同

K 类互斥分类可以学习 K 组线性 logits，再用 Softmax 共同归一化成和为 1 的分布；训练时用多分类交叉熵。而 One-vs-Rest 是 K 个二分类器的策略，模型的概率含义与联合 Softmax 不同。

Multinomial Logistic / Softmax(10)
pk=ezk∑j=1Kezj

对于多标签任务（多个标签可同时为真），反而常用每个标签的独立 Sigmoid + BCE。多分类和多标签的目标设定必须先区分。

10 · 交互实验：移动边界，而不是盲调准确率

改变权重与偏置，观察概率曲线如何变陡或平移；改变阈值，则只移动预测正类的判定线，不改变拟合概率。请注意：可视化使用教学构造的单特征模型，并非训练过程或论文复现实验。

当前 x=1：p≈0.7311；阈值 0.50，预测为正类。

同一预测概率的损失也取决于真实标签：若 y=1，BCE=0.3133；若 y=0，BCE=1.3133。这是单样本教学计算，不是训练损失或测试指标。

11 · 最小实现：用数值稳定的 Logit 计算损失

直接对很大的正负 logit 计算 exp(z) 容易溢出；若先算 Sigmoid 再取 log(p)，也会遭遇近端点的浮点问题。更稳健的是从 logits 直接计算 softplus(z)−y·z，并使用稳定的 softplus 分支。

Logits 形式的稳定 BCE(11)
L(z,y)=log⁡(1+ez)−yz

下面给出纯标准库的训练核，完整可运行版本见 logistic_regression_demo.py。注意测试是确定性的数值自检，并不构成某项历史研究的性能复现。

def sigmoid(z):
    if z >= 0:
        return 1.0 / (1.0 + exp(-z))
    ez = exp(z)
    return ez / (1.0 + ez)

def softplus(z):
    return max(z, 0.0) + log1p(exp(-abs(z)))

def binary_loss_from_logit(z, y):
    return softplus(z) - y * z

实验还会用中心差分验证梯度符号、检查大 logits 的有限损失，并确认训练后的正则化目标下降。完整代码不依赖第三方包；若使用 scikit-learn，需确认当下版本的 solver/penalty 默认值。

12 · 哪些情况值得格外小心？

适合的基线

线性信号明确、样本量相对有限、需要可解释 log-odds 或稳定概率基线时，正则化 Logistic Regression 往往是有效起点。

容易误读的情形

非线性边界、特征高度共线、完全分离、类别极不平衡、标签漂移与概率失校准，都要求额外诊断。

模型报告不宜只给准确率。按业务成本选择阈值，检查混淆矩阵、Precision/Recall、ROC-AUC 或 PR-AUC，且应分离训练/验证/测试集。对高风险决策还需检查子群表现及数据收集偏差；系数的相关性不代表因果性。

13 · 从生物测定到现代线性分类器：证据脉络

逻辑函数与概率建模有较长发展史，不能把 Logistic Regression 的全部思想归到一篇单独的新论文。下列材料承担不同的证据角色：

  1. Berkson (1944), Application of the Logistic Function to Bio-Assay：Logistic 函数在生物测定中的早期方法语境。
  2. Cox (1958), The Regression Analysis of Binary Sequences：二元序列回归问题的经典历史资料。
  3. Nelder & Wedderburn (1972), Generalized Linear Models：将 Bernoulli、链接函数与线性系统项纳入统一 GLM 框架；不是逻辑回归的唯一发明出处。
  4. Stanford CS229, Lecture Notes §5, §7, §9.2：Bernoulli 最大似然、Sigmoid 梯度、Newton 方法与 GLM 推导。
  5. scikit-learn, Linear Models · Logistic Regression：现代正则化、求解器、二/多分类约定。
