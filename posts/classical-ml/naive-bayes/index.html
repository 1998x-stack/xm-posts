Understanding Naive Bayes

为什么“天真”的条件独立假设，也能成为有效的分类器？从词袋证据到概率、平滑与模型误区。

核心文献 1997 · 1998 · 2003预计阅读 30 分钟概率分类 · 生成式模型
CHAPTER 01 · 从一封消息出发

为什么两个词就能改变一封消息的类别？

一条新消息只有 free offer 两个词。我们想判断它更像「推广」还是「工作」：不是先背下贝叶斯公式，而是先问——哪一类消息更容易产生这两个词？

朴素贝叶斯（Naive Bayes，NB）使用一个很强的近似：在类别已知时，把不同特征视作条件独立。训练时只需计数、估计概率；推断时将每个观察到的特征对类别的支持合起来。这个模型简单、训练廉价，但「容易分类」不等于「给出的概率一定校准良好」。

论文定位。Naive Bayes 并非由单篇论文提出的单一网络架构。本文以 McCallum & Nigam (1998) 的文本事件模型比较为主线，穿插 Domingos & Pazzani (1997) 的分类最优性分析；图与小语料均为独立教学构造。
CHAPTER 02 · 条件概率

从生成问题倒转成分类问题

把类别记为 C，消息的特征向量记为 x。生成问题从「类别已知」出发，研究哪个特征更可能出现，即 P(x | C)；分类则反过来寻求 P(C | x)。贝叶斯公式把两者连接起来：

贝叶斯判别(1)
P(C|x)=P(x|C)P(C)P(x)

对所有候选类别，分母 P(x) 相同，所以比较类别时只需要似然 × 先验。在本文教学语料中，两类各有 3 篇训练文本，因此用经验先验 P(C = 推广) = P(C = 工作) = 0.5。

维度约定：训练样本数为 n，词表大小为 V，每篇文本由长度为 V 的词频向量表示；训练词频矩阵的形状为 n × V，单篇推断输入为 1 × V。NB 在不同类别中分别估计特征参数，而不是学习注意力权重或深层隐藏状态。

CHAPTER 03 · 图模型

“朴素”究竟假设了什么？

假设一篇文档有 d 个特征（对于词袋模型，通常是词表每个词的计数或出现标记）。朴素条件独立让原本难估计的联合似然分解为多个局部项：

条件独立近似(2)
P(x|C)≈∏j=1dP(xj|C)

这个乘积是通用特征形式。文本的多项式事件模型更准确的写法是：每次词位抽样服从同一类别词分布，文档用词频计数 tw 汇总，于是每个词似然项拥有一个指数 tw；与词的顺序无关。固定一篇文档时，多项式系数与类别无关，可在判别中抵消。

条件独立大幅降低参数量，却可能把相互依赖的线索重复计数。Domingos 与 Pazzani（1997） 说明：某些分布中，即使独立假设被严重违背，零一损失下的分类决策仍可能是最优的；但这不等于估计的后验概率也准确。

CHAPTER 04 · 两种事件模型

同样叫 Naive Bayes，重复词与缺席词为何待遇不同？

Multinomial NB · 词频

“free free meeting” 的计数是 (2, 1)。重复的 free 会再次增加推广类证据；词袋顺序被忽略。适合以词频为输入的文本分类基线。

Bernoulli NB · 出现标记

相同消息只有 free=1、meeting=1。所有词表维度都计入似然，包括未出现的词，通过 1 − θ 项惩罚某类高概率词的缺席。

Multinomial 的判别似然(3)
P(x|C)∝∏w∈VθC,wtw
Bernoulli 的判别似然(4)
P(x|C)=∏w∈VθC,wbw(1−θC,w)1−bw

这里 θC,w 在 Multinomial 中是「某次词位抽到 w 的概率」，在 Bernoulli 中是「文档含 w 的概率」，两者不能混作同一个参数估计；tw 是词频，bw 是 0/1 出现标记。原论文 Section 2 分别定义事件模型，分类前必须先说清楚采用哪一个。

CHAPTER 05 · 零概率问题

从未见过的词，为什么不该否定整类？

如果某类训练语料里没出现 free，那么不平滑的 Multinomial 极大似然会给这个词 0 概率。连乘的结果立即变成 0，哪怕同一句话里出现许多非常有力的其他线索。

加法平滑（Multinomial）(5)
θC,w=NC,w+αNC+α|V|

NC,w 是类别 C 的 w 总词频，NC 是该类所有词频之和，|V| 是训练词表大小，α > 0 是每个词的对称伪计数。α=1 通常称 Laplace smoothing，其他正值是 Lidstone smoothing。分子分母必须一致平滑，才能让词概率之和为 1。

Bernoulli 不能照搬这个分母：其 θ 使用「含某词的文档数」平滑，常见形式是 (含词文档数 + α)/(该类文档数 + 2α)。

CHAPTER 06 · 数值稳定

将连乘变成相加，为什么几乎是必需的？

长文本把上千个小于 1 的数相乘，浮点数可能下溢。取自然对数后，乘积成为求和，保留相同的最大值类别。

Multinomial 的对数打分(6)
sC(x)=logP(C)+∑w∈VtwlogθC,w

需要后验数值时，可对各类别 sC 使用 log-sum-exp 归一化；只求类别则用 argmax 即可。注意 算出归一化的模型后验与真实世界校准概率仍是两件事。

CHAPTER 07 · 逐笔手算

六篇小文档：free offer 为什么给出 12:1？

我们构造 6 篇文本，每类 3 篇：推广类分别为 “free offer now”、 “free prize today”、 “offer prize free”；工作类为 “project meeting today”、 “project report now”、 “meeting report project”。词表大小是 8，两类各有 9 个词位。

表 1 · 教学语料的词频（不是 1998 论文实验数据）
词推广词频工作词频
free30
offer20
prize20
project03
meeting02
report02
today / now各 1各 1

对新消息 “free offer”，用 α=1：推广类的 free 与 offer 分别为 4/17、3/17；工作类都是 1/17。两个类别先验都是 1/2，因此后验优势为 (4×3)/(1×1)=12；由此推出模型内归一化后验 12/13 ≈ 92.3%。它是固定模型的教学算术，并非对任何真实用户消息的可信度评估。

观察 “free free meeting”：Multinomial 会再次计算第二次 free；Bernoulli 则仍然只记 free 出现一次。这就是两种事件模型会对同一封邮件作出不同判断的重要原因。

CHAPTER 09 · 超出文本

高斯朴素贝叶斯、类别特征与 Complement NB 的边界

条件独立是模型家族的共同结构，单个特征用什么概率分布描述，要由数据类型决定：

Gaussian NB

连续数值特征（例如测量值）常按每个类别、每个维度单独估计均值与方差，使用一维高斯密度相乘。特征相关性、方差为零与概率校准都需要处理。

Categorical / Complement NB

Categorical NB 为每个离散属性分别学习类别条件分布；Complement NB 从「非本类」语料估计权重，属于后续文本分类改进，而非 1998 论文的第三个事件模型。

Gaussian NB 的单维条件密度(7)
p(xj|C)=12πσC,j2exp(−(xj−μC,j)22σC,j2)

μC,j、σ²C,j 分别是该类第 j 维的均值与方差。这里的概率密度不是离散词概率；不能将两个公式的量纲和分母混用。详见 scikit-learn 的模型家族说明。

CHAPTER 10 · 原始论文

论文究竟证明了什么？哪些只是本篇教学例子？

McCallum & Nigam（1998）对 Multinomial 与 Multivariate Bernoulli 两种事件模型进行了系统比较，考察五组文本语料和词表规模。论文摘要与结论报告：在其比较设置下，Multinomial 的错误率相对于 Bernoulli 平均降低约 27%；小词表时 Bernoulli 有时更好，规模较大时 Multinomial 通常更占优。这是作者报告的历史数据集平均结果，不是跨任务、跨数据集或现代模型的普适性能保证。论文 Abstract、Figures 1–6、Conclusion。

Domingos & Pazzani（1997）从损失函数角度解释独立性假设可能不精确，但零一分类仍有机会正确。它没有证明后验概率必然校准，也没有证明朴素贝叶斯总比更复杂的分类器更好。摘要与理论分析。

Rennie 等（2003）系统讨论文本朴素贝叶斯的假设缺陷并提出改进；其方法应作为 1998 原模型之外的后续发展讲述。ICML 2003 论文。

证据边界。本篇 6 篇文本、比值 12:1、交互结果、SVG 图形均是明确标记的教育性构造；没有把它们算作原论文复现实验，也没有推断原始实验的未报告指标。
CHAPTER 11 · 误区与风险

条件独立、校准和数据泄漏：三个最重要的边界

  • 高分类准确率 ≠ 概率可信。后验的排序正确时，数值也可能过于极端；如果需要风险评分，应以独立验证集评价 log loss、Brier score 与可靠性曲线，并考虑校准。
  • 词频不等于语义。词袋模型忽略顺序、否定、上下文与多义词；“not free” 未必能被词频直观区分。对短文本和大词表，选错特征模型可能更关键。
  • 预处理必须仅用训练折拟合。构建词表、特征选择、校准和参数调整如果偷偷看到测试集，会制造数据泄漏。类别不均衡时也须正确设置先验和评估指标。
  • 生成假设与判别边界是两回事。不同模型可能给出类似的类别决策，却不意味着学习到相同概率密度。不要把 posterior 直接当作因果解释。

工程上，NB 是值得保留的低成本、可解释基线；需要语言上下文、关联特征或复杂非线性决策时，应和逻辑回归、线性 SVM、校准模型及现代编码器进行同数据、同划分的公平比较。

CHAPTER 12 · 最小可复验代码

在同一份小数据上核对手算、归一化与伯努利重复词不敏感

下面的完整标准库 Python 代码也保存在仓库的 naive_bayes_demo.py。它使用 log-space、Laplace/Lidstone 平滑和稳定归一化，独立实现两种事件模型。这不是论文原始实现，也不进行生产级文本清洗。

"""Deterministic educational Naive Bayes: no external dependencies."""
from collections import Counter
from math import exp, log

DOCS = {
    "promo": ["free offer now", "free prize today", "offer prize free"],
    "work": ["project meeting today", "project report now",
             "meeting report project"],
}
VOCAB = sorted({w for docs in DOCS.values() for d in docs for w in d.split()})

def probabilities(words: str, alpha: float = 1.0, model: str = "multinomial"):
    if alpha <= 0 or model not in {"multinomial", "bernoulli"}:
        raise ValueError("alpha must be positive; unknown model")
    tokens = Counter(w for w in words.split() if w in VOCAB)
    scores = {}
    for label, docs in DOCS.items():
        score = log(len(docs) / sum(map(len, DOCS.values())))
        if model == "multinomial":
            counts = Counter(w for doc in docs for w in doc.split())
            denominator = sum(counts.values()) + alpha * len(VOCAB)
            score += sum(n * log((counts[w] + alpha) / denominator)
                         for w, n in tokens.items())
        else:
            presence = Counter(w for doc in docs for w in set(doc.split()))
            for word in VOCAB:
                theta = (presence[word] + alpha) / (len(docs) + 2 * alpha)
                score += log(theta if word in tokens else 1 - theta)
        scores[label] = score
    peak = max(scores.values())
    weights = {label: exp(score - peak) for label, score in scores.items()}
    z = sum(weights.values())
    return {label: value / z for label, value in weights.items()}

if __name__ == "__main__":
    p = probabilities("free offer")
    assert abs(p["promo"] - 12 / 13) < 1e-12
    assert abs(sum(p.values()) - 1) < 1e-12
    assert probabilities("free free meeting", model="bernoulli") == probabilities(
        "free meeting", model="bernoulli")
    assert probabilities("project meeting")["work"] > 0.9
    print("toy assertions passed", p)

运行 python posts/classical-ml/naive-bayes/naive_bayes_demo.py 可进行断言；仓库的 tests/test_naive_bayes_demo.py 额外检查未见词、先验归一化、重复词和 α 参数边界。

CHAPTER 13 · 知识地图

把朴素贝叶斯压缩为一条可迁移的思考链

定义类别 → 选择事件模型 → 统计条件分布 → 加入平滑 → 取对数累加 → 比较类别 → 检查校准和泛化。

最核心的区分是：贝叶斯公式负责从生成概率逆向推断类别，朴素假设负责让联合似然可估计，事件模型规定数据到底按词频、出现标记还是连续密度建模。三个问题不能互相替代。

如果你已理解本文，可进一步比较 SVM 的最大间隔思想：SVM 直接构造分类边界，Naive Bayes 则先建模类条件特征分布再反向判别。这是生成式与判别式方法的经典对照。
