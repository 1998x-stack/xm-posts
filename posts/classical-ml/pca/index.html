Understanding PCA

为什么保留方差最大的方向，恰好让重建误差最小？从点云的长轴，一路推到特征向量、SVD 和真实数据流水线。

Pearson 1901 · Hotelling 193331 分钟阅读Classical ML / Dimensionality Reduction

01 · 把二维数据压成一维时，保留什么？

想象一团沿斜线展开的二维点云。只有一个数字可用来保存每个点时，我们不应随意删除 x 或 y，而应该找到能保留最多变化的一根新坐标轴。

PCA（Principal Component Analysis）用方差刻画这种变化。对于中心化数据和正交投影，方差保留最大与平方重建误差最小是同一个数学问题的两种看法。

02 · 新坐标系由数据决定

原始特征轴来自采集方式；主成分轴来自样本之间如何一起变化。第一根轴是方差最大的方向，第二根在与其正交的约束下保留剩余最大方差。PCA 不使用分类标签，因此属于无监督线性降维。

注意：“方差最大”并不等于“最适合分类”。某个预测标签可能恰好依赖低方差方向；那时降维甚至会丢失判别线索。

03 · 为什么要中心化

如果整个点云被平移得远离原点，但形状不变，我们仍应得到同一组主方向。要做到这一点，先减去训练样本均值。中心化是平移操作；除以标准差的标准化则会改变各轴相对权重，是另一个决策。

中心化样本及其均值(1)
ai=xi−μ,μ=1n∑i=1nxi

xᵢ、μ、aᵢ ∈ ℝᵈ；n 是观测数。

04 · 从投影到重建

令 w 为单位方向，中心化的样本 a 在这一根轴上的坐标是 wᵀa；乘回 w 则得到原空间中的正交投影。多维情形下把 k 根正交单位主轴排成 W∈ℝᵈˣᵏ。

压缩坐标与原空间重建(2)
z=W⊤(x−μ),x^=μ+Wz

WᵀW=Iₖ；z∈ℝᵏ。还原时要把训练均值 μ 加回去。

05 · 协方差是点云的形状摘要

将 n 个中心化观测按行组成 A∈ℝⁿˣᵈ；协方差矩阵 C 的对角记录各维方差，非对角记录两个维度共同变化的强度。

样本协方差矩阵(3)
C=1n−1A⊤A

C∈ℝᵈˣᵈ。使用 n−1 作为无偏样本协方差的分母；改用 n 只对特征值做同比缩放，不改变主方向。

协方差是对称半正定矩阵，所以其特征值非负，可建立正交特征向量基。

06 · 方差最大化的准确形式

一维投影分数的样本方差为 wᵀCw。若不限制 w 的长度，就可以无限放大分数；因此将 w 限制为单位向量。

第一主方向的最大方差目标(4)
maxw⊤w=1w⊤Cw

多根主轴时令 WᵀW=Iₖ，最大化 tr(WᵀCW)。

这说明 PCA 找到的是特征的线性组合，不是从 d 个原始特征中机械挑 k 个。

07 · 为什么会出现特征向量？

对带单位长度约束的最大化问题引入拉格朗日乘子。由于 C 对称，驻点满足 2Cw−2λw=0，得到特征方程。将其代回目标，投影方差恰好等于 λ。

Rayleigh 商与特征方程(5)
ℒ=w⊤Cw−λ(w⊤w−1)⇒Cw=λw

最大特征值对应最大方差；下一主轴受正交约束，对应下一特征值。

w 与 −w 表示同一根主轴。特征值重合时，单个方向可能不唯一，但整个主子空间仍可有稳定意义。

08 · 为何也是最小重建误差？

对中心化矩阵 A 投影到 W 张成的正交子空间，再还原为 AWWᵀ。保留部分与垂直残差正交，勾股定理可以推广到 Frobenius 平方范数：

正交投影的能量守恒(6)
‖A−AWW⊤‖F2=‖A‖F2−‖AW‖F2

公式中三个下标 F 都表示 Frobenius 范数，外面的平方是范数平方；等式要求 W 的列正交（WᵀW=I）。不能直接把这里的 F 范数换成谱范数。

因为 ‖A‖² 固定，最大化保留能量就等价于最小化重建误差。条件是中心化、正交投影和欧氏平方损失；换成其他损失或非线性方法不能直接沿用此证明。

09 · 工程上为什么往往直接做 SVD

协方差分解对概念有帮助，但数值上显式形成 AᵀA 可能把条件数平方，增大舍入误差。对 A 直接做 SVD 可以得到相同的主方向：V 的列向量是特征空间主轴。

中心化矩阵的奇异值分解(7)
A=UΣV⊤,λj=σj2n−1

前 k 个右奇异向量形成 W；不必显式计算 d×d 的协方差矩阵。

randomized SVD 与 IncrementalPCA 是更现代的扩展路径，应与历史 PCA 数学概念区分开来。

10 · 四个点的手算：80% 从何而来？

构造样本 (−2,0)、(0,−1)、(0,1)、(2,0)。均值正好为零。按 n−1=3 计算，样本协方差为 diag(8/3, 2/3)，两个特征值分别为 8/3 和 2/3。

保留第一主轴 x 方向时，解释方差比例为 (8/3)/(10/3)=80%，重建得到 (−2,0)、(0,0)、(0,0)、(2,0)。这些数字是独立教学算例，不是论文 benchmark。

把“丢失 20%”翻译成四个点的实际误差

投影到 x 轴时，只保留每个点的横坐标，纵坐标设为 0。重建误差就是原点到投影点的平方距离，不是“标签正确率”。

四点教学算例：只保留 x 坐标
原始点保留 1 维后重建平方误差
(−2,0)(−2,0)0
(0,−1)(0,0)1
(0,1)(0,0)1
(2,0)(2,0)0

原始总平方能量是 4+1+1+4=10；投影后保留 4+0+0+4=8，丢失 2。因此保留 8/10=80%，丢失 2/10=20%。由于本例已中心化，这正对应方差占比。样本协方差虽除以 n−1，但分子分母同比缩放，百分比不变。

11 · 如何选择保留的维度 k

按照从大到小排序的特征值，累计解释方差可用于衡量压缩和保留变化之间的折中。若总方差为零，则比例无定义。

累计解释方差比例(8)
Rk=∑j=1kλj∑j=1rλj

r 是非零特征值的数量。95% 是常见的启发式阈值，并非统一正确答案。

实际选择还应结合重建误差、下游验证集表现、可解释性与推理预算。解释方差不是因果解释，也不保证最大化预测性能。

12 · 互动：转动主轴，看残差如何变化

在一个固定的合成二维点云上转动单位投影方向。橙点是投影，绿色虚线是垂直残差。观察每个方向的平均保留平方能量与平均平方重建误差如何相互补偿。

观察实验：先按「水平轴」「竖直轴」，再按「寻找最佳方向」。对于固定且已中心化的这批点，保留比例 + 丢失比例始终为 100%；这里优化的是平方重建误差，不是分类准确率。最佳方向按钮会选择最接近真实最优角度的 5° 网格值。

13 · 五个工程边界

  1. 数据泄漏：先划分训练和测试，再只在训练集上 fit 均值、Scaler 和 PCA；测试集只 transform。
  2. 量纲差异：大数值尺度的维度可能主导协方差；StandardScaler 是需要论证的选择，不是 PCA 的定义。
  3. 高维低样本：中心化矩阵秩至多 min(n−1,d)，无法从极少样本中恢复所有主方向。
  4. 符号及重特征值：特征向量可翻转符号，重根时基甚至可旋转；比较时宜看子空间。
  5. 白化 ≠ PCA 默认行为：whiten 进一步缩放不同分量至单位方差，会改变分量原有的相对幅度。

14 · 纯 Python 验证与现代 API

仓库中的 mini_pca.py 实现二维解析 PCA（无需 NumPy），并由 tests/test_pca.py 检查四点特征值、能量守恒、平移/旋转和非法输入。它是教学数值核，而非通用稳健 SVD 库。

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
# 必须先划分 X_train / X_test
pipe = make_pipeline(StandardScaler(), PCA(n_components=0.95))
Z_train = pipe.fit_transform(X_train)
Z_test = pipe.transform(X_test)  # 不要在测试集重新 fit

若量纲一致且绝对方差大小有意义，可以省略 StandardScaler；但仍需中心化，并在所有数据划分中复用训练均值和主轴。

15 · 原始文献、现代研究与证据

PCA 不是一篇有当代分类基准表格的深度学习论文。Pearson (1901) 研究最佳拟合直线和超平面的几何问题；Hotelling (1933) 将其发展为多变量统计主成分分析。Jolliffe 和 Cadima 的现代综述则系统回顾其变体和应用。

  1. Pearson (1901), On Lines and Planes of Closest Fit to Systems of Points in Space — 几何起点。
  2. Hotelling (1933), Analysis of a Complex of Statistical Variables into Principal Components — 统计主成分体系。
  3. Jolliffe & Cadima (2016), Principal Component Analysis: a Review and Recent Developments — 综述。
  4. scikit-learn PCA API — 现代 SVD、whitening 行为。
  5. scikit-learn Common Pitfalls — 泄漏与正确的变换流程。

16 · 一个可迁移的心智模型

几何上找点云展开最长的轴；统计上找协方差最大特征值的方向；代数上取中心化矩阵的右奇异向量；压缩上用正交投影保留最大能量、最小化平方重建误差。

当目标不再是方差、数据呈复杂非线性结构、或预测目标藏在小方差方向时，PCA 仅是一种有用的基线，而不是万能的信息保留算法。

继续阅读 Understanding SVM，比较无监督方差方向与有监督最大间隔方向。

本批学习路线：PCA 解释如何把点云压缩到一条轴上 → K-Means 学会按距离把点分组 → GMM 理解为什么同一个点也能对两个分量各占一部分责任。PCA 与聚类目的不同，降维不是聚类必需步骤。
