PAPER STUDY · CLASSICAL MACHINE LEARNING

Understanding SVM

为什么「正确分开两类」还不够？从最大间隔的几何直觉到支持向量、软间隔与核技巧。

论文主线 · 1992 → 1995预计阅读 28 分钟二分类与核方法

01 · 为什么「分对了」还不够？

把蓝点与橙点分开，你可能画出无数条正确的线。若新数据略有噪声，哪条线更值得信任？支持向量机的回答不是「找任意一条线」，而是：在训练样本可分的前提下，挑选离最近样本仍有最大安全距离的决策边界。

这个几何直觉衍生了 Maximum-Margin Classifier。早期的 Boser、Guyon 与 Vapnik（1992） 研究了最大间隔分类器；Cortes 与 Vapnik（1995） 则将支持向量网络系统化扩展至不可完全分离的数据并讨论核空间中的判别面。

不要把直觉当成保证：最大训练间隔并不意味着对任何数据分布都必然得到最好的测试准确率。泛化还依赖数据、特征、核函数、正则化以及模型选择。

02 · 从得分函数到几何距离

给定二分类训练集 {(xi,yi)i1…n}，其中 xi∈ℝd、yi∈{−1,+1}。线性模型使用 f(x)=w⊤x+b 打分，以符号作为类别。几何问题是：点离 f(x)=0 到底有多远？

点到决策超平面的距离(1)
d(x,H)=|w⊤x+b|‖w‖2

把参数统一缩放并不改变决策边界，因此可选取规范化方式，使离边界最近的样本满足 yi(w⊤xi+b)=1。正负两侧的支持超平面分别是 f(x)=+1 和 f(x)=−1。

这里要区分两个量：函数间隔 yif(xi) 会随 w、b 同比例缩放；几何间隔 yif(xi)‖w‖ 不会。因此，不能只让函数得分无限增大，必须明确规范化约束。

03 · 硬间隔：几何目标变成凸优化

最大化 2‖w‖ 等价于最小化权重范数。在训练数据严格线性可分且各类非空时，硬间隔 SVM 的规范形式是：

硬间隔原始优化问题(2)
minw,b12‖w‖2
约束yi(w⊤xi+b)≥1,i=1,…n

这是一个带线性不等式约束的凸二次优化问题。优化几何间隔，而不单是训练分类正确率，是核心区别。w 的方向垂直于超平面，b 使它平移。

普通可分超平面

只要求 sign(w⊤x+b)=y，可能贴着某个样本走。

硬间隔最优超平面

在相同训练集合上，最大化最近点到决策面的距离。

如果数据存在标签冲突、异常点或真正的重叠，约束可能无可行解。这不是优化器坏了，而是硬间隔假设不符合数据。

04 · 对偶：为什么只有少数点决定边界？

为每个约束引入非负的拉格朗日乘子 αᵢ，得到下式。先对原始变量 w、b 取极小，再对 α 取极大。

硬间隔拉格朗日函数(3)
L(w,b,α)=12‖w‖2−∑i=1nαi[yi(w⊤xi+b)−1]
∂L∂w=0

推出 w=∑i=1nαiyixi，即模型方向可以由训练向量组成。

∂L∂b=0

推出 ∑i=1nαiyi=0，正负类权重需要相互平衡。

代回 L

得到只依赖训练样本内积 xᵢᵀxⱼ 的优化问题。

硬间隔对偶优化问题(4)
maxα∑i=1nαi−12∑i=1n∑j=1nαiαjyiyj(xi⊤xj)
约束αi≥0,∑i=1nαiyi=0

互补松弛条件 αi[yif(xi)−1]=0 说明：对硬间隔最优解，只有落在边界约束上的点才可能有 αi>0。支持向量是 αᵢ>0 的样本；落在间隔边界的点也可能因为退化情况而有 αi=0。

05 · 一个可以手算出最优解的一维例子

设四个训练点 x∈{−2,−1,+1,+2}，左侧标为 −1，右侧标为 +1。最近的异类点是 x=−1 和 x=+1；选取 w=1、b=0，恰好满足它们的规范化约束。

一维解析解(5)
w=1,b=0⇒f(x)=x,γgeo=1

检验：对四个点都有 yif(xi)≥1；x=±1 处恰等于 1。对偶解给出 w=12·1·1+12·(−1)·(−1)=1。未知点 x=0.4 的得分为 +0.4，预测为正类；但这个 0.4 不是概率。

这个玩具例子展示解与 KKT 结构，并非复现 1995 年论文的真实数据或训练流程。你可以在文章后面的 Python 文件中运行对应断言。

06 · 软间隔：当现实数据不能彻底分开

引入每个样本的松弛变量 ξi≥0，并让间隔约束允许违反：yif(xi)≥1−ξi。现代常见的 L1 松弛变量惩罚 / hinge-loss C-SVM 使用：

现代 C-SVM 软间隔优化问题(6)
minw,b,ξ12‖w‖2+C∑i=1nξi
约束yif(xi)≥1−ξi,ξi≥0

对固定的 w、b，最优 ξi=max(0,1−yif(xi))，所以它等价于 12‖w‖2+C∑i=1nmax(0,1−yif(xi))。C 大会更严厉地惩罚间隔违反；C 小则允许更大的违规以换取更强的权重正则化，但并非保证训练集一定准确。

动手比较：C 大一点，为什么会换一条边界？

沿用第 05 节的一维玩具数据 x = −2, −1, +1, +2（标签等于符号）。固定 b=0，只比较四个候选 w。每个候选的目标值 = ½w² + C × hinge 损失总和；数值越小越优。注意：这是有限候选比较，不是运行通用 SVM 求解器。

w = 0.25½w² = 0.031 · Σhinge = 2.5
J = 0.281
w = 0.5 · 当前较优½w² = 0.125 · Σhinge = 1
J = 0.225
w = 1½w² = 0.5 · Σhinge = 0
J = 0.500
w = 2½w² = 2 · Σhinge = 0
J = 2.000

C = 0.1：在四个候选中 w = 0.5 的目标值最小。它分类正确，但 ±1 两点仍在间隔内，hinge 损失不为零。

读图提示：长条代表较大的目标值（反而更差）。减小 C 可以容忍部分训练点进入间隔；增大 C 会放大违规惩罚，但仍需结合验证集判断泛化。

与 1995 年原文的精确关系：Cortes–Vapnik 正文第 3 节重点推导的是含 (∑i=1nξi)2 的惩罚形式；今天广泛使用的线性惩罚 ∑i=1nξi 的 C-SVM 对应原论文 Appendix A 的 F(u)=u 情形。两者相关，但目标与对偶约束不应混为同一个公式。参见 原文 §3、Appendix A。

对现代线性 hinge-loss C-SVM，对偶具有 0≤αi≤C 的盒约束；KKT 对应关系是：αi=0 通常在间隔外；0<αi<C 的点恰位于间隔边界；αi=C 的点可能在间隔内或者被错分。不要把所有 αi>0 的点都说成「距离边界最近」：软间隔中的支持向量也可以在间隔内部。

07 · 核技巧：在新空间画直线，在原空间得到曲线

如果两类点排成内外圈，原空间不存在一条直线能把它们分开。可以把样本映射到特征空间 φ(x)，在新空间使用线性判别；其在输入空间对应的边界可以是非线性的。

对偶式只出现 φ(xi)⊤φ(xj)，因此不一定要显式建立 φ(x) 的全部坐标，使用一个满足核条件的 K(x,z)=⟨φ(x),φ(z)⟩ 即可。

核 SVM 的决策函数(7)
f(x)=∑i:αi>0αiyiK(xi,x)+b
线性核K(x,z)=x⊤z
多项式核K(x,z)=(x⊤z+c)p，p 为正整数
RBF / Gaussian 核K(x,z)=exp(−γ‖x−z‖2)，γ>0
有效核的条件任意有限样本上的 Gram 矩阵需要半正定

核技巧并不是「把数据随便变换就一定可分」。选核函数与超参数相当于选择归纳偏置；任意相似度函数也未必对应一个合法的内积空间。

08 · 动手观察：γ 如何改变样本之间的相似度？

对 RBF 核，γ 控制相似度随距离衰减的快慢。下面五个一维训练位置是 −2、−1、0、1、2。矩阵每格表示两个位置的核值；这里只改变核矩阵，不执行 SVM 训练。

γ = 0.75：距离 1 的点，其 RBF 相似度约为 0.47。

γ 过大时，距离稍远的点几乎无法互相影响，决策边界可能非常局部；γ 过小时，许多样本之间的差异被压缩。同时调 C 与 γ，并且用独立验证集或交叉验证比较，不能只凭训练曲线选择。实践建议可参见 scikit-learn SVM 文档。

09 · 把原理落成可以检查的代码

仓库中的 mini_svm.py（源码） 是一个仅用 Python 标准库的一维硬间隔解析解示例：它找到最近的异类点，构造最大间隔分界，并验证约束、KKT 支持系数、hinge loss 与 RBF 核对称性。它是窄范围的解析教学示例，不是通用 SVM 求解器。

from mini_svm import solve_hard_margin_1d, rbf
model = solve_hard_margin_1d(
    negatives=[-2.0, -1.0], positives=[1.0, 2.0]
)
assert model["w"] == 1.0 and model["b"] == 0.0
assert model["support"] == (-1.0, 1.0)
assert abs(rbf(0.0, 1.0, gamma=0.75) - 0.47236655) < 1e-7

在仓库根目录运行 python posts/classical-ml/svm/mini_svm.py 和 python -m pytest tests/test_svm.py -q。如果希望训练非线性、数万维或大数据集，请使用经过充分测试的 LIBSVM / scikit-learn 等实现，并在使用前进行特征标准化和验证集模型选择。

10 · 回到论文：究竟哪些结论有原始证据？

1992 · COLT

Boser、Guyon、Vapnik 在 A Training Algorithm for Optimal Margin Classifiers 中提出最大间隔的训练算法，指出解可由支持样本表示；这是本篇硬间隔机制的主要历史依据。

1995 · ML

Cortes、Vapnik 的 Support-Vector Networks 将不可分数据的软间隔与核空间中的判别面组织为统一方法；原文 §§3–4 与 Appendix A 讨论了不同松弛惩罚方案。

1995 · OCR

原文 §6 在光学字符识别任务中进行比较，并报告多项式核相关实验。其结果受当时数据、预处理、训练与基线条件限制；不应直接推断 SVM 在今天所有数据集或深度模型上占优。

本篇几何图、热力图和一维代码是为了拆解优化机制而新构造的教学材料；它们不是复原的论文图、不是 OCR 结果，也不构成独立性能实验。与论文对应的主要结论逐项记录在源代码目录的 evidence.json 中。

11 · 工程选择、边界条件和三个常见误解

  • 样本数决定了核方法的规模压力。显式 Gram 矩阵包含 n2 个核值；常见核 SVC 拟合在较大 n 时会昂贵。预测成本与保留下来的支持向量数量相关，不能只看特征维度。
  • 数据缩放会改变距离与内积。特别是 RBF 核，特征量纲混乱会让某些维度支配 γ‖x−z‖2；常见做法是在交叉验证的每个训练折内学习标准化参数，防止泄露。
  • C 与 γ 不等于「越大越好」。它们控制复杂度与间隔违规权衡；验证集、任务代价、类不平衡与概率校准都可能影响选择。
误解：SVM 就是核函数

线性 SVM 不需要核技巧；核是推广非线性决策面的重要方式。

误解：得分就是概率

f(x) 是有符号的间隔相关决策分数；概率输出需要额外校准。

多分类 SVM、支持向量回归 SVR 与 one-class SVM 都是后续相关方法族，但不是这篇二分类推导的直接等号替换。SVM 今天仍是理解最大间隔、凸优化、对偶、稀疏支持表示与核方法的重要基石。

12 · 把 SVM 压缩成一条思考链

挑一条线 → 让最近点尽可能远 → 写成约束优化 → 由 KKT 找到支持向量 → 用松弛应对噪声 → 用核内积实现非线性边界。

读完后应该能独立回答：为何是 1/||w|| 而非 |wᵀx+b|；为什么 α 的非零位置决定预测成本；C 的作用是什么；以及特征映射与核函数为何可以在不显式计算高维坐标时实现复杂边界。
