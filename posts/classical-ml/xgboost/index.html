Understanding XGBoost

树为什么可以一棵接一棵地变准？从二阶梯度与分裂增益，到稀疏数据与可扩展系统的完整机制。

Tianqi Chen · Carlos GuestrinKDD 2016约 34 分钟Trees & Ensembles

01 · 为什么一棵树的错误能被下一棵树修正？

普通决策树从根到叶做出一次选择。Boosting 的关键不是在许多树之间投票，而是让后面新增的树沿着损失下降方向，修正前面树组合的连续预测分数。于是一个复杂函数被拆成一系列相对简单的树。

例如第一轮预测 −0.40，下一轮增加 +0.12，则总分 −0.28。分类模型通常再应用 sigmoid 或其他链接函数。论文 §2.1 的预测是加性树函数之和；§2.3 则引入 shrinkage 控制新树的贡献。

加性更新与学习率(1)
ŷit=ŷit−1+ηft(xi)

其中 t 是迭代轮次，fₜ 是新树，η 是学习率。旧树通常不会在每轮重新优化全部参数。

02 · 树模型到底输出什么？

每棵回归树包含一个把输入特征映射到叶子编号的结构函数 q(x)，以及每片叶子的连续分数 wⱼ。样本走到第 j 片叶子时，树输出 wⱼ，并与其他树的分数相加。即使任务是分类，树的叶子仍通常是连续预测分数，而非直接写“正类”或“负类”。

论文把树复杂度放进训练目标，而不仅仅是手工限制深度：

树复杂度的正则化(2)
Ω(f)=γT+λ2∑j=1Twj2

γT 惩罚树的叶子总数，λ 控制叶子权重大小。剪枝、行采样与列采样等设置还会影响实际训练；这里聚焦 KDD 2016 论文中的基础推导。现代 XGBoost 另有 L₁ 正则和更多参数，不能反过来说这些配置都出自下面的简化目标。

03 · 为什么要用梯度和 Hessian？

在第 t 轮，旧模型预测是已知常量，新树的任务是让新预测的损失下降。论文 §2.2 对损失在旧预测附近作二阶泰勒展开，把每个样本的复杂损失压缩为两个局部统计量：一阶导 gᵢ 表示降低损失的方向，二阶导 hᵢ 描述局部曲率。

二阶目标的样本统计量(6)
gi=∂ℓ∂ŷ,hi=∂2ℓ∂ŷ2

于是每条样本的新树输出 fₜ(xᵢ) 参与 gᵢ fₜ(xᵢ) + ½ hᵢ fₜ(xᵢ)²，再加树的正则项。这里省略与新树无关的常数。对平方误差 ℓ=½(ŷ−y)²，有 g=ŷ−y 和 h=1；对二分类 logistic 损失也有非负 Hessian，但梯度表达式不同。

推导条件：损失需要可微并允许局部二次近似；下面每片叶子的分母 H+λ 必须为正。自定义目标或非凸 Hessian 需要额外检查。学习率 shrinkage 在树被拟合之后应用，不应误写进这一步二次目标的导数。

04 · 一片叶子的最优权重，从哪里来？

固定树结构后，所有落在第 j 片叶子的样本对同一个 wⱼ 贡献损失。定义 Gⱼ=Σᵢ∈Iⱼ gᵢ 和 Hⱼ=Σᵢ∈Iⱼ hᵢ。叶子目标整理为 Gⱼwⱼ + ½(Hⱼ+λ)wⱼ²，一元求导并令其为零得到：

固定树结构的最优叶子权重(3)
wj∗=−GjHj+λ

四个样本若 g=[0.5,0.5,−0.5,−0.5]，h=[1,1,1,1]，前后两条分别落在左右叶，则 G_L=1, H_L=2, G_R=−1, H_R=2。取 λ=1，左叶权重 −1/3，右叶 +1/3。

树结构的最优目标(4)
L∗=−12∑j=1TGj2Hj+λ+γT

05 · Split Gain：为什么这个阈值值得切？

我们既要降低损失，也不想无限增加叶子。把最优叶值代回目标后，比较切分后的两个叶子与切分前的父叶，得到论文 Eq. (7) 的正则化分裂增益：

XGBoost 的分裂增益(5)
Gain=12(GL2HL+λ+GR2HR+λ−GL+GR2HL+HR+λ)−γ

只有候选增益为正，才有理由接受该次分裂。以上样本在特征值 2 与 3 之间切、λ=1、γ=0.1 时，Gain=½(1/3+1/3)−0.1≈0.2333。这里的数值是按公式构造的教学算例，不是 KDD 的实测性能。

07 · Exact Greedy：从排序到最优局部分裂

论文 Algorithm 1 按每个特征排序样本，逐个候选位置扫描，用前缀和维护 G_L,H_L，并从该节点总和推得右侧 G_R,H_R。每移动一条样本只需更新统计量，然后按上式计算候选增益。

  1. 为当前轮计算每条训练样本的 g/h。
  2. 对当前节点每个可用特征排序，枚举相邻不同取值之间的阈值。
  3. 在排序序列上累加梯度与 Hessian，比较每一个有效阈值的 Gain。
  4. 记录收益最大的候选，再按节点增长规则递归生长。

这叫 exact greedy，并不是穷举所有可能树形或保证全局最优；大型数据下，排序与遍历细粒度阈值会成为瓶颈。

08 · Approx 与加权 Quantile Sketch

2016 年论文 §3.2 将近似分裂候选分为 global proposal 与 local proposal：前者每棵树开始时给出候选，后者允许每次划分节点后重新提出候选。只有候选集上的分裂会被评分，从而降低精确枚举的代价。

按 Hessian 质量计算分位(7)
r(z)=∑i:xik<zhi∑i=1nhi

如果两个位置之间样本数一样多，但 Hessian 质量差异很大，只按样本计数选择分位数就可能忽视二阶目标最敏感的区域。论文 §3.3 的 weighted quantile sketch 解决加权候选提出，并研究 merge/prune 的误差保障。

历史与现代实现要区分：目前官方文档的 tree_method="hist" 基于预分箱直方图；它与论文原文的 global/local approximate proposal 不是同一算法选项。请用版本对应的 Tree Methods 文档确认具体语义。

09 · Sparsity-aware：缺失值默认方向也是模型参数

特征缺失、one-hot 编码和稀疏矩阵都容易产生大量未存储项。如果每次找分裂都访问全部条目，会浪费大量时间。XGBoost 的稀疏感知算法只遍历有值条目，并对每个候选阈值比较“缺失走左”与“缺失走右”两个方案。

论文 Algorithm 3 写明这两个扫描方向，Fig. 5 在 Allstate-10K 的稀疏数据上报告，相比不感知稀疏的基础算法有 50 倍以上的速度差异。这是特定的稀疏度、硬件和实验条件，不能推成所有数据集上的普遍加速。

还应区分“语义上的缺失值”与“数值 0”：稀疏表示把哪些值当成未存储项，取决于输入数据与 API，不能无条件将零填补与缺失默认方向视为等价。

10 · 论文标题为何强调 Scalable System？

二阶优化并非 XGBoost 唯一贡献。论文 §4 将数据按特征预排序为 column block，复用有序扫描；同时分析 CPU cache、预取、磁盘数据压缩与 sharding。算法减少无谓扫描，系统布局减少不必要的数据搬运。

Block / Cache

列式排序使访问更连续，缓解随机内存访问和重复排序；多线程可以按列并行收集候选统计量。

Out-of-core

内存放不下时从磁盘块预取；列压缩和多盘分片提升有效 I/O 吞吐，但要权衡解压成本。

论文 §6.5 的 Criteo / AWS c3.8xlarge 实验里，压缩对应约 3 倍加速，再通过双 SSD 分片增加约 2 倍；最终方案单机处理约 17 亿条样本。这些是论文原实验环境的结果，不能称为当前任意硬件的预期加速。

11 · 最小代码与可验证的不变量

先不启动一个完整训练作业，而是用只依赖 Python 标准库的代码验证 Eq. (5) / Eq. (7)。下面是核心方法，配套完整文件 mini_xgboost.py 还包含阈值扫描、缺失方向比较及确定性断言。

def leaf_weight(G, H, lam=1.0):
    assert H + lam > 0
    return -G / (H + lam)

def gain(GL, HL, GR, HR, lam=1.0, gamma=0.1):
    left = GL**2 / (HL + lam)
    right = GR**2 / (HR + lam)
    parent = (GL + GR)**2 / (HL + HR + lam)
    return .5 * (left + right - parent) - gamma

assert abs(leaf_weight(1, 2) + 1/3) < 1e-12
assert abs(gain(1, 2, -1, 2) - (1/3 - .1)) < 1e-12

运行 python posts/classical-ml/xgboost/mini_xgboost.py。它是数学核验证，不是原论文系统实验复现。真实训练的模型 API、hist 与 approx 设置请见 官方 Python API。

13 · 与 GBDT、Random Forest 和现代 Hist 的关系

GBDT / Gradient Boosting

逐轮新增函数、改善当前损失，是整个方法家族的基本策略；XGBoost 是其中一套有系统优化的实现。

Random Forest

树通常通过 bootstrap 和随机特征子集相对独立地拟合，预测时平均/投票；不是逐步修正残差。

2016 年 XGBoost

二阶目标、正则化、weighted quantile、稀疏感知与 column block 是这篇论文的主线。

现代 XGBoost

包含 histogram 分箱、硬件加速、更多约束及接口演进；版本特性需要单独查文档。

树提升很适合许多结构化特征学习任务，但是否优于线性模型、神经网络或随机森林，应由目标数据及一致的实验协议决定。分布漂移、特征泄露、类别失衡、推理延迟和模型可解释性也需要实证检查。

14 · 从公式走向系统的阅读路径

  1. 预测：一棵新树为所有相关样本追加连续的叶子修正量。
  2. 目标：用 g/h 近似损失并惩罚叶子数与叶权重。
  3. 贪心：通过叶子最优分数推导 Gain，在候选阈值中选择有收益的分裂。
  4. 规模：加权候选、缺失值默认方向、排序列块和磁盘路径减少代价。
  5. 证据：把 Fig. 5 / Fig. 11 / Fig. 12 的数据集、硬件与测量维度留在结论里。
