# 数据与语料 / Datasets & Data Curation

本分类专门研究大型语言模型的训练数据：预训练语料、数据采集/清洗/去重、混合采样、版权与数据治理、数据污染，以及数据集质量的分领域评测。

## 内容

- [Understanding FineWeb](fineweb/index.html) — Penedo et al., NeurIPS 2024：Common Crawl、WARC 正文抽取、MinHash 去重、过滤器消融与 FineWeb-Edu。

- [The Pile: An 800GB Dataset of Diverse Text](the-pile/index.html) — 22 个来源、采样权重、BPB、受控模型实验与数据治理（发布状态以 `content/posts.json` 为准）。
