# Typed Decision Models & System One

研究在调用时定义问题、答案类型和有限候选项，并由模型返回类型化答案及概率分布的决策模型。

核心内容：Jev / System One、Choice、Score、Noul、Box 的版本边界；State 与 Questions 契约；并行原子判断；模型概率和 confidence 的区别；与生成式 LLM、传统分类器的比较。

延伸方向：open typed decision models、selective reasoning、model adaptation、decision delegation。
