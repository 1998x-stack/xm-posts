Understanding Embeddings

为什么文本可以变成向量，而向量接近并不等于语义完全相同？从矩阵查表、预测上下文，到对比学习和检索系统，沿原始论文重建机制。

Word2Vec 2013 → E5 2022预计阅读 32 分钟词向量 · 句向量 · 相似度 · 检索

01 · 为什么需要 Embedding？

“猫”和“狗”在词表中只是两组整数标识。我们希望它们在许多语境下共享统计结构，却不能把“词 ID 相邻”误认为“语义相近”。Embedding 的作用是给离散项目分配可由任务损失学习的连续参数。

One-hot 向量表达身份，但词与词彼此正交；稠密表示可通过预测邻近词、分类或对比配对等目标学习几何关系。近邻本身并不保证具有意义：使用的训练样本、损失、维度、文本领域都会改变空间。

先区分两个术语：Embedding layer 是矩阵查表；semantic embedding model 是将词、句或文档转成适合某个任务的表示的模型体系，两者不是同一层次。

02 · 查表究竟发生了什么？

设词表大小 V、向量维度 d；模型保存可学习矩阵 E ∈ ℝ^(V×d)。输入 token ID，取对应的行，比显式建立巨大的 one-hot 再乘矩阵更直接。重复的 token ID 在这一层访问同一行，而在后续上下文层可能变成不同 hidden states。

ei=Ei
EQ 1 E 的形状是 [V,d]；输入 [B,T] 得到 [B,T,d]，具体坐标与编号没有语义必然联系。

举个独立计算的例子：V=50,000、d=768 的 float32 表有 38,400,000 个参数，占 153.6 MB（十进制）。这是单张嵌入表的参数内存，而不是模型训练显存，也不是输出的单条句向量大小。

03 · Word2Vec：语义是从上下文预测中出现的

Mikolov et al. (2013) 的 CBOW 由上下文预测中心词，Skip-gram 由中心词预测窗口上下文。2013 年 NeurIPS 论文 引入 Negative Sampling，用正词对与噪声负例训练局部二分类目标，避免在每个样本上做完整词表归一化。

J=logσ(vw⊤uc)+∑j=1klogσ(−vw⊤unj)
EQ 2 最大化 J；v、u 为中心与上下文向量，c 是正例，nⱼ 是负例（Mikolov et al., 2013）。

训练目标中通常有中心词和上下文两套参数表；导出的词向量可能来自其中一套或组合，两种选择必须明确。可结合专篇 Understanding Word2Vec 进一步看 CBOW / SGNS 的推导。

04 · GloVe 的全局共现视角

GloVe (Pennington, Socher & Manning, EMNLP 2014) 使用词共现计数 Xᵢⱼ，优化加权最小平方目标：让 wᵢᵀw̃ⱼ+bᵢ+b̃ⱼ 逼近 log(Xᵢⱼ)。论文 Eq. (8) 的权重函数 f(Xᵢⱼ) 会改变不同共现数量的贡献；对数只针对正的共现项。

Word2Vec / SGNS

以局部中心词—上下文对和负采样驱动训练。

GloVe

以全局共现统计和加权回归作为目标。

二者学习的是以词条为中心的静态词向量；同一个词形在不同句子里通常仍从同一表取向量。

05 · 同一词，为什么需要不同的上下文向量？

“river bank”和“bank account”里的 bank 有不同含义。BERT 原始结构把 token、position、segment 的表示组合输入 Transformer；经上下文编码后，同一 token 在不同句子里的最终隐藏状态可以不同。

需要区分：输入 token embedding（查表）、contextual token representation（编码器输出），以及sentence embedding（整句压缩/任务优化后的向量）。直接用通用 BERT 的 [CLS] 并不保证具备出色的余弦检索空间，这也是 SBERT 的研究动机。

06 · 从一串 token 表示压缩成句向量

上下文编码器输出形状通常是 [B,T,d]。如果要建单向量索引，需要得到 [B,d]。常见方案包括 CLS、mean、max pooling；mean 时必须排除 padding，否则同一个句子在不同批次长度下可能得到不同向量。

s=∑t=1Tmtht∑t=1Tmt
EQ 3 mₜ=1 表示有效 token，0 表示 padding，且分母必须大于零。

Sentence-BERT (2019) 用孪生/三元组结构训练可独立比较的句向量，§3 讨论 CLS、MEAN 和 MAX，论文默认 MEAN。Pooling 本身不能代替为语义匹配设计的训练目标。

07 · 点积和余弦什么时候等价？

余弦考虑的是方向，点积还受向量长度影响。只有对非零向量做 L2 归一化后，点积才等于 cosine；单位向量之间的平方欧氏距离 = 2−2cosine，因此也与其排序单调相关。

cos(a,b)=a⊤b‖a‖·‖b‖
EQ 4 两个输入均非零；各自 L2 归一化之后，点积与余弦相等。

交互 · 单位向量夹角与相似度

两条二维向量始终为单位长度；选择角度查看解析几何结果。此处不是预训练模型 benchmark。

夹角 0°：cosine = 1.000，点积 = 1.000，平方 L2 距离 = 0.000。

单个向量相似度 0.8 并不意味着“有 80% 概率相关”；除非经过针对目标任务的校准，向量相似度不是概率。

08 · 为什么现代句向量使用对比学习？

SBERT 用孪生编码器与任务相关训练损失，使句子可以独立编码再比较。SimCSE (2021) 无监督方案用同一句话两次 dropout 前向作为正例，其他批内样本作为负例；监督方案采用 NLI entailment 正对，并使用 contradiction 难负例。E5 (2022) 通过弱监督文本对比预训练学习通用文本向量。

ℓi=−loges(qi,di)/τ∑j=1Nes(qi,dj)/τ
EQ 5 q、d 是查询/文档向量，s 是相似度，τ>0；这是单向 InfoNCE 示意式，不代表所有模型的全部损失。

对比学习优化的是相对区分与排序。温度 τ、样本构成、负样本质量、假负例都会影响训练信号，不同论文的损失结构也会增加对称性或 hard negative 处理。

09 · Embedding 如何变成向量检索与 RAG？

将 query 与 document 分别编码为固定维度向量，文档端可离线存储，查询端在线编码；按相似度执行 Top-k 候选召回后，再根据任务使用关键词、元数据过滤与交叉编码器精排。ANN 近邻索引在速度、内存与召回之间权衡，并不等同于数学精确 Top-k。

01 · Chunk 保留语义边界、标题、权限、来源与可追溯文档 ID。

02 · Encode 固定模型版本、tokenizer、pooling、归一化与输入模板。

03 · Index 将文档向量和原文映射存储，并量化 ANN recall 与延迟。

04 · Rerank 必要时混合 BM25、元数据过滤、cross-encoder 或业务规则。

E5 的对应模型卡 要求在检索时为 query 和 passage 采用不同前缀；这是该模型家族的使用协议，不能推广到所有 Embedding 模型。

10 · 如何科学地验证向量质量？

STS 通常评估文本相似度与人工相关性标注的相关程度，而检索任务需要在明确的查询与文档相关性标注上计算 Recall@k、MRR@k、nDCG@k。还要报告 P95 延迟、索引体积、更新成本、ANN 相对于精确排序的召回率。

Recall@k

Top-k 结果命中的相关文档占全部相关文档的比例。

MRR@k

每个查询首个相关结果排名的倒数后求平均。

nDCG@k

分级相关性在靠前位置获得更高权重。

系统指标

尾延迟、吞吐、内存、向量更新与过滤正确性。

对比前应固定训练/测试切分、领域、语种、chunk 大小、是否做 rerank、是否存在泄漏。不同论文的数据集分数不能简单横排成现代 RAG 模型排行榜。

11 · 误区、边界与失败案例

否定与数字 “可退款”和“不可退款”字面接近，却在业务上相反。

多义词 静态词向量不能直接根据当前上下文消歧。

长文压缩 单向量可能丢失多主题或细粒度实体信息，必要时多 chunk 与混合检索。

版本漂移 不同 encoder/normalize 版本的向量可能不在同一可比较空间。

安全与权限 向量不等于匿名化，删除索引与权限过滤必须独立设计。

Embedding 是可训练的近似表示，不自动等于事实正确性、逻辑推理或检索系统的可靠性。

12 · 用纯 Python 验证算子与边界条件

仓库提供 mini_embedding.py，实现 lookup、masked mean、cosine、Top-k；没有下载模型，不是 Word2Vec 或 SBERT 的实验复现。

from mini_embedding import lookup, masked_mean, cosine, topk
states = lookup([0,1,2], [[1.,0.],[0.,1.],[0.,0.]])
q = masked_mean(states, [1,1,0])
assert abs(cosine(q, [1.,1.]) - 1.0) < 1e-12
print(topk(q, {"A":[1.,1.], "B":[-1.,0.]}, 2))

完整代码见 mini_embedding.py，对应确定性测试为 tests/test_embeddings.py。
