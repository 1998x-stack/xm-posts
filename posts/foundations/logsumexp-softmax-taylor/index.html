Understanding LogSumExp & Softmax Taylor Expansion

为什么把 logits 减去均值，就会在 LogSumExp 中看到方差，并在 Softmax 中得到一个可用于 Attention 的线性近似？

中心化 · 累积量 · 归一化 · 线性注意力苏剑林 · 2026-07-13阅读约 28 分钟

01 · 为什么 Softmax 近似必须先看平移？

假设四个 token 的得分是 −1、0、1、2。把它们全部加 10，并不会改变注意力分配：竞争关系没变。可是，直接把每个指数函数在 0 附近截断，数值会发生巨大改变。

这意味着，研究 Softmax 的泰勒展开，起点不该是逐项截断 exp(xᵢ)，而应先利用整体平移不变性，把有意义的差异与无意义的整体偏移分离。LogSumExp（下称 LSE）恰好把这两件事连接起来。

L(x)=log⁡(∑i=1nexi),L(x+c1)=L(x)+c
(1)

对任意实数 c，Softmax(x + c1) = Softmax(x)。与之配对的是 LSE 的平移等变性：LSE(x + c1) = LSE(x) + c。数值计算里常取 c = −max(x) 来防止指数溢出；下文推导则选 c = −均值，让中心矩自然出现。这两种平移用于不同目的。

02 · 先固定记号与展开的“方向”

给定 n 个有限实数 logits，记 μ 为平均值、δᵢ 为中心化偏差、mᵣ 为 r 阶中心矩。m₁ = 0，m₂ ≥ 0，m₃ 刻画偏斜。这里不是对样本统计量做随机估计，而是对固定有限向量做确定性代数。

μ=1n∑i=1nxi,δi=xi−μ,mr=1n∑i=1nδir
(2)

要得到标准、可检查的泰勒级数，引入一个标量 λ，研究 x(λ) = μ1 + λδ 在 λ = 0 附近的变化。λ = 0 时所有位置相同，Softmax 正好均匀。后续 O(λᵏ) 都表示在固定 n、固定 δ 下、λ → 0 的局部余项；不能随意把 n、δ 同时扩大而沿用同一个误差常数。

03 · LogSumExp：均值之后为什么出现方差？

先抽走均值，再把求和看成对均匀下标的期望：L(μ1 + λδ) = log n + μ + log E[exp(λδ)]。最后一项是中心化离散分布的累积量生成函数。这让方差、偏度及四阶累积量依次显露，而不是偶然凑出来的系数。

L(μ1+λδ)=log⁡n+μ+λ22m2+λ36m3+λ424(m4−3m22)+O(λ5)
(3)

推导只需要两步：先展开 exp(λδᵢ) 并对 i 求平均，因为 m₁ = 0，所以期望形如 1 + λ²m₂/2 + λ³m₃/6 + λ⁴m₄/24 + …；再展开 log(1+u) = u − u²/2 + …。正是后一步产生了 −3m₂²/24。

一阶为什么消失？ 不是 LSE 永远没有一阶项，而是我们选择了零均值方向 δ。在一般方向 h 上，LSE 的一阶变化不为零，等于 Softmax 加权平均的 h。

04 · 一个 Hessian，看清局部几何

对 LSE 求一次导数，得到 Softmax 概率 pᵢ；再求一次导数，得到 H = diag(p) − ppᵀ。对任何方向 h，二次型 hᵀHh = Varₚ(h) ≥ 0。这里 δᵢⱼ 是 Kronecker 符号，与上文的中心化 δᵢ 不同。这同时证明 LSE 凸，说明它对整体平移方向不敏感，也揭示了局部曲率由加权方差决定。

∂L∂xi=pi,Hij=pi(δij−pj)
(4)

当所有 logits 相同，pᵢ = 1/n。这时沿 δ 方向的曲率恰好是 m₂，所以 LSE 的二阶修正是 m₂/2。这个矩阵是概率分布的协方差结构，而不是 Hessian 恰好“看起来像一个投影”的偶然公式。

05 · Softmax 的三阶概率修正

从 pᵢ(λ) = exp(λδᵢ) / Σⱼexp(λδⱼ) 出发，同时展开分子与分母。零阶是均匀分布；一阶将概率质量沿中心化 logits 重新分配；二阶必须减去全局 m₂，才不会让所有概率的和偏离 1。

pi(λ)=1n[1+λδi+λ22(δi2−m2)+λ36(δi3−3m2δi−m3)]+O(λ4)
(5)

由 Σδᵢ = 0、Σ(δᵢ² − m₂) = 0、Σ(δᵢ³ − 3m₂δᵢ − m₃) = 0 可知：每一阶截断的总和都严格等于 1（忽略浮点舍入）。但这不是非负性的证明：例如很大的 λ 可能使一阶近似给出负概率。

pi(x+εh)=pi(x)+εpi(x)(hi−∑j=1npjhj)+O(ε2)
(6)

上式关于均匀基点展开。若要在任意已知 logits x 周围移动小方向 εh，正确的一阶导数使用基点的 p(x) 加权均值，而不是无条件使用算术平均。这是阅读各种“Softmax 线性化”公式时最容易混淆的基点问题。

06 · 什么时候近似会失效？

泰勒级数的精度取决于中心化得分的幅度：若 |λδᵢ| 普遍很小，高阶项较小；如果 logits 分离明显，精确 Softmax 接近 one-hot，而任意固定阶的多项式未必能捕捉指数优势。误差大小也依赖采用的范数与数据分布。

可以合理尝试

对分散程度已受控的 logits 做分析、给出局部梯度/曲率解释，或作为需要误差诊断的候选注意力近似。

不能直接替换

概率必须非负的采样器、强对比 logits、多极端 token 的精确检索，或没有补偿机制就要求和原模型逐点一致的注意力层。

一个重要区分：这里近似的是整个归一化 Softmax，不同于用有限阶多项式近似 exp 后再重新归一化得到的 Taylor Softmax 变体；两者的权重非负性、归一化与可重排计算特性需要分别验证。

08 · 一阶展开如何线性化 Attention？

将某个 query 的有效 key 得分记作 zⱼ = qᵀkⱼ/√d。对长度为 t 的有效前缀做一阶 Softmax 展开，得到权重 wⱼ ≈ 1/t + (zⱼ − z̄)/t。于是输出 y = Σⱼ wⱼvⱼ 的近似，分解为Value 均值 + Query 与 key-value 相关量 − 均值乘积校正。

y~t=Svt+qt⊤Skvtd−(qt⊤Sk)Svt2d
(7)

其中 qₜ、kⱼ ∈ ℝᵈ，vⱼ ∈ ℝᵈᵥ，Sₖ ∈ ℝᵈ，Sᵥ ∈ ℝᵈᵥ，Sₖᵥ ∈ ℝᵈˣᵈᵥ。公式保留 1/√d 的常见 scaled-dot-product 约定；若论文使用不同缩放，需要调整。这里是以平坦 logit 为基点的教学级一阶状态近似，并非声称它能无损替换 pretrained Transformer。

09 · 因果前缀怎样变成可更新的状态？

Sk=∑j=1tkj,Sv=∑j=1tvj,Skv=∑j=1tkjvj⊤
(8)

第 t 步只需把新的 kₜ、vₜ 和 kₜvₜᵀ 加入上一时刻状态。随后使用公式 (7) 计算 ỹₜ。相对于每个 query 访问 t 个历史 token 的精确点积注意力，这个固定维度状态令单步关于序列长度的代价不再显式依赖 t；其代价仍随 d、dᵥ 变化，且对训练并行、数值稳定性与 GPU 实现不能只用“线性”二字判断。

对于 causal mask，应只在 j ≤ t 的有效前缀上统计；padding mask 也应从计数和求和中排除。切勿将 −∞ 掩码当成普通实数带入泰勒展开。位置偏置、温度、旋转位置编码等都会改变 logits，也就改变适用的扰动区间。

10 · 与 Gated DeltaNet 论文是什么关系？

苏剑林在 2026 年 7 月的文章以《The Key to Going Linear: Analysis-Driven Transformer Linearization》为背景讨论展开法。Kuzina 等人的论文则进一步研究冻结预训练主干时，哪一种线性状态更新最能保留 Softmax 注意力行为，并分析与 key 相关的 rank-1 修正，比较核方法、纯门控累积与 Delta 类型更新。论文原文。

本文公式 (7) 是一阶均匀中心化带来的Vanilla 状态近似，其中不存在论文 Gated DeltaNet 的 key 依赖遗忘/写入算子。因此不能从公式 (7) 推出“等价于 GDN”，更不能把论文所述 downstream 质量保留直接归因于这个简单公式。论文的 sink tokens、局部窗口与短卷积是补偿结构，不是泰勒展开自动产生的性质。

读者若关注“从近似关系到具体 recurrent 更新规则”，建议回到原论文 Section 3 的不同状态更新定义，再分别检查实验设定与消融证据，而不是将各类线性 Attention 混为一谈。

11 · 数值实现、Mask 与工程边界

  • 精确计算：实际 LSE/Softmax 使用减去最大值的稳定实现，不能为了展开推导中的“减均值”而忽略溢出风险。
  • 近似条件：监测中心化 logits 的极值和离散程度；如截断概率出现负值，不能将其直接当概率用于采样或交叉熵。
  • 前缀归一化：因果 attention 每个 t 有独立的 t、Sₖ、Sᵥ 和 Sₖᵥ，不能错把全序列统计量提前泄露到当前位置。
  • 性能边界：数学重排只说明存在固定状态表达；不能自动保证精确召回、同等训练效果、低延迟或对硬件更高效。
  • 局部与全局：三阶截断维持和为 1，不代表非负性与精确注意力的因果选择行为被保留。

12 · 最小可运行验证

下面的核心断言可用 Python 标准库执行。完整实现保存在文章源码目录的 mini_softmax_taylor.py，包含稳定 LSE、中心化、多阶截断与单前缀 Attention 公式。它只用于验证代数性质，不复现实验模型。

from math import exp, isclose
x = [-1.3, -0.3, 0.4, 1.2]
def softmax(a):
    m = max(a)
    z = [exp(v-m) for v in a]
    return [v/sum(z) for v in z]
assert all(isclose(a,b,abs_tol=1e-12)
           for a,b in zip(softmax(x),softmax([v+1000 for v in x])))
mean = sum(x)/len(x)
delta = [v-mean for v in x]
first = [(1 + .2*v)/len(x) for v in delta]
assert isclose(sum(first), 1.0, abs_tol=1e-12)
print("shift invariant; first-order normalized")

再把 λ 从 0.4 减小到 0.2：固定 δ 时，一阶误差的主导阶通常是 O(λ²)，二阶误差是 O(λ³)，但特殊向量可能使某些系数消失。因此数值实验应报告实际误差，而非仅凭“高阶一定更准”作全域断言。

13 · 结论、来源和进一步阅读

这一推导最值得保留的结构是：减均值 → 中心矩/累积量 → 归一化概率修正 → 可维护的 Attention 前缀状态。每一步都伴随局部条件和严格的版本边界。
