Understanding SGD

既然每个样本只提供不完整的梯度，我们为什么还愿意立即更新参数？从随机逼近、Mini-batch 与梯度噪声，到大规模学习的算力权衡。

Robbins–Monro 1951 → Bottou 2010预计阅读 30 分钟随机优化 · 批量策略 · 数学证明

01 · 为什么不先算完所有梯度？

假设模型在训练集上有一百万个样本。普通梯度下降每次更新都要计算一百万项的平均梯度；如果我们只看其中一个样本，就立刻修改参数，会不会被这个样本“带偏”？

SGD 的关键并不是声称单样本梯度更准确，而是：很多情况下，早期低成本而带噪的进步，比等待一次昂贵的精确梯度更划算。这是 Bottou（2010）在大规模学习中讨论的中心权衡，而非对任何任务的无条件性能保证。

历史辨析：Robbins 与 Monro（1951）研究的是随机逼近与带噪观测求根，不应被描述为已经提出了现代神经网络中的 Mini-batch SGD、反向传播训练系统或 GPU 实现。

02 · 全批量梯度下降在算什么

设训练样本为 zᵢ=(xᵢ,yᵢ)，每份损失为 ℓᵢ(θ)=ℓ(θ;zᵢ)；参数向量 θ∈ℝᵈ，训练集规模 n。经验风险及其全量梯度是：

F(θ) = (1/n) Σᵢ₌₁ⁿ ℓᵢ(θ)
∇F(θ) = (1/n) Σᵢ₌₁ⁿ ∇ℓᵢ(θ)假设样本损失可微并且可交换有限求和与求导。梯度、参数都是 d 维向量；平均是沿样本维而非参数维。

Batch GD 的一步更新是 θₜ₊₁=θₜ−ηₜ∇F(θₜ)。它使用在同一个 θₜ 处得到的所有样本梯度。对高维大数据集，一步可能非常昂贵；但这不意味着 GD 在小数据或要求高精度的任务中没有优势。（Bottou 2010，§2.1，Eq. 2）

03 · SGD：一次只听一个样本

SGD 把整个数据集的平均换成随机选中的一个样本：

iₜ ∼ Uniform({1,…,n})
gₜ = ∇ℓᵢₜ(θₜ) ∈ ℝᵈ
θₜ₊₁ = θₜ − ηₜgₜ上式是“均匀有放回抽样”的清晰数学模型。实际训练常用无放回的 shuffle 每轮遍历样本，采样依赖关系随之改变。

“随机”发生在样本选择而非导数本身；已知样本和当前 θ 后，通常仍是对该样本执行确定的求导。（Bottou 2010，§2.2，Eq. 4）

04 · 无偏性不是“每一步都正确”

SGD 所依赖的不是“抽样总是代表总体”，而是特定抽样方案下的条件期望。

E[gₜ | θₜ] = (1/n) Σᵢ₌₁ⁿ ∇ℓᵢ(θₜ) = ∇F(θₜ)适用于给定 θₜ、均匀有放回随机抽样；若改变采样概率或重新加权，需重新检查无偏性。

如果把样本抽取概率变成按难例偏置、又没有重要性权重修正，随机梯度的期望可能不等于目标训练集的原始均值。这一细节在负采样、分层采样和大规模数据流水线中都很关键。

05 · Mini-batch：在成本与噪声之间折中

现代训练经常每次取一个样本集 Bₜ，求平均梯度再更新：

gᴮₜ = (1/|Bₜ|) Σᵢ∈Bₜ ∇ℓᵢ(θₜ)
θₜ₊₁ = θₜ − ηₜgᴮₜMini-batch 大小 B 是样本数；损失按 sum 还是 mean reduction 会改变梯度尺度，应与学习率解释一致。

在独立同分布抽样、每份梯度具有有限协方差 Σ、并且固定 θ 时，批量均值的协方差为 Σ/B。这个经典 1/B 结论依赖采样假设；相关样本、无放回抽样与非均匀权重会带来修正。更大的 B 可能提升设备利用率，但不保证按比例加速训练或改善泛化。

06 · 为什么路径会摇摆？

一个样本给出的下降方向可能只是局部意见。训练损失曲面上的参数可能一边向目标区域靠近，一边因为样本噪声在谷底附近往返。

形式化地写 gₜ = ∇F(θₜ) + ξₜ，在理想无偏条件下 E[ξₜ | θₜ]=0。同一个步长既放大目标梯度，也放大随机噪声。接近极小值时真实梯度逐渐缩小，噪声的相对影响就可能更显著。

07 · 学习率与随机逼近的条件

学习率 ηₜ 是对随机梯度意见的信任程度。太大可能使参数越过谷底或震荡；太小则花很久才能移动到有用区域。

Σₜ ηₜ = ∞, Σₜ ηₜ² < ∞经典 Robbins–Monro 型步长条件；只有配合恰当的目标函数、噪声、迭代有界性等假设，才可用于相应收敛证明。

例如 ηₜ=c/(t+t₀)（c>0、t₀>0）满足上述两级求和条件。常数学习率在带噪情形下通常不保证精确收敛到某个点；但在非凸深度学习中，它可能是训练策略的一部分，不能把这个凸随机逼近定理当成现代网络的普遍保证。（Bottou 2010，§2.2）

09 · 极简 Python：把更新写出来

下面是最小更新核。为了让数学细节透明，独立文件 mini_sgd.py 仅依赖 Python 标准库，并能处理向量参数、batch 平均、朴素 Momentum 和学习率计划。

def sgd_step(theta, batch_gradients, lr):
    batch_size = len(batch_gradients)
    mean_gradient = [
        sum(g[j] for g in batch_gradients) / batch_size
        for j in range(len(theta))
    ]
    return [p - lr * g for p, g in zip(theta, mean_gradient)]

该代码假设输入已经是每样本梯度；它不包含自动微分、数据并行同步、梯度裁剪、梯度累积或混合精度。配套 tests/test_sgd.py 验证精确均值、期望无偏、学习率计划与简化 Momentum 的行为。

注意框架常把 Mini-batch SGD 简称为 “SGD”。在训练代码中，通常按一个 batch 执行 forward/backward 后 optimizer.step()，并不是对每个样本各自执行一次参数更新。

10 · 优化误差不等于泛化误差

“训练损失下降快”与“预测误差下降快”是两个目标。Bottou 2010 的关键讨论是固定计算预算下，是否值得把已经足够好的训练目标继续优化得极精确。

经验风险不是未知数据分布上的预期风险。对很大的训练集，SGD 虽然带噪、经验目标未必精确最优，却可能以更少计算获得有竞争力的测试性能；相反，对小样本或高精度优化问题，全量方法与其他方法可能更有效。原论文将这些情况放在不同计算预算下分析（§3, Table 2）。

12 · Momentum、ASGD 与 Adam

Vanilla SGD

只依赖当前抽样梯度，更新核 θ←θ−ηg。没有逐坐标历史状态。

Momentum SGD

额外维护速度向量，积累更新方向。和纯 SGD 不同；不同框架在 dampening/Nesterov 等参数下采用不同约定。

ASGD（平均随机梯度）

通过迭代均值平滑参数估计。Bottou 2010 §4, Eq. 12 讨论 Polyak–Juditsky 平均。

Adam / AdamW

维护梯度一阶、二阶矩，自适应调整坐标尺度；不是 SGD 的数学同义词。参见 Adam、AdamW。

也要区分动量缓冲与参数平均：Momentum 作用于每次梯度更新，ASGD 另行统计参数迭代的平均值。对于论文里 SGDQN 的二阶近似，亦不能当成原始 SGD 算法本身。

13 · 真实训练系统中的边界

训练环节需要澄清的含义
Batch size 与梯度累积若模型、样本、损失归一化一致且中途不更新参数，分批累积平均梯度可在精确算术下等价于一次较大 batch；浮点舍入、BatchNorm 等可破坏严格等价。
Shuffling随机打乱后无放回遍历与均匀有放回抽样的理论不是逐步骤完全相同，虽然实践中都常被叫作 SGD。
Learning-rate scheduleWarmup、余弦退火和分段调度是工程选择；不要把经典 η∝1/t 定理直接套到这些计划上。
Momentum / weight decayPyTorch SGD 支持多个选项；若启用 Momentum 或 weight decay，就必须在复现协议中记录，而非笼统报告“SGD”。
GPU 性能较大的 batch 可能提升矩阵计算利用率；最少样本/步与最少墙钟时间、最快达到目标验证指标不是同一个优化目标。
适用范围：这里的无偏性与方差公式基于明确采样假设；收敛讨论需要凸性、平滑性或其他限制；论文测试数据是特定年代的任务。本文代码是可验证的教学更新器，不声称复现论文 RCV1 / ALPHA / CONLL 的实测性能。

14 · 将直觉变成可复查的结论

SGD 最有用的心智模型是：用有噪声、成本更低的梯度估计来推进参数；用学习率控制噪声；用批量大小控制单步统计精度和计算代价。

当训练不稳定时，先确认梯度是在同一个 θ 上计算、样本平均还是求和、随机抽样是否有偏、学习率如何变化；再把观察与优化目标、测试指标分开评价。
