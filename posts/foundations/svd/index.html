Understanding SVD

一个矩阵如何把空间变形，又为什么只保留少数几个方向就能重建大部分信息？从圆和椭圆开始，一步步走向奇异值、低秩近似、PCA 和数值计算。

Singular Value DecompositionEckart & Young · 1936预计阅读 26 分钟

01 · 为什么要把一张大矩阵拆开？

想象有一张「用户 × 电影」评分表：行和列都很多，但真正支配打分的因素可能只是少数几个，例如动作偏好与剧情偏好。我们希望把它压缩成若干个容易理解的方向，同时知道丢掉的到底有多少信息。

矩阵可能并不稀疏，也不一定是方阵。直接对它做特征值分解往往没有定义；SVD 的价值在于：任何实矩阵都存在这样的正交分解。它把“方向”与“强度”分开，并提供一套可以精确量化压缩误差的语言。

压缩

保留前 k 个结构最显著的方向，用更小的表示近似原矩阵。

解释

把输入方向、输出方向、响应幅度与零空间分别看清。

本文研究实矩阵 A ∈ ℝm×n。复矩阵版本需要共轭转置 Vᴴ，而不是普通转置；本篇公式不把两者混同。

02 · 从单位圆看见奇异值

取二维单位圆上所有向量，逐个施加线性变换 A。通常得到一只倾斜的椭圆：一个主轴被拉长，另一个主轴被缩短。椭圆半轴的长度，就是奇异值 σ₁、σ₂；轴的方向，与左右奇异向量相关。

更精确地说，V 的列给出输入空间的主方向；沿第 i 个方向输入一个单位向量，A 的输出就是 σᵢ 倍的第 i 个左奇异向量。如果 σᵢ = 0，这个方向会被完全压扁，落在 A 的零空间中。

这里“旋转”只是直观比喻：正交矩阵也可能包含镜像反射；高维情形是超球面映射到椭球体。

03 · U、Σ、Vᵀ 究竟各做什么？

A=UΣV⊤
(1)

对 A ∈ ℝm×n，令 q = min(m,n)。薄 SVD（economy SVD）使用 U ∈ ℝm×q、Σ ∈ ℝq×q、Vᵀ ∈ ℝq×n。Σ 是非负对角矩阵，奇异值按非增顺序排列；U 和 V 具有正交列。

从右向左理解相乘：Vᵀ 把输入投影到一组正交方向，Σ 沿这些方向缩放，U 将结果放回输出空间。分解不是唯一的：奇异向量可同步翻转符号；重根对应子空间还允许旋转。因此研究的是子空间和奇异值，而不是某一列向量的唯一朝向。

04 · 从特征值问题推导 SVD

AᵀA 是 n×n 的对称半正定矩阵，所以存在非负特征值和一组正交特征向量。这些特征值恰好是奇异值的平方：

A⊤Avi=σi2vi
(2)

对于非零奇异值，我们定义对应的左奇异向量：

ui=Aviσi，当σi>0
(3)

于是 Avᵢ = σᵢuᵢ；当 i ≠ j 时，uᵢᵀuⱼ = (vᵢᵀAᵀAvⱼ)/(σᵢσⱼ) = 0，且每个非零 uᵢ 的范数为 1。剩余的向量可以补全为正交基，构成完整 SVD。

这是数学推导，不是推荐的数值算法。实际计算应使用稳定的 SVD 例程；先构造 AᵀA 可能使条件数平方，丢失小奇异值的精度。

05 · 秩一项：矩阵中的分层结构

沿着正交方向展开，整个矩阵等于若干个秩一外积之和。设 r = rank(A)，则：

A=∑i=1rσiuivi⊤
(4)

每个外积 uᵢvᵢᵀ 都是 m×n 矩阵（当系数非零时秩为 1），σᵢ 决定这个结构贡献的大小。若前几项占据大部分能量，我们就能删去较小项，只留下主要模式。

值得区分：低秩假设是一种建模选择。对噪声近似独立、谱衰减缓慢的数据，前几个奇异值可能并不能很好代表原矩阵；压缩有效并非普遍事实。

06 · 为什么截断是最优低秩近似？

给定目标秩 k（0 ≤ k < r），保留最大的 k 个奇异值及其向量：

Ak=∑i=1kσiuivi⊤
(5)

Eckart–Young 定理说明，这个 Aₖ 在所有秩不超过 k 的矩阵中，同时最小化 Frobenius 范数误差和谱范数误差。Frobenius 误差可以直接由丢弃的奇异值求出：

‖A−Ak‖F2=∑i=k+1rσi2
(6)

对谱范数，若 k < r，还有 ‖A − Aₖ‖₂ = σₖ₊₁；对 k = r，两种误差都为 0。最优解可能不唯一，尤其在截断位置存在相等奇异值时。

关键逻辑是：正交变换不改变这两类范数；把问题变换到 Σ 的坐标系后，任何秩 k 的候选都无法消除第 k+1 个方向及更小方向的全部残差。严谨证明与历史表述可以追溯到 Eckart & Young (1936) 及 Johnson (1963)。

07 · 交互实验：rank 与能量

现在把理论放进一个可精确手算的教学矩阵：A = diag(9, 4, 2, 1)。它的奇异值恰好是 [9, 4, 2, 1]；总平方能量为 9²+4²+2²+1²=102。

Ek=∑i=1kσi2∑i=1rσi2
(7)

能量比例与“解释方差”的概念相关，但并不等于任何下游任务的准确率。而且小矩阵 k=2 的低秩存储可能反而比原矩阵更大，压缩要在大规模、低秩情形才可能有收益。

08 · SVD 如何连接 PCA？

假设 X ∈ ℝn×d，每一行是一个样本，每一列是一个特征。先按列减去均值，形成中心化的 X。对它做 SVD，V 的列就是 PCA 的主方向，UΣ 则给出样本在这些方向上的坐标。

X⊤Xn−1=VΣ2n−1V⊤
(8)

这里的分母 n−1 是样本协方差的常见定义；若使用总体协方差，则分母改为 n。中心化不可省略：不中心化直接取 V，得到的是数据原点意义下的能量方向，不自动等于常规定义的 PCA。标准化各列方差也不是 SVD 的内置步骤。

PCA 是一种统计建模方法；SVD 是可用于实现 PCA 的线性代数分解。二者有关联，却不能当作完全同义词。

09 · 伪逆、最小二乘与不稳定性

对不一定方阵、可能秩亏的 A，常通过 Moore–Penrose 伪逆寻找最小二乘解 x* = A⁺b。分解后，只需对非零奇异值取倒数，并交换左右方向：

A+=VΣ+U⊤
(9)

当奇异值非常小时，1/σ 会很大，测量噪声因此在逆问题中被放大。对于满列秩或满行秩矩阵，常用条件数衡量这种敏感性：

κ2(A)=σmaxσmin
(10)

需要小心：对秩亏矩阵，如果讨论从所有输入到输出的可逆性，条件数应视为无穷；只看「非零奇异值的比值」会隐藏零空间方向。实际中可以采用奇异值阈值、截断 SVD 或 Tikhonov / ridge 正则化控制放大，但它们改变了原问题。

10 · 工程选择：完整、薄、随机化

做法适用情形需要警惕
完整 SVD需要 U、V 的完整正交基中间矩阵尺寸可能非常大
薄 SVD需要重建、PCA、常规低秩分析仍可能计算全部 q 个奇异值
截断 / partial SVD只需要前 k 个大奇异值迭代法的收敛和谱间隙影响表现
随机化 SVD大型矩阵、低秩结构明显属于近似方法，结果依赖采样、迭代与随机性

对于密集 m×n 矩阵，计算完整 SVD 的常见时间复杂度量级为 O(mn·min(m,n))，具体依赖算法与形状。Halko、Martinsson 与 Tropp (2011) 研究了以随机投影捕获主导子空间，再在较小矩阵上计算分解的框架；它不是「求一遍普通 SVD 然后扔掉尾部」的同义改写。

在 GPU/LLM 工程中，低秩近似可用于权重压缩或低秩增量，但保留能量不等于保留任务质量；性能还取决于矩阵布局、批量、内存带宽、kernel 选择、额外乘法与数值精度。实践中应同时报告误差、延迟、吞吐、显存，不能只报告压缩率。

11 · 可运行的最小数值验证

NumPy 的 np.linalg.svd(A, full_matrices=False) 返回 U、奇异值一维数组 s 和 Vh（实矩阵时即 Vᵀ）。注意返回的是 Vh 而不是 V；重建时直接使用 (U * s) @ Vh，无需手工对矩阵列做不匹配的广播。

import numpy as np

# pip install numpy ; 这是确定性算例，不是论文实验复现
A = np.array([[3., 0.], [0., 2.], [0., 0.]])
U, s, Vh = np.linalg.svd(A, full_matrices=False)
assert U.shape == (3, 2) and s.shape == (2,) and Vh.shape == (2, 2)
assert np.allclose((U * s) @ Vh, A)
assert np.allclose(s, [3., 2.])

k = 1
Ak = (U[:, :k] * s[:k]) @ Vh[:k, :]
assert np.linalg.matrix_rank(Ak) == 1
assert np.isclose(np.linalg.norm(A - Ak, "fro"), 2.)
assert np.isclose(np.linalg.norm(A - Ak, 2), 2.)

# 不要直接对 A.T @ A 求 eig 来替代稳健 SVD:
# 当条件数很大时，平方会放大数值问题。
print("SVD reconstruction and rank-1 error OK")

脚本见仓库 mini_svd.py。先安装 numpy，运行 python posts/foundations/svd/mini_svd.py。断言覆盖形状、精确重建、秩一截断以及 Frobenius / 谱范数误差；该算例不是大规模性能评测。

12 · 证据、适用边界和阅读

本文的最优性结论属于数学定理；1936 年论文研究的是更低秩矩阵逼近，而不是现代深度学习的实验基准。Σ=[9,4,2,1] 与其交互数值完全是教学构造。随机化 SVD 与 NumPy API 是后续研究和现代实现，不应追认到 Eckart–Young 的原文。

  1. Eckart, C. & Young, G. (1936). The Approximation of One Matrix by Another of Lower Rank. Psychometrika 1(3), 211–218。最优低秩问题的历史来源。
  2. Johnson, R. M. (1963). On a Theorem Stated by Eckart and Young. Psychometrika 28(3), 259–263。对原先陈述定理的证明。
  3. Stephen Boyd. EE263 Course Reader. SVD 几何、伪逆、低秩逼近与最小二乘。
  4. NumPy: numpy.linalg.svd. API、thin/full 形状与重建的工程依据。
  5. Halko, N., Martinsson, P.-G. & Tropp, J. A. (2011). Finding Structure with Randomness. SIAM Review 53(2), 217–288。随机化低秩方法。
