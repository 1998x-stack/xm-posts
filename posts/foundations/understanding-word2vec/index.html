Understanding Word2Vec / An illustrated deep dive

词，如何找到
自己的位置？

Word2Vec 的惊人之处，不在于它把词变成了一串数字。而在于：只要反复预测词语出现的上下文，向量空间里就会慢慢长出相似、关联，甚至某些可计算的语义关系。

两篇 Mikolov 2013 论文原理 → 公式 → 代码 → 证据可离线阅读
01 · The question

词可以是编号，但编号不懂相似。

假设词表里有 cat、dog、Paris。一个普通词典会把它们编码为 17、42、91。这样的 ID 只告诉计算机“它们不同”，完全不知道 cat 与 dog 的关系比 cat 与 Paris 更近。

One-hot 同样如此：每个词是一根互相正交的坐标轴，不带语义距离。分布式表示想做一件更有野心的事：将每个词放到一个低维、可学习的坐标空间里。

分布假设的直觉

词的意义在某种程度上可以从它的语言环境中推断：经常出现在相似上下文里的词，可能有相近的功能或含义。它不是逻辑定理，也不保证消除歧义、偏见和词序信息。

Word2Vec 的设计是把这个直觉变成一个廉价的预测任务：不要求人类标注语义关系，只利用原始文本中的词与上下文。

03 · Two directions

同一个窗口，两种相反的预测方向。

2013 年的第一篇论文提出两种低计算成本的架构。它们共享思想，却改变了输入和目标的方向。

每一组 (center, context) 都构成预测任务；一个中心词通常对应多个正例。

CBOW

上下文向量求和/平均，再预测中心词；共享投影参数。通常计算高效，对常见词的学习很有效。

Skip-gram

每个中心词对应多个上下文预测，计算量与窗口内目标数相关；在原论文部分语义任务中有优势。

“CBOW 更快 / Skip-gram 更善于稀有词”是常见经验概括，不是对所有语料、实现和任务的保证。

04 · The representation

所谓神经网络的第一层，其实是一张表。

设词表大小为 V，向量维度为 D。模型有输入向量矩阵 W_in ∈ R^(V×D) 与输出向量矩阵 W_out ∈ R^(V×D)。输入词的 one-hot 向量 x 与矩阵相乘，实际上只是在取出对应的一行：

h=WinTx=Win[wordid]∈RD

训练过程中，输入表与输出表都会被更新。原始 Word2Vec 的常见导出方式是取 W_in（C 实现中的 syn0），而不是把二者混成一张“唯一”的 embedding 矩阵。

05 · Computational bottleneck

如果每预测一个词，都要考虑整本词典呢？

Skip-gram 可以采用一个普通的 Softmax 输出层。输入中心词 c，希望预测目标上下文词 o：

P(o|c)=exp(uo·vc)∑w∈Vexp(uw·vc)

分子评估一个候选词，分母却需要遍历整个词表。当词表有百万词时，即使只训练一个正样本，这也变得昂贵。

06 · A different objective

不预测所有词，而是问一句：这对词像真的吗？

对一个真实词对 (c, o)，我们要把它们的内积推高。再从噪声分布采出 k 个负样本，让中心词和这些词的内积推低。

JSGNS=logσ(uo·vc)
+∑i=1klogσ(−uni·vc)

这里 σ(z) = 1 / (1 + exp(−z))；J 是要最大化的目标，写成训练损失时取负号。不同于 Softmax，负采样并不产生一个覆盖全词表的规范化条件概率。

优化方向非常清楚：提高正样本内积，降低负样本内积。但注意，这并不意味着负采样要把所有语义上相似的词都推开——被采样的负例只是训练时的噪声对，有时也会碰到真实但未观测的关联。

为什么噪声词不是完全均匀采样？

第二篇论文报告了一个经验选择：若词 w 的出现频率为 f(w)，负采样分布可取 Pₙ(w) ∝ f(w)^0.75。相较原始频率，它降低极高频词的主导地位；相较均匀分布，它又不过度偏向大量稀有词。

07 · The learning dynamics

一个内积，怎样真的推动向量移动？

当我们最小化负对数目标时，对一个正样本可写成 ℓ⁺ = −log σ(u·v)。对中心向量 v 求导：

∂ℓ+∂v=(σ(u·v)−1)u

由于 σ(z)−1 为负，梯度下降会让 v 朝 u 的方向移动。而对一个负样本 ℓ⁻ = −log σ(−n·v)：

∂ℓ−∂v=σ(n·v)n

这次梯度下降把中心向量朝远离负样本输出向量的方向更新。正、负两种力量加在一起，词向量逐渐开始组织起来。

重要区分

这里被“拉近/推远”的是输入中心向量 v 与输出上下文向量 u，并非任意两个导出的输入词向量都直接受到同样的成对拉力。

原版 word2vec.c 的 SGNS 更新也体现了这一点：先计算内积，再用与 label−σ(score) 对应的量更新 syn1neg 与 syn0；它还用 sigmoid 查找表提速。

08 · The engineering

论文的精髓，还有三个容易被跳过的工程选择。

机制解决的问题正确理解
高频词子采样常见虚词产生海量冗余窗口训练时概率性丢弃频繁词；不等于负采样
动态窗口固定最大窗口对远近词一视同仁随机缩短有效半径，近邻平均更易被采到
词组发现“New York” 等多词整体语义难以直接用单词加法表示通过统计短语识别后，把词组当成 token 训练

论文常见的高频词丢弃近似式：

Pdiscard(w)=max(0,1−(tf(w)))

这是论文中便于理解的近似式；经典 word2vec.c 的保留概率使用 (√(f/t)+1)·t/f 并与随机数比较。二者不能在逐样本复现中混用。

真正复现实验时，应报告语料、词表阈值、维度、窗口、epoch、negative 数量、噪声分布、学习率、子采样与随机种子，而不能只写“Word2Vec, 300d”。

09 · What emerges

语义结构不是写进来的，而是训练中涌现出来的。

训练完成后，可以通过余弦相似度比较两个输入词向量的方向，而不只比较欧氏距离：

cos(a,b)=(a·b)(‖a‖2‖b‖2)

论文还检验了类似 king − man + woman ≈ queen 的向量关系。这不是一条对所有词、语言和语境都成立的“算术语义定律”，而是在特定训练和评估条件下观察到的统计规律。

同样重要的是其局限：静态词向量给一个词形一个向量，无法天然区分一个多义词的不同上下文；语料偏差也会进入表示。它并不承担现代上下文化语言模型的全部角色。

10 · Reproducible implementation

现在，让 15 行核心 NumPy 数学跑起来。

下面的核心更新流程与前面的公式对应：V 是输入表，U 是输出表。真实程序还需要构造词表、滑动窗口、负样本采样与训练循环；完整可运行版本在压缩包的 code/train_sgns.py。

sgns_core.py · NumPy 伪代码（一个正样本）
# center, target: token id; negatives: k 个噪声 token id
v = V[center].copy()
u_pos = U[target].copy()
u_neg = U[negatives].copy()

s_pos = u_pos @ v
s_neg = u_neg @ v
p_pos = sigmoid(s_pos)
p_neg = sigmoid(s_neg)

loss = np.logaddexp(0, -s_pos) + np.logaddexp(0, s_neg).sum()
g_center = (p_pos - 1) * u_pos + (p_neg[:, None] * u_neg).sum(axis=0)

V[center] -= lr * g_center
U[target] -= lr * (p_pos - 1) * v
np.add.at(U, negatives, -lr * p_neg[:, None] * v)

此处仅展示梯度更新。复制后需先定义数组、负例、sigmoid 与 lr；完整脚本独立可运行，附数值梯度与 smoke tests。

最小实验建议

固定语料和随机种子，分别改变 k、window、subsampling。记录 loss、训练耗时和词对余弦，而不要以一个玩具语料的最近邻词就宣称复现论文结果。

回到原始实现

原始代码中可以看到 syn0（输入嵌入）和 syn1neg（负采样输出嵌入）的分离，以及 negative + 1 次更新（一个正例加若干负例）。读源码时应特别关注 TrainModelThread 里 CBOW 与 Skip-gram 的两个分支。

注意 NEG 是修改后的训练目标，不是“只计算少数类别但仍然精确优化 Softmax”。这一区分有助于理解为什么计算量能显著下降。

12 · A mental model

最后，用四句话记住 Word2Vec。

① 信号来自共现

词与上下文天然构成自监督预测任务。

② 模型只是浅层

从词表查出向量，用点积评估匹配。

③ 负采样换了目标

把全词表归一化改成正、负词对的分类学习。

④ 几何关系是结果

相似与类比是数据和目标共同形成的结构，而非写死的语义规则。
