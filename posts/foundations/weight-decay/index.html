让权重逐步缩小，就能更好泛化吗？从一个收缩因子开始，沿着 L₂ 正则化、SGD 与自适应优化器，理解 Weight Decay 的真正作用。

Krogh & Hertz · NeurIPS 1991 / Loshchilov & Hutter · ICLR 2019 · 约 27 分钟阅读

01 · 为什么让参数变小？

假设两个网络都能拟合训练集。一组参数的整体范数更大，另一组更小，我们是否应该偏好后者？Weight Decay（权重衰减）给出了一个简单、可计算的偏好：每走一步，都对当前参数施加朝零的收缩。

这并不意味着“参数越小，泛化越好”。大参数可能携带有效信号，强制收缩也可能造成欠拟合。Krogh 与 Hertz（1991）分析了线性网络中的两种机制：抑制与任务无关的参数分量，以及在适当衰减强度下缓解固定目标噪声。其理论边界必须保留。

要区分两个操作：“在损失中添加平方范数惩罚”与“优化更新后直接缩小权重”对普通 SGD 可以等价，但对 Adam 一般不能等同。

02 · Weight Decay 的最小定义

给定权重 w，令 δ 为每一步实际衰减比例，则 w 变成 (1−δ)w。正权重向零靠近，负权重的绝对值也缩小；它不是统一减去一个正数。

式 01 / 单步按比例收缩
w+=(1−δ)w

通常取 0 ≤ δ < 1，以确保只收缩而不发生符号反转。

现代实现常用 δ=αₜλ，其中 αₜ 是第 t 步学习率，λ 是配置中的 weight_decay 系数。若任务梯度 gₜ 不为零，最简单的解耦 SGD 更新为：

式 02 / 同时加入数据梯度与衰减
θt+1=(1−αtλ)θt−αtgt

θₜ、gₜ 的形状相同，都是 n 维参数向量；此式不是完整 Adam 更新。

收缩项作用于更新前的 θₜ。如果学习率或衰减系数随训练改变，每一步的收缩比例也会改变。

03 · L₂ 惩罚：通过目标函数来控制大小

另一种方式是在任务损失 f(θ) 上增加欧氏范数平方惩罚。这样求梯度时，会产生额外的 λθ，再交由优化器处理。

式 03 / 带有平方范数惩罚的目标
freg(θ)=f(θ)+λ2‖θ‖2

各参数坐标平方和，不包含任何按坐标自动缩放。

式 04 / 正则化所增加的梯度
∇freg=∇f+λθ

直觉上，它希望参数不要离原点太远。下面的二维图：橙色椭圆是同一任务损失，青绿色圆是同一参数范数。折中解通常离原点更近，但不一定等于零。

一个可手算的例子：若 f(w)=½(w−3)²，加上 ½λw² 后，令导数为零，得到最优权重：

式 05 / 一维平方损失的正则化解
w*=31+λ

λ=0 时最优值 3；λ=1 时最优值 1.5。过强惩罚也会增加拟合偏差。

这个例子与岭回归（Ridge Regression）共享数学结构。不过，深度网络存在重参数化、归一化与不同层尺度，不能把“权重小”直接当作“函数复杂度低”的普适指标。

04 · 标准 SGD 为什么能等价？

考虑没有动量的普通 SGD：把 L₂ 惩罚梯度 λθ 加到任务梯度 g，再做固定学习率 α 的下降，代数展开得到：

式 06 / 无动量 SGD 的等价展开
θ+=θ−α(g+λθ)=(1−αλ)θ−αg

原论文 Loshchilov–Hutter §2 Eq. (1) 与 Proposition 1 把 λpaper 直接定义为每步衰减比例，从而对应 L₂ 系数 λpaper/α。现代 PyTorch 常把 weight_decay 定义成和学习率相乘的系数，因此要先看清符号约定，不能照抄论文数值而忽略换算。

等价条件：这里明确是标准无动量 SGD。同样把惩罚梯度写进动量缓冲，和在动量更新之外缩小参数，会改变后续步的更新路径。

05 · Adam 里的 L₂ 为什么不等于 Weight Decay？

把自适应优化器的梯度缩放暂时写成预条件器 Pₜ。耦合 L₂ 时，优化器拿到 g+λθ，会连正则梯度一起缩放。解耦 Weight Decay 时，预条件器只处理任务梯度，衰减则绕过该路径。

式 07 / 耦合路径的更新方向
−αPt(g+λθ)
式 08 / 解耦路径的更新方向
−αPtg−αλθ

看一个严格可手算的固定预条件器示例：设 θ=(1,1)，任务梯度为零，P=diag(1,1/5)，α=0.1、λ=0.1。耦合更新得到 (0.990, 0.998)，解耦更新得到 (0.990, 0.990)。第二维的 L₂ 惩罚被预条件器缩小，却不影响直接衰减。这不是一条真实 Adam 训练轨迹，而是对不等价性的精确微型证明。

原论文 Proposition 2 证明了对一般非标量预条件器，不存在统一标量 L₂ 系数来重现相同的直接衰减。AdamW 进一步保证任务梯度进入一、二阶矩缓冲，而 decay 不进入这些缓冲。详情可继续阅读站内 Understanding AdamW。

06 · 学习率调度会改变累计衰减

先假设任务梯度在每一步都严格为零，学习率与衰减系数固定。那么重复 T 次后，参数变为原参数乘以收缩因子的 T 次幂：

式 09 / 零梯度与常数系数的累积效应
θT=(1−αλ)Tθ0

该式只在零任务梯度下是完整更新；不应当用它预测真实训练的最终参数或模型精度。

例如 α=0.1、λ=0.2，则每步保留 98%；50 步只保留约 36.42%。若采用余弦学习率等调度，准确形式变成每一步因子的连乘 ∏ₜ(1−αₜλₜ)。这解释了为什么单看 weight_decay=0.01 并不足以判断真实的累计约束强度。

论文 §4 针对视觉分类，比较过不同训练预算、学习率日程与不同 decay 策略，研究超参数空间的相互依赖；不能把具体任务的经验值直接推广到任意训练配置。

08 · 哪些参数应该使用 Weight Decay？

对矩阵权重启用 decay，而给偏置、归一化尺度参数设置 weight_decay=0，是一种常见工程做法。但它是可选的经验配置，而不是普遍数学定律；尤其 Embedding、归一化层、模型参数化方式应参照具体训练 recipe。

参数组常见选择需要核查
Linear / Conv 的权重矩阵启用 decay学习率日程、训练步数、模型规模
Bias常不衰减是否对偏置也想加入相同的先验
LayerNorm / RMSNorm 的尺度参数常不衰减归一化参数是否应独立分组
Embedding因模型而异是否按预训练框架或论文设置处理

现代 PyTorch AdamW 的 decay 不进入一阶或二阶矩估计；实际训练前仍需核实各个 param_group，防止同时在损失中再手动加 L₂ 惩罚而造成重复约束。

09 · 用纯 Python 验证三个关键结论

以下代码展示无动量 SGD 中两种写法完全等价。仓库的 mini_weight_decay.py 还实现了预条件器差异与零梯度多步衰减。这是最小算术实验，不包含神经网络训练，也不是 AdamW 的完整实现。

def decayed_sgd(theta, grad, lr, decay):
    return [(1 - lr * decay) * w - lr * g
            for w, g in zip(theta, grad)]

def l2_sgd(theta, grad, lr, penalty):
    return [w - lr * (g + penalty * w)
            for w, g in zip(theta, grad)]

a = decayed_sgd([2., -1.], [.5, -.25], .1, .2)
b = l2_sgd([2., -1.], [.5, -.25], .1, .2)
assert all(abs(x - y) < 1e-12 for x, y in zip(a, b))

如果换成非标量预条件器，等价性不再普遍成立。真正的 AdamW 还必须处理一阶矩、二阶矩、偏差修正与 epsilon 等状态，这部分与站内 AdamW 文章互为补充。

10 · 原始论文证据与局限

1991 · Krogh & Hertz

讨论线性网络中无关权重分量的抑制、对固定目标噪声的作用，并给出理论与模拟。并非“所有深度模型都提高测试指标”的结论。

NeurIPS 4, A Simple Weight Decay Can Improve Generalization；摘要与正文理论部分。

2019 · Loshchilov & Hutter

Proposition 1 证明标准 SGD 的参数化等价；Proposition 2 给出自适应情形的不等价；Algorithms 1–2 描述 SGDW 与 AdamW，§4 和 Figures 1–4 是视觉分类实验。

ICLR 2019, Decoupled Weight Decay Regularization。

论文中的泛化实验有具体数据集、模型结构、训练预算和指标约束。本文 SVG 只展示机制与数学关系，不是原论文曲线或实测指标的复刻。关于更广泛任务是否得到同样收益，原文 §5 也明确提出后续验证的必要性。

四个常见误区：（1）把所有优化器里的 L₂ 都叫直接 decay；（2）把“解耦”误解为学习率与衰减没有任何关系；（3）认为权重只会单调趋于零，忽略数据梯度；（4）把较小范数等同于任何场景下更好的泛化。
