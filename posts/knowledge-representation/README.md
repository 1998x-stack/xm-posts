# 知识表示与语义技术 / Knowledge Representation & Semantic Technologies

本领域研究如何把领域知识表示为机器可处理的概念、关系、公理与实例，并通过查询、推理和验证支持语义互操作。

- **正式文章**：[Ontology Engineering：从分类树到可推理的知识模型](ontology/index.html)，主题 `ontology-engineering`。
- **与相邻分类的边界**：本类关注显式符号知识与形式语义；`foundations / representation` 关注学习型表示；`architectures / graph-neural-networks` 关注图上的神经消息传递；`retrieval-rag` 关注检索和生成应用。
- **数据源**：`content/categories.json` 定义稳定 Topic；`content/posts.json` 控制文章发布；`content/reading_paths.json` 维护跨领域学习关系。
