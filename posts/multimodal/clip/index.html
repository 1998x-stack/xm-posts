Understanding CLIP

一张图片为什么能和一句话比较相似度？CLIP 的关键不是让模型“看图说话”，而是让图像与文本经过两条编码路径，最终落在同一个可比较的向量空间。

核心论文：Radford et al. · 2021Contrastive Language–Image Pre-training约 26 分钟
先记住这一句话：图像编码器负责“把画面变成向量”，文本编码器负责“把描述变成向量”；训练时让正确配对的向量更接近、错误配对的向量更远。推理时，只需把候选类别写成文本，再比较相似度。

01 · 为什么要让图像和语言对齐？

传统图像分类器通常先确定一份标签清单，例如“猫、狗、汽车、飞机”，再训练最后一层分类头。模型学会的是这组固定标签：当新任务要识别“水彩风格的柴犬”或“停在雪地里的黄色校车”，往往需要补充数据、重新训练或修改分类头。

但互联网上的图片经常已经带有标题、说明、替代文本或上下文描述。它们未必是人工审核过的标准标签，却包含了大量自然语言监督。CLIP 的问题意识是：能不能直接从这些图文配对中学习视觉概念，并让语言成为新任务的接口？

固定类别监督

训练时先定义类别集合，输出头与类别表绑定；新类别通常需要新增标注或适配。

自然语言监督

从图片旁边的文字学习关联；使用时再用一句描述指定希望识别的概念。

论文构建了包含约 4 亿组图像—文本配对的 WebImageText（WIT）数据集。这里的文字并不都等同于高质量人工标签：它来自网络上的多种公开来源，规模大、覆盖广，也天然带有噪声和偏差。原论文 §2.2。

CLIP 并不是“完全不需要监督”。它使用的是图像与自然语言之间的配对监督，而不是每张图片都必须有一个人工指定的封闭类别 ID。

02 · 双编码器：两种输入，进入同一语义空间

CLIP 包含两个独立的编码器。图像编码器读取像素，文本编码器读取 token；两者各自产生一个特征向量，再经过线性投影和 L2 归一化，映射到同一个多模态嵌入空间。

从输入到向量，逐步看清数据形状

  1. 图像路径：图像 xᵢ 进入 ResNet 或 Vision Transformer，得到视觉特征，再用线性层投影到共享维度。
  2. 文本路径：文本先经 BPE 分词和 Transformer 编码，取最后一层的 [EOS] 位置表示，再做 LayerNorm 与线性投影。
  3. 归一化：两边向量都除以自身的 L2 范数，使向量长度为 1。之后点积就等价于余弦相似度。
ziI=fI(xi)‖fI(xi)‖2 , ziT=fT(ti)‖fT(ti)‖2
(1)

归一化之后，两个向量的点积只反映方向是否接近，不会因为某个编码器输出的数值尺度更大就天然占优。注意：共享的是投影后的表示空间，不是让两边共用同一套 Transformer 参数。

原论文到底用了哪些编码器？

部件论文中的选择需要理解的细节
图像编码器ResNet 系列，或 ViT-B/32、ViT-B/16、ViT-L/14ResNet 版本加入 attention pooling；ViT 版本沿用 patch + Transformer 主干，并调整初始化与 LayerNorm。
文本编码器12 层 Transformer，基础模型 63M 参数宽度 512、8 个 attention heads；使用小写 BPE，词表 49,152。
文本汇聚[EOS] 位置表示最大序列长度 76；取最后一层 EOS 表示，LayerNorm 后线性投影。
共同空间线性投影 + L2 归一化最终比较图像向量与文本向量的余弦相似度。

编码器配置与文本汇聚细节来自 原论文 §2.4。

因此，“CLIP 就是 ViT”并不准确。CLIP 是一种图文对比预训练方法；图像编码器可以是 ResNet，也可以是 ViT。论文中表现最好的配置是 ViT-L/14@336px，它在 ViT-L/14 的基础上又以 336 像素分辨率额外预训练一个 epoch。

03 · 对比学习：一个 batch 就能构造 N × N 个配对

假设一个 batch 中有 N 组真实配对：(I₁,T₁), (I₂,T₂), …, (Iₙ,Tₙ)。图像编码器输出 N 个向量，文本编码器也输出 N 个向量。把两组向量两两比较，就得到一个 N × N 相似度矩阵。

定义第 i 张图像与第 j 段文本的相似度：

sij=(ziI)⊤zjTτ
(2)

τ 是温度参数。它控制 softmax 对相似度差异的敏感程度。以上 batch 目标与对称交叉熵对应 原论文 §2.3。由于向量已经归一化，分子点积就是 cosine similarity；除以温度相当于放大或缩小 logits。

为什么要做两个方向？

只训练“给定图像找文本”还不够。CLIP 同时训练图像到文本（I→T）与文本到图像（T→I）：对每张图像，正确文本应该在这一行得分最高；对每段文本，正确图像也应该在这一列得分最高。

pI→T(j|i)=exp(sij)∑k=1Nexp(sik) pT→I(i|j)=exp(sij)∑k=1Nexp(skj)
(3)

每个方向都把正确配对当作分类目标，使用交叉熵；最后对两个方向取平均：

L=12 ( −1N∑i=1NlogpI→T(i|i) −1N∑i=1NlogpT→I(i|i) )
(4)
容易混淆的地方：负样本是“同一个 batch 里的其他配对”，不是人工标注的“错误类别”。如果两个不同图片其实都能匹配同一段描述，那么把它们强行视作负例可能引入噪声；这也是大规模网页图文数据并不完美的原因之一。

05 · 零样本分类：文本编码器临时生成分类器

训练完成后，给定一张新图片和一组候选类别名称。先用图像编码器得到图片向量，再把每个类别写成文本提示并送入文本编码器。最后计算图像向量与每个类别向量的相似度，分数最高的类别就是预测结果。

y^=argmaxc cos(zI,zT,c)
(5)

从分类器角度看，这很巧妙：传统线性分类器的权重通常是训练出来的一组参数；CLIP 则让文本编码器根据类别描述生成这些权重。因此，增加一个新类别不必重新训练图像分类头，只需要增加一条候选文本。

原论文 §3.1.2 将零样本分类解释为：把数据集的类别名称当作候选图文配对，比较每张图像与所有候选类别文本的相似度，再经 softmax 得到分布。类别文本可以提前编码并缓存，不必每张图重复计算。

06 · Prompt 与温度：文字写法会改变分类边界

一个常见误解是“把类别名直接交给文本编码器就行”。但训练数据中的文本通常是完整描述，而不是孤立单词。论文发现，给类别补上自然语言上下文通常更贴近训练分布。例如把 dog 写成 a photo of a dog，在 ImageNet 上比只输入类别名高出约 1.3 个百分点。

词义歧义也会影响结果：crane 可能是起重机，也可能是鹤；boxer 可能是拳击手，也可能是犬种。加入任务语境，例如“a photo of a {label}, a type of pet”，可以帮助文本编码器确定词义。论文还报告了多模板集成的收益：ImageNet 使用 80 个上下文模板进行集成，比单一默认提示又提升约 3.5 个百分点。见 原论文 §3.1.4。

训练时，论文把温度参数作为可学习的 log-parameterized 标量优化，而不是固定超参数；初始值相当于 τ=0.07，并限制 logit scale 不超过 100，以避免训练不稳定。推理时，温度缩放也会影响 softmax 概率的尖锐程度，但不会改变原始 cosine 相似度的排序。

07 · 数据、训练与规模：CLIP 为什么能学到这么多概念？

要素原论文设置它解决什么问题
训练数据约 4 亿组互联网图文对（WIT）扩大视觉概念覆盖范围，不局限于固定类别表。
Batch size32,768在一个 batch 内构造大量负配对，让对比任务具有较大的候选集合。
训练轮数32 epochs论文训练 5 个 ResNet 与 3 个 ViT 规模配置。
优化器Adam + decoupled weight decay，cosine learning-rate schedule优化双编码器和投影层；温度参数也参与学习。
计算资源最大 ResNet 版本 RN50x64：592 张 V100、18 天；最大 ViT：256 张 V100、12 天大规模图文预训练仍然需要非常高的计算投入。

训练规模、优化器与温度设置见 原论文 §2.5。

这里要避免一个误读：CLIP 的“zero-shot”说的是下游分类时不使用该任务的训练样本来拟合分类器，并不意味着预训练阶段没有数据、没有监督或没有巨大的算力成本。

对比目标之所以有吸引力，是因为它不要求模型逐字生成一条描述。模型只需在当前 batch 的 N 段文本中识别哪一段与给定图像配对。论文报告，在小到中等规模实验里，contrastive objective 的零样本 ImageNet 学习效率相较其图像描述生成基线高约 4–10 倍；ViT 图像编码器相较标准 ResNet 还带来额外计算效率收益。这里是论文实验中的特定对比，不应当理解成所有任务、所有模型都恒定加速。

08 · 原论文结果：它真正证明了什么？

论文 Table 1 / §3.1.3 的代表性结果之一，是零样本 CLIP 在 ImageNet 上达到 76.2% accuracy，top-5 accuracy 达到 95%，与当时原始 ResNet-50 的 ImageNet accuracy 相当；这一结果没有使用 ImageNet 的 128 万张人工标注训练图片来拟合下游分类器。

模型 / 方法ImageNet accuracy解释与比较边界
Visual N-Grams（2017）11.5%较早的自然语言零样本迁移方法，数据规模、架构和计算预算与 CLIP 不同。
CLIP（论文最佳配置）76.2%零样本分类；论文另报告 top-5 accuracy 为 95%。

这张表用于展示研究进展，不是严格控制变量的算法对比。原论文明确提醒：CLIP 使用了约 10 倍规模的数据集、不同的模型与更多训练计算，因此不能把全部差距都归因于单一损失函数。

更广泛的评测也说明 CLIP 不是只会 ImageNet：论文在 30 多个数据集上评估了零样本迁移，覆盖细粒度分类、视频动作识别、OCR、地理定位等任务；在 Figure 5 / §3.1.5 的 27 个数据集比较中，zero-shot CLIP 在其中 16 个数据集上超过了基于 ResNet-50 特征训练的监督线性分类器。不同任务之间的表现差异仍然很大。

09 · 能力边界：图文相似，不等于视觉理解无所不能

原始 CLIP 擅长什么？

  • 在候选文本中检索与图片最匹配的描述。
  • 用自然语言指定类别，完成零样本图像分类。
  • 抽取图像或文本表示，用于相似度检索、线性探测或其他迁移任务。

哪些任务不能直接交给它？

  • 自由形式图像描述：CLIP 本身输出向量与相似度，不是自回归文本生成器。
  • 精确定位：全局向量相似度不会自动给出物体框、像素分割或图像中的证据位置。
  • 计数与细粒度判断：论文发现它在抽象计数、距离估计以及部分细粒度类别上表现较弱。
  • 提示稳定性：同一类别换一种措辞，分数和排序可能发生变化；prompt 设计不是无关紧要的包装。

还要重视训练数据与分类标签带来的社会偏差。论文指出，模型从未经充分筛选的网络图文数据中学习，类别集合如何设计会明显影响分类结果和偏差表现。官方模型卡也提醒，细粒度分类、计数和公平性仍是重要限制。不能把“无需下游标注”误解为“没有偏差”或“可以无条件用于高风险决策”。

模型卡还将 CLIP 定位为研究产物，而非未经验证即可部署的通用模型；原始模型没有专门针对英语以外语言训练或评测，因此不应把这里的英文提示方法直接外推到多语言场景。模型卡也把未经领域测试的部署列为不推荐用途，并明确排除监控与人脸识别。

边界判断：CLIP 是强大的跨模态表示与检索基础模块，不是完整的视觉问答、目标检测或图像生成系统。后续系统可以把 CLIP 编码器与区域特征、检测器、生成式语言模型或跨注意力模块组合起来，但那已经是更大的架构。

10 · 最小可运行实现：把论文目标变成可测试的计算

下面的代码只实现 CLIP 的数学核心：归一化向量、构造图文相似度矩阵、计算双向 softmax 交叉熵，以及用候选文本做零样本排序。它使用纯 Python 标准库，便于看清每一步；它不是完整 CLIP 网络，也不是论文训练复现。

from clip_toy import symmetric_contrastive_loss, zero_shot_scores

images = [[1.0, 0.0], [0.0, 1.0]]
texts  = [[0.9, 0.1], [0.1, 0.9]]

loss, scores = symmetric_contrastive_loss(images, texts, temperature=0.1)
print("loss:", round(loss, 4))
print("similarities:", scores)

candidates = {
    "dog": [0.9, 0.1],
    "cat": [0.1, 0.9],
}
print(zero_shot_scores([1.0, 0.0], candidates, temperature=0.1))

实现与测试文件：clip_toy.py · tests/test_clip_toy.py。测试检查正配对分数更高、对称损失有限且非负、零样本排序符合预期，并拒绝非法温度与零向量。

阅读代码时，重点检查四个不变量

  1. 图像和文本特征维度必须一致，且 batch 中配对数量相同。
  2. 向量归一化后，点积才对应 cosine similarity。
  3. 图像到文本的 softmax 沿文本候选维度计算；文本到图像沿图像候选维度计算。
  4. 损失是两个方向交叉熵的平均值，而不是只计算一行或一个方向。
