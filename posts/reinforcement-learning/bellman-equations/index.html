Understanding
Bellman Equations

为什么“一步奖励 + 下一状态价值”，足以决定长期最优行为？从回报递归、策略评估到最优控制与 TD 学习。

2026 · Bellman / Sutton & Barto强化学习 · Value-based Learning约 30 分钟阅读

01 · 为什么能只看一步，却优化长期回报？

假设你站在岔路口：一条路立即得到一点奖励，却结束了；另一条路现在得到的少，但可能持续赚取。只比较眼前奖励显然可能选错。Bellman 的核心发现是：只要未来的最佳价值已经用一个函数描述，今天的决定就能用“一步奖励 + 下一状态价值”来比较。

它不是一个深度学习模型，也不是“把 TD target 写出来”这么简单，而是把长时间的序贯决策重写成对自身一致性的要求。Bellman（1952）从动态规划建立阶段决策的最优性原理；在强化学习里，我们用它定义价值函数，并据此规划或从经验学习。

02 · 先把“未来所有奖励”拆成两项

定义从 t 时刻开始的折扣回报 Gt：第一个奖励是 Rt+1，以后依次按 γ、γ² 等递减。取常见的 0≤γ<1，使有界奖励下无限期回报有定义；有限回合任务也可讨论 γ=1，但要单独处理终止与收敛。

Equation 01折扣回报的递归定义
Gt=Rt+1+γGt+1

来自 Sutton & Barto §3.3–3.5。若进入真实终止状态，后续回报定义为 0。

这是代数恒等式，不是学习算法。价值函数出现于对这个随机回报取条件期望时。奖励发生于转移之后，因而教材习惯写 Rt+1 而非 Rt；下标错一位，TD 更新就可能错位。

03 · 把问题说清楚：有限 MDP 的五个零件

考虑状态集合 S、可行动作集合 A(s)、环境联合转移概率 p(s′,r|s,a)、策略 π(a|s) 与折扣因子 γ。Markov 条件要求：给定当前状态和动作，下一状态与奖励的分布不再依赖更久远的历史。终止状态可视为无未来奖励的吸收状态。

Vπ(s)：状态价值

从状态 s 出发，此后一直执行策略 π，能获得的期望折扣回报。

Qπ(s,a)：动作价值

先在 s 执行指定动作 a，随后执行策略 π，能获得的期望折扣回报。

状态价值隐含了当前也依照 π 选择动作；动作价值则固定第一步动作。这正是下面两条期望方程外层求和位置不同的原因。

04 · Bellman 期望方程：沿一条既定策略展开

先给定策略 π。把回报递归式代入 Vπ 的定义，再按“动作 → 环境转移”拆开全期望，得到：

Equation 02状态价值的 Bellman 期望方程
Vπ(s)=∑aπ(a|s)∑s′,rp(s′,r|s,a)[r+γVπ(s′)]

对动作按 π 加权，对环境后继状态和奖励按联合分布 p 求期望；Sutton & Barto §3.5 (Eq. 3.14)。

读法从外向里：① 策略选 a 的概率；② 环境返回 (s′,r) 的概率；③ 这一转移的奖励 r 加折扣后的未来状态价值。两次加权都不可随意省略。若环境奖励是确定的，可把 r 单独写成 R(s,a,s′)；本文坚持更一般的联合分布记法。

固定第一步动作：Q 的对应形式

Equation 03动作价值的 Bellman 期望方程
Qπ(s,a)=∑s′,rp(s′,r|s,a)[r+γ∑a′π(a′|s′)Qπ(s′,a′)]

当前动作 a 已经给定，所以最外层不再对 a 求和；下一步才依据 π 采样动作。

05 · Bellman 最优性方程：从“平均”换成“最好”

如果允许在每个状态都选长期最优的动作，最优状态价值 V* 不依赖预先给定的 π，改为对动作取最大值：

Equation 04状态价值的 Bellman 最优性方程
V*(s)=maxa∑s′,rp(s′,r|s,a)[r+γV*(s′)]

max 只针对智能体能选的动作；随机转移仍是期望。Sutton & Barto §3.8 (Eq. 3.17)。

与期望方程比较，改变的是代理可控制的动作选择，不是环境随机转移的求期望。若环境可能以 30% 概率成功，不能把这 30% 直接 max 成成功路径。

Q* 如何给出一个贪心策略

Equation 05动作价值的 Bellman 最优性方程
Q*(s,a)=∑s′,rp(s′,r|s,a)[r+γmaxa′Q*(s′,a′)]

给定 (s,a) 后先经历一次环境转移，再在下一状态选择最大 Q。

一旦求出 Q*(s,a)，只需在每个状态选择 Q* 最大的合法动作，便得到最优确定性策略（并列最优动作可任选或随机化）。这也是 Q-learning 能在未知模型下尝试学习动作价值的原因。

区分两个下标：对 V* 的最优性备份先选当前动作 a；对 Q* 的备份，当前 a 已固定，max 出现在后继状态 s′ 的下一动作 a′ 上。

06 · 两个动作足以让差异可见

构造一个教学示例（非论文实验）：只有一个可决策状态 S。选择「停止」立即得到奖励 1 并真正终止；选择「继续」立刻得到奖励 0.3，然后确定性地返回 S。每一步都可以重新选择，未来按 γ 折扣。

始终停止的价值是 1；始终继续的价值是 0.3/(1−γ)。γ=0.5 时持续继续仅值 0.6，停止更好；γ=0.9 时持续继续值 3，继续更好。拐点是 γ=0.7，两种动作等价。若固定策略以概率 p 继续、以 1−p 停止，其价值是 [1−p+0.3p]/[1−γp]；这不是对两个纯策略价值简单平均，因为每次回到 S 都会重新抽取动作。

07 · 交互实验：自己做 Bellman 备份

滑动 γ 会同时改变长期权衡与收敛速度；p 决定待评估策略继续的概率。下方“迭代值”从 0 开始，每点一次执行 Vₖ₊₁(S)=max(1, 0.3+γVₖ(S))。当 γ 较大时，学习者会看到值函数如何逐步从短期终止选项，变成长期继续选项。

08 · 为什么反复代入会收敛？

令 Tπ 表示把任意价值向量 V 代入 Bellman 期望右端的算子；T* 表示代入最优性右端的算子。Bellman 方程正是固定点条件 V=TπV 或 V=T*V。把“已满足的方程”改成“不断应用算子”，就得到可计算的迭代算法。

Equation 06固定策略的矩阵形式
Vπ=rπ+γPπVπ⇒Vπ=I−γPπ−1rπ

这里 Vπ 是按状态排列的向量；此处省略了向量表示上的粗体。有限状态且 0≤γ<1 时逆矩阵存在。

矩阵表示用在固定策略评估：Pπ 的第 (s,s′) 个元素是按 π 混合后的转移概率，rπ 是各状态的期望单步奖励。最优性方程含 max，通常不再是同一线性方程组。

三行证明的核心

对任意 V、W 与状态 s，固定 π 下求和中的差异只发生在后继价值项。概率权重之和为 1，因此差的绝对值至多为 γ‖V−W‖∞。最优算子则使用不等式 |maxᵢxᵢ−maxᵢyᵢ|≤maxᵢ|xᵢ−yᵢ|，得到同一上界。对全部状态取最大：

Equation 07折扣 Bellman 算子的收缩性
‖TV−TW‖∞≤γ‖V−W‖∞

在有限 MDP、有效转移概率及 0≤γ<1 下，对 Tπ 与 T* 都成立；由此导出唯一固定点与同步价值迭代收敛。

在有限状态、有限奖励与 0≤γ<1 条件下，Banach 固定点定理保证唯一固定点；从任何有限初值反复完整同步备份都会趋于它。注意：γ=1 的一般持续任务不能直接套用这条 γ-收缩证明；有终止条件的随机最短路和平均奖励任务需要各自的假设。

09 · 两条主路：策略迭代 vs 价值迭代

策略迭代 Policy Iteration

固定 π → 用 Bellman 期望方程评估 Vπ → 按一步前瞻对动作改进 π → 重复，直到策略稳定。

价值迭代 Value Iteration

从任意 V₀ 出发，直接反复执行 Vₖ₊₁=T*Vₖ；数值足够接近 V* 后再取贪心策略。

两者都属于已知转移模型的动态规划方法。精确策略评估可解线性方程，也可用迭代；价值迭代不要求每轮都先把某条策略评估到收敛。在实际任务中，近似评估、异步更新、函数逼近等会引入额外条件，不能从有限表格型结论直接推断深度网络必收敛。

10 · 环境模型未知时：从全期望到一次样本

前面的 Bellman 备份显式求和 p(s′,r|s,a)，它适合知道环境模型的规划。真实强化学习通常拿不到全部概率，只观察一条转移样本 (s,a,r,s′)。TD(0) 用单样本构造引导目标，形成误差：

Equation 08一步采样 TD 误差
δt=Rt+1+γ(1−dt)V(St+1)−V(St)

dₜ=1 仅表示真实 MDP 终止；由外部时间上限造成的截断通常不应无条件将后继价值归零。

在 Q-learning 中，把后继价值替换为 maxa′Q(s′,a′)，并仅更新当前 (s,a) 的估计。DQN 进一步让神经网络拟合 Q 值，加入经验回放与目标网络，但其训练能否稳定、能否收敛，不再仅由表格型 Bellman 收缩性保证。

顺序阅读可参考本站 DQN（神经网络版 Q-learning）、GAE（把不同跨度的 TD 信息组合为优势估计）、PPO（使用优势的策略优化）与 MCTS（搜索树中的规划）。

11 · 六个尤其容易混淆的边界

  1. 把 Bellman 理解成只有一个等式。 期望/最优、状态价值/动作价值共四种经典形式；对应的条件化变量不同。
  2. 把 max 施加给环境随机性。 控制者最大化动作，但不能随意选择随机发生的后继状态。
  3. 把终止与时间截断当成同一件事。 真终止未来回报为 0；外部限时截断需要结合任务语义判断是否引导。
  4. 以为 γ=1 自动也有唯一固定点。 一般持续型任务不满足此处的折扣收缩前提。
  5. 把示例中的闭式 Vπ 等同于两条纯策略价值的加权平均。 每次回到 S 策略都会重新采样。
  6. 误将表格型值迭代的收敛定理搬到任意 DQN。 非线性函数逼近、离策略训练与自举结合时，需要额外稳定化措施和分析。
最重要的分界：Bellman 方程刻画的是“价值的自洽性”；DP 使用模型直接计算这一自洽条件，TD / Q-learning 则用样本近似满足它。

12 · 可执行的最小数值实现

仓库中的 mini_bellman.py 仅依赖 Python 标准库，实现两个算子、闭式固定点、价值迭代和数值断言；不是完整 Gym 训练器，也不是对 Bellman 1952 论文的实验复现。

def optimal_backup(v, gamma):
    return max(1.0, 0.3 + gamma * v)

def policy_backup(v, gamma, p):
    return (1 - p) * 1.0 + p * (0.3 + gamma * v)

def exact_policy(gamma, p):
    return (1 - 0.7 * p) / (1 - gamma * p)

测试覆盖 γ=0.5 / 0.7 / 0.9 的最优动作阈值、π 的精确固定点、γ 收缩上界、从不同初值迭代到唯一解，以及终止不自举。可使用 python posts/reinforcement-learning/bellman-equations/mini_bellman.py 或 python -m pytest -q tests/test_bellman.py 核验。
