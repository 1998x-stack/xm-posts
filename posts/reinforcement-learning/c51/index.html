REINFORCEMENT LEARNING · DISTRIBUTIONAL VALUE LEARNING

Understanding C51

Q-learning 只预测“平均能拿多少分”；C51 进一步预测“可能拿到哪些分，各有多大概率”。

Bellemare · Dabney · Munos · ICML 2017 · 论文精读 · 算例为独立教学构造

01 · 为什么平均回报不够？

两种动作的期望回报都等于 2：动作 A 总是得到 2；动作 B 有一半概率得到 0，另一半得到 4。标量 Q 值无法区分它们的回报形状。C51 的关键不是简单引入风险偏好，而是把“未来折扣奖励的随机变量”作为学习对象，训练一个概率分布，并最终仍可通过其期望值选择动作。

设折扣回报随机变量 Z(s,a) 是从状态 s 采取动作 a、此后遵循某策略时的未来折扣奖励总和。传统 Q(s,a)=E[Z(s,a)]；C51 试图近似 Z 的分布，而不只是均值。

02 · 从标量 Bellman 到分布式 Bellman

经典 Bellman 更新把奖励与下一状态的价值期望相加；分布式版本保留下一状态回报的随机性：

Z(s,a)=dR(s,a)+γZ(S′,A′)

这里“=d”表示两侧同分布而非逐样本相等；R 是随机即时奖励；S′ 是转移后的随机状态；A′ 是下一策略选取的动作；γ∈[0,1) 是折扣因子。对两侧取期望可回到熟悉的 Bellman 期望方程，但只保留期望会丢失分布形状。

论文对固定策略的分布式算子给出 Wasserstein 距离意义下的收缩分析；对控制场景的最优性算子则不能直接照搬同样的收缩结论。不要将“表格策略评估理论”误解成“任意深度 C51 必然收敛”。

03 · 为什么是 51 个原子？

C51 用 N=51 个固定位置 zᵢ=vmin+iΔz 表示离散概率分布，Δz=(vmax−vmin)/(N−1)。原论文 Atari 配置使用 vmin=−10、vmax=10，因此 Δz=0.4；网络对每个动作输出 51 个 logits，经 softmax 转为概率 pᵢ(s,a)。这些位置固定，网络学习的是概率，不是原子坐标。51 是原论文的设计选择，不是分布式强化学习的普遍定理。

Q(s,a)=∑i=0N−1pi(s,a)zi

pᵢ 是原子 i 的概率，zᵢ 是固定回报位置。行为决策仍可以选取使上述期望最大的动作，因而“学分布”不意味着“必然采取风险规避策略”。

04 · 最关键的步骤：投影 Π

一次环境转移给出奖励 r 与下一状态 s′。先用下一状态的期望 Q 选择贪心动作 a*；再将其每个原子位置变换为 Tzⱼ=clip(r+γzⱼ,vmin,vmax)。变换后的位置通常不落在原来固定网格上，故需要把概率质量按距离线性分配给两个邻近原子。

令 b=(Tzⱼ−vmin)/Δz，l=⌊b⌋，u=⌈b⌉。当 l≠u 时，向位置 l 增加 pⱼ(u−b)，向 u 增加 pⱼ(b−l)；若 l=u，整份 pⱼ 归入该原子。边界先 clip，防止概率落到支持集之外。多个来源原子的贡献累加成目标分布 m。

例如在简化网格 {0,1,2,3,4} 上，某一项概率 p=0.6 被变换到 1.4：l=1、u=2，故 m₁ 增加 0.6×0.6=0.36，m₂ 增加 0.6×0.4=0.24。这是演示投影规则的教学算例，不是论文报告的 Atari 结果。

05 · 训练流程与损失函数

从 replay buffer 采样转移；用在线网络在下一状态比较各动作的期望并选 a*；用目标网络给出 a* 的 51 维概率；将 Bellman 变换后的分布投影到固定网格；最后最小化目标概率 m 与当前网络输出 pθ(s,a) 之间的交叉熵。

L(θ)=−∑i=0N−1milogpθ,i(s,a)

θ 为当前网络参数；mᵢ 为停止梯度的投影目标概率；pθ,i 为在线网络对当前 (s,a) 输出的概率。终止转移不再 bootstrap：目标直接集中在经过裁剪的即时奖励附近。交叉熵用于匹配类别概率，不能把它误写为直接最小化 Wasserstein 距离。

for (s, a, r, next_s, terminal) in replay_batch:
    a_star = argmax_a expected_return(online(next_s, a))
    next_prob = target(next_s, a_star)  # 51 probabilities
    projected = zeros(51)
    for j in range(51):
        tz = clip(r if terminal else r + gamma * atoms[j], vmin, vmax)
        b = (tz - vmin) / delta
        l, u = floor(b), ceil(b)
        if l == u: projected[l] += next_prob[j]
        else:
            projected[l] += next_prob[j] * (u - b)
            projected[u] += next_prob[j] * (b - l)
    loss = -sum(projected[i] * log(online(s, a)[i]) for i in range(51))

这是展示主要运算顺序的伪代码，不包含优化器、梯度截断、探索调度、Atari 预处理或完整论文复现。

06 · 优势、证据与适用边界

优势是比标量价值更丰富的训练目标：同均值、不同形状的回报不再不可区分。Bellemare 等人在 Atari 任务上报告了相对其 DQN 基线的表现改善；具体实验依赖论文的任务、协议与超参数，不能推断“所有环境都提高同一幅度”。原论文还讨论了分布式 Bellman 理论性质及其与传统价值学习的区别。

限制：固定区间外的目标被裁剪；51 个原子限定分辨率；投影引入近似误差；复杂分布未必适合固定等距支持；深度控制的稳定性不由策略评估收缩定理直接保证。后续 QR-DQN 等方法使用不同的分布表示，不能混同为 C51 原论文的一部分。

工程上可用于离散动作价值学习、回报不确定性可视化及作为 distributional RL 教学基线；若动作连续、奖励尺度极大或分布多峰且超出支持范围，应重新审查表示方式与边界。
