PAPER STUDY · VALUE-BASED REINFORCEMENT LEARNING

Understanding DQN

一台只看到像素的机器，为什么能通过输赢反馈学会做动作？从贝尔曼自举到经验回放与目标网络，拆开 Deep Q-Network 的稳定训练机制。

Mnih et al. · Nature 2015约 34 分钟Deep Q-Learning / Experience Replay / Atari

01 · 一个分数，而不是一张规则表

想象你只看得到游戏画面：球正在向左下方移动，挡板应该往哪边走？监督学习需要标准答案；但游戏只告诉你最终拿了多少分。DQN 的想法是：让神经网络预测“在当前状态选择每个动作，未来累计奖励有多好”，然后选出分数最高的动作。

这就是 Deep Q-Network 中的 Q：动作价值（action-value），不是动作发生的概率。DQN 主要研究离散动作空间，网络一次前向计算输出所有合法动作的价值；探索时使用 ε-greedy，不是每次都盲从网络。

本文以 Mnih 等，Nature 2015 为主案例。2013 年预印本是前史；Double DQN、Dueling DQN 属于后续研究，不混入原始算法。

02 · 从未来回报到贝尔曼自举

每次动作后获得奖励 r，但有些好动作需要先忍受眼前的小损失。折扣因子 γ（0≤γ≤1）控制我们重视多远的未来；Q*(s,a) 表示先在状态 s 执行动作 a，然后做最优决策时的期望折扣回报。

(1)
Q*(s,a)=𝔼s′,r[r+γmaxa′Q*(s′,a′)]

这个等式把一个难以直接观察的长期目标，变成“即时奖励 + 下一个状态的最好估计”。这叫 bootstrap（自举）：学习目标并非全是真实标签，也部分依赖模型目前的预测。它是 Q-learning 的力量，同时也是深度网络不稳定的来源。

03 · 为什么直接把 Q-learning 接到神经网络上会震荡？

一条游戏轨迹中相邻画面高度相似，因此每次沿时间顺序更新，梯度会持续受到同一种局面支配。更麻烦的是：你改变 Q 网络的一组参数，既改变左边的预测，也会立刻改变右边用于监督自己的“答案”。输入强相关 + 目标自己在移动，使训练容易震荡甚至发散。

论文用两个明确的装置拆开这些问题：experience replay 用随机小批量降低样本时间相关性，target network 用延迟同步减缓目标漂移。二者是稳定性工程设计，并不是贝尔曼方程的数学必然条件。见原论文第 1 页及 Methods / Algorithm 1。

04 · 经验回放：从连续时间流到随机小批量

与环境交互时，将转移 (s,a,r,s′,d) 放入有限容量缓冲区 D。训练时随机抽取一批，而不是只用最近一步；d 表示 episode 是否真正终止，是本文代码为避免跨终止状态 bootstrap 而显式添加的标志。

随机采样削弱相邻样本的相关性，并允许一条经验被再次利用；但数据仍来自不断改变的行为策略，样本也并非严格独立同分布。原论文使用均匀抽样，容量 1,000,000，mini-batch 为 32；优先回放不属于该版本。

05 · 目标网络：不要让学生每一步都改试卷答案

训练同时维护两个参数副本：在线网络 θ 用来选择动作并接受梯度更新；目标网络 θ⁻ 用来构造下一个状态的 Q 值目标。每隔 C 次参数更新才把 θ 复制给 θ⁻，中间保持后者不变。

目标“较慢”不意味着无偏或保证收敛，它只是避免每次更新都立即改变训练标签。2015 年论文 Extended Data Table 1 设 C = 10,000 次参数更新，不是 10,000 个 Atari 原始帧。

对一条从回放中取出的转移，我们希望在线网络对已选动作的预测接近目标 y。设 d∈{0,1}，d=1 表示终止；γ 为折扣，a′ 枚举下一状态合法动作。注意这里 max 和评价都由目标网络 θ⁻ 完成，这是原版 DQN 而非 Double DQN。

07 · 原始 Nature DQN：从四帧像素到动作分数

游戏画面先转为 84×84 的灰度表示，堆叠最近 4 帧 来捕捉运动方向。该 2015 年网络依次是 32 个 8×8/stride 4 卷积核、64 个 4×4/stride 2、64 个 3×3/stride 1、512 维全连接，再用线性层给出每个动作的 Q 值。隐藏层使用 ReLU。

一个状态只需一次前向传播就得到 |A| 个 Q 值。输出不是 softmax，也不是每个动作各有一个 CNN；选出的动作 a 仅用于从向量中取出对应 Q(s,a) 计算回归误差。Nature 2015 Figure 1 / Methods。

08 · 把所有部件串成一轮训练

交互与优化是两个节拍：执行 ε-greedy 动作、获得奖励与下一状态、写入回放缓存；缓存准备就绪后，按更新频率抽样并构造 y，对 θ 做梯度下降，然后定期复制 θ 至 θ⁻。

① 探索：训练中的 ε 从 1.0 逐步下降至 0.1；测试使用独立的 ε=0.05。

② 回放：50,000 帧开始积累学习条件；从 1,000,000 容量中均匀取 32 条。

③ 目标：γ=0.99、目标网络每 10,000 次参数更新同步。

④ 算力：论文设动作重复 4、更新频率 4、RMSProp 学习率 0.00025；50,000,000 帧/游戏，注意“帧”和“动作选择”不是一回事。

11 · 不要混淆 2013、2015 与后续改进

2013 年 Playing Atari with Deep Reinforcement Learning 展示了 7 款游戏上的早期方案，常用的架构是 16 个 8×8/s4 卷积核、32 个 4×4/s2、256 隐藏单元。2015 年 Nature 版本是三层卷积 + 512 隐藏单元、49 游戏基准。网络和实验范围都发生了变化。

后来的 Double DQN（van Hasselt 等）把“由在线网络选下一动作”与“由目标网络估计它的价值”拆开，以减轻 max 自身带来的过估计偏差：

(6)
yDouble=r+γ(1−d)Q(s′,arg maxa′Q(s′,a′;θ);θ−)

Dueling DQN、Prioritized Experience Replay、Rainbow 也都是不同的后续研究，不能作为原始 Nature DQN 的实验配置。原版 DQN 没有 actor、critic 的双网络政策梯度结构：它是 off-policy、value-based 算法，而 PPO 是策略更新算法。

12 · 一段可以独立核验的数学代码

该最小代码使用 Python 标准库实现终止状态 masking、阈值为 1 的 Huber 损失和三个卷积输出尺寸检查。它不是一份可运行的 Atari DQN 训练器，也不声称复现论文成绩；完整源码在仓库同目录的 mini_dqn.py。

"""DQN target and Huber checks; standard library, no Atari training."""
from math import isclose

def td_target(reward, gamma, terminal, next_q_values):
    if not 0 <= gamma <= 1 or not next_q_values:
        raise ValueError("invalid gamma or next action space")
    return reward if terminal else reward + gamma * max(next_q_values)

def huber(td_error, threshold=1.0):
    if threshold <= 0:
        raise ValueError("threshold must be positive")
    a = abs(td_error)
    return 0.5 * a * a if a <= threshold else threshold * (a - 0.5 * threshold)

def valid_conv(n, kernel, stride):
    if n < kernel or kernel < 1 or stride < 1:
        raise ValueError("invalid convolution parameters")
    return (n - kernel) // stride + 1

def check():
    assert isclose(td_target(1, 0.99, False, [1.2, 2.0]), 2.98)
    assert isclose(td_target(1, 0.99, True, [1.2, 2.0]), 1)
    assert isclose(huber(1.58), 1.08)
    assert isclose(huber(0.5), 0.125)
    assert [valid_conv(84, 8, 4), valid_conv(20, 4, 2),
            valid_conv(9, 3, 1)] == [20, 9, 7]
    print("DQN math invariants passed")

if __name__ == "__main__":
    check()

运行 python posts/reinforcement-learning/dqn/mini_dqn.py 应打印断言通过提示。真正复现 Atari 还需要 ALE 环境版本、预处理、训练调度、种子、日志、计算预算与统计检验。

13 · 模型在哪些地方依然不可靠？

一是 离散动作 约束：输出层直接列出动作，在连续控制空间通常并不实用。二是 样本效率：每游戏数千万帧，在实际机器人等昂贵交互场景下成本极高。三是 最大化偏差和离策略分布漂移：延迟目标并不能从理论上消除函数逼近与 bootstrap 风险。

另外，reward clipping 将不同奖励尺度压成 −1/0/+1，有利于统一学习率，却牺牲幅度信息；Atari 分数也不能作为现实世界控制任务的泛化结论。对于 Atari 的新版评测基准，应明确环境版本、sticky actions 和训练预算，不能直接与 2015 分数作无条件比较。
