Understanding GAE

一个动作的后果要很多步之后才出现，策略梯度该相信多少未来？从 TD residual、k-step 优势到 λ 加权，理解广义优势估计背后的偏差—方差机制。

Schulman et al. · ICLR 2016约 32 分钟Policy Gradient / Actor–Critic

01 · 为什么策略梯度在延迟奖励下会摇晃？

机器人第三步终于站稳，却不能简单认为第一步抬脚就是决定性原因。奖励越晚到来，越多后续随机事件会混进动作的学习信号。GAE 不是另一个策略更新器；它首先是回答“这个动作到底比预期好多少”的优势估计器。

策略梯度把动作概率的变化方向交给优势 Aπ(s,a)=Qπ(s,a)−Vπ(s) 决定。正优势鼓励动作，负优势抑制动作。但真实的 Q、V 未知，只有从交互中采到的奖励序列。论文要解决的问题是：能否既不过度依赖不准确的 Critic，也不被漫长轨迹的噪声淹没？

02 · 为什么需要价值基线？

REINFORCE 式的 Monte Carlo 信号把动作之后的回报直接放进 log-prob 梯度。它不需要 bootstrap，却承受未来奖励的较高方差。引入仅依赖状态的 baseline，在标准 score-function 条件下不改变期望梯度；用 V(s) 作 baseline，剩下的就是“比当前状态通常得到的回报更好或更差”。

目标差异：2016 原论文以未折扣总奖励为目标，但引入 γ 来控制估计方差。因此 γ<1 已可能让折扣梯度偏离原目标；“λ=1 无偏”必须说明相对于哪个目标（原论文 §2 脚注 1）。

03 · 一步 TD Residual：把遥远未来折成预测

只观察当前奖励，再加上下个状态的折扣价值预测，最后减去当前状态的价值估计：这就是一步 temporal-difference residual。它描述在当前状态动作下，我们观察到的反馈比预测好多少。

δtV=rt+γV(st+1)−V(st)

Schulman et al. 2016, §3 Eq. (10)–(11)，V 为近似的折扣价值函数。

当 V 恰好等于真实的 Vπ,γ 时，对固定 (sₜ,aₜ) 的后继随机性取期望，TD residual 是折扣优势 Aπ,γ 的无偏估计；Critic 不准确时就可能带来偏差。

04 · 多看几步，价值项为什么会抵消？

把相邻两个 TD residual 相加，δₜ+γδₜ₊₁，第一步的 +γV(sₜ₊₁) 和第二步的 −γV(sₜ₊₁) 正好抵消。剩下两次真实奖励、两步后的 bootstrap 和初始价值基线。k 越大，越少相信近处的 Critic，越多依赖未来真实奖励。

Ât(k)=∑l=0k−1γlδt+lV

原论文 §3 Eq. (14)，这是 telescoping sum 的结果。

例如二步估计等于 rₜ+γrₜ₊₁+γ²V(sₜ₊₂)−V(sₜ)。这里并非凭空加入信息，而是用更长的真实轨迹替换了短期的自举预测。

05 · GAE：不再选唯一 k，而是混合不同长度

只选 k=1 往往太依赖 Critic；只选很大的 k 则会遇到更高的随机方差。GAE 以 λ 为连续旋钮，把第 1、2、3 … 步优势按几何衰减权重混合。交换求和顺序后，这个复杂混合就简化成对未来 TD residual 的指数加权。

ÂGAE(γ,λ)t=∑l=0∞(γλ)lδt+lV

原论文 §3 Eq. (16)。这就是 GAE(γ,λ) 的核心式。

γ 与 λ 都影响远期残差的衰减，但角色不同：γ 决定折扣价值函数的目标尺度；λ 是额外的偏差—方差控制。即使两组参数的乘积一样，学习目标也未必完全相同。

06 · λ=0 与 λ=1，两端有什么差别？

λ=0：一步 TD

只看 δₜ，通常方差较低；但 Critic 误差可能直接影响估计，造成偏差。

λ=1：完整回报 − baseline

完整终止轨迹里，价值项发生望远镜式抵消，依赖更多远期真实奖励，方差通常较高。

08 · 一次反向扫描，如何 O(T) 计算全部优势？

对每个起点都重新累加未来项会重复计算。设末端 ÂT=0，从后向前执行 δ+γλ×下一步优势，只遍历一次轨迹就能算出全部值。实际实现还要处理 episode 终止掩码。

Ât=δtV+γλmtÂt+1

工程形式：真实 terminal 时 mₜ=0，继续时 mₜ=1；rollout 末端的 δ 需要正确 bootstrap。

终止与截断不是一回事。 真正吸收态的未来价值应归零；时间上限或 rollout 缓冲区满，通常需要保留边界状态 V(sT) 的 bootstrap。把所有 done 一律当 terminal，会系统性删掉应有的价值信息。

09 · 原论文的训练链条：GAE + TRPO

原论文 §6.1 的流程是：用当前策略采样 N 步；利用尚未更新的 Vφᵢ 计算 TD residual 和 GAE；通过 TRPO 做 Actor 的信任域更新；最后按 §5 Eq. (29)–(30) 更新 Critic。GAE 本身不规定 Actor 如何更新。

作者特别指出，应先用旧 Critic 计算本批优势，再调整 Critic。否则如果先把 Critic 对当前轨迹过拟合，残差可能被压近零，让 Actor 的学习信号也消失。

§4 还把 TD residual 解释为 potential-based reward shaping：取势函数 Φ=V，把远期奖励的部分影响提前转化成局部的“超出预期”，再用 γλ 衰减其远期影响。

r̃t=rt+γΦ(st+1)−Φ(st)

原论文 §4 Eq. (20)–(25)；令 Φ=V 时得到 TD 残差。

11 · 后来的 PPO / RLHF 为什么经常用 GAE？

2017 PPO 论文 §5 使用截断 GAE 估计优势，再利用 clipped surrogate 调整策略。GAE 与 PPO 能很好配合，但 2016 GAE 原论文采用的是 TRPO，而非 PPO。

现代 Actor–Critic 常见 λ-return 目标；2016 原论文 §5 主实验则采用折扣 Monte Carlo 回报拟合 Critic。

部分无需独立 Critic 的组内优势算法不使用传统 GAE。进一步阅读 Understanding PPO 与 Understanding GRPO。

12 · 最小数值实现与可重复断言

仓库中的 gae.py 不依赖机器学习框架。输入长度 T 的奖励和真实终止标志、长度 T+1 的预测价值；输出每步优势。核心实现：

running = 0.0
for t in range(T - 1, -1, -1):
    alive = 0.0 if terminals[t] else 1.0
    delta = rewards[t] + gamma * alive * values[t + 1] - values[t]
    running = delta + gamma * lam * alive * running
    advantage[t] = running

确定性断言验证 λ=0 一步 TD、λ=1 完整回报、λ=0.95 手算值、真实 terminal 阻断未来贡献、普通截断保留 V(sT)，以及跨 episode 不串联。这是公式核验，不是机器人训练结果复现。

13 · 五类最容易误解的边界

  1. 把 λ=1 说成对所有目标无偏。 必须区分折扣梯度 gγ 与未折扣原目标。
  2. 把 time-limit truncation 当作真正终止。 会错删 bootstrap。
  3. 误把 GAE 当成 PPO 的发明。 前者 2016，后者 2017。
  4. 先更新 Critic 再计算同批优势。 会违背原论文的更新顺序。
  5. 从几条曲线推断“λ=0.95 永远最佳”。 效果取决于任务、γ、Critic 误差与数据预算。
核心直觉：GAE 把“一步 TD 的低方差”与“长轨迹回报的低自举依赖”连成一条可调的曲线；它解决的是估计策略梯度方向时的信用分配问题。
