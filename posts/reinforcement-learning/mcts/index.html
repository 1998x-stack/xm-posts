PAPER STUDY · REINFORCEMENT LEARNING / PLANNING

Understanding MCTS

不必看完整棵树，也能做出更好的决策？从有限采样预算与 UCT 的探索—利用平衡出发，拆解树搜索，并分清 AlphaZero 之后的新机制。

Kocsis & Szepesvári · 2006约 32 分钟UCT / Search / PUCT

01 · 一百次试探，如何分给上万条路？

每步有四种行动、持续十步，完整展开就有 4¹⁰ 种路径。实际系统可能只允许一百次模拟。最难的不是能否枚举，而是如何决定哪里值得多看一眼。

纯随机 Monte Carlo 可以估计一条路的结果，却难以把深层的信息逐步积累。MCTS 将模拟组织成一棵缓慢长大的搜索树，边走边记录访问次数和值，使下一次采样不再从零开始。它不是一个必须先训练的神经网络；典型设定需要能模拟动作后果的生成模型或游戏规则。

MCTS 是 planning/search 框架；UCT 是经典的特定树内选择方法。两者不是同义词。

02 · 搜索树存的不是所有路径，而是“证据”

节点代表状态 s，边代表动作 a。从状态起执行动作并完成一次 rollout，得到回报 G。我们只记录这条路径的次数与回报总和，下次从根开始时就能利用这些统计信息。初始大部分分支尚未展开，因此搜索树通常是不对称的。

均匀随机采样

很多试探彼此独立，难以在不同深度上有针对性地累积动作证据。

有树的自适应采样

用树内选择策略寻找值得深挖或尚未探索的动作，沿访问路径持续更新统计。

如果继续增加预算，当前解可能越来越稳定，但 Browne 等（2012）描述的 anytime 特征并不代表每次额外模拟都会单调提升质量。

03 · 一轮搜索的四个阶段

典型 MCTS 以 Selection → Expansion → Simulation → Backpropagation 为一轮。四阶段是综述中广泛采用的分解，不意味着所有变体都采用随机终局 rollout，也不意味着每轮都要扩展节点。

点击四个阶段，检查每一步究竟改变什么

Selection · 选择从根沿已建好的子树往下走。若节点全部合法动作已扩展，就用 UCT 从子边中挑一个；尚未扩展时转入 Expansion。

树内策略决定到哪里寻找信息；模拟策略决定如何给叶节点估值。把二者混为一谈，很容易在实现中破坏选择与回传逻辑。

04 · 哪些统计量足以支持下一次决策？

N(s,a) 是从 s 走 a 的次数；W(s,a) 是这些回报之和；Q(s,a) 是平均回报。G 可为终局胜负、有限期累计奖励或折扣回报，但各分支必须采用一致尺度与玩家视角。

Q(s,a)=∑i=1N(s,a)GiN(s,a)

EQ 01 Gᵢ 是从边 (s,a) 开始的第 i 次模拟回报；N(s,a) 是该边访问次数。这是统计估计，不能误认为神经 Q 网络。

假设 A 被试过 20 次，Q=0.72；B 只被试过 5 次，Q=0.58。直接贪婪选择 A 可能遗漏 B 的潜力，因为少量样本难以说明 B 真的更差。

05 · UCT：同时奖励“表现好”和“还不确定”

Kocsis 与 Szepesvári（2006）将 UCB1 的探索—利用思想放到树中，使每个已展开的父节点像一个局部多臂老虎机，按置信上界在它的孩子间选择。

UCT(s,a)=Q(s,a)+cln⁡N(s)N(s,a)

EQ 02 c ≥ 0 是探索系数；N(s) 是父节点访问次数。此为常见 UCT 归一化记法；原论文还讨论奖励范围与参数形式。未访问分支应先扩展，不能将 N(s,a)=0 直接代入分母。

Q 利用项

历史平均回报越高，倾向复用这条分支。

U 探索项

子节点访问次数在分母；少量访问会得到额外优先权，避免过早放弃。

c 的含义

更大意味着更重视试探；奖励范围和应用不同，系数并无统一最优值。

注意：普通 bandit 的奖励分布通常作平稳假设，而树搜索的子动作价值会随下层搜索改进而变化。因此不能无条件把 UCB1 的简单置信界直接当作任意 MCTS 的有限预算保证。

06 · 交互实验：改变 c，优先动作如何翻转？

固定父节点访问 N(s)=40，A 的 Q=0.72、n=20，B 的 Q=0.58、n=5，C 的 Q=0.63、n=15；三个 n 之和为 40。只改变探索系数 c，计算每个分支的 UCT 得分。

动作 A · n=201.021Q = 0.72
动作 B · n=51.181Q = 0.58
动作 C · n=150.977Q = 0.63

当前优先选择 B。改变 c 观察得分更新。

这些数值是确定性的教学计算，而不是论文实验数据。在真正 MCTS 中，每一轮模拟后 N、W 与 Q 都会变化；这里保持它们不动，专门隔离探索系数的影响。

07 · 回传：为什么只更新实际走过的节点？

模拟结束得到 G，沿路径从叶子回到根，对经过的节点做 N ← N+1、W ← W+G；未访问的兄弟节点保持不变。均值可在线更新：

Qnew=N·Qold+GN+1

EQ 03 旧统计已含 N 次回报，再增加一份新回报 G；将累计 W 与 N 单独存储，效果与上式相同。

双人零和博弈尤其要说明价值视角：若统一存“根玩家收益”，轮到对手行动时选择应对应对手目标；若存“当前行动方收益”，回传时需进行一致的视角/符号转换。两种约定可用，但不能混用。

这里的 Backpropagation 是统计回传，不是神经网络链式法则意义上的梯度反向传播。

08 · 一个可以手算的两层决策树

根节点有动作 L 和 R；L 分支终局奖励分别为 0.2、0.5，R 分支是 0.8、1.0。这个例子仅有单个最大化奖励的智能体，因此不用转换双人对手视角。UCB 选择、未访问分支优先扩展、随机 rollout、回传构成完整循环。

先走 L

可选 l1→0.2 或 l2→0.5。最好的 L 分支仍低于任意 R 结果。

先走 R

可选 r1→0.8 或 r2→1.0。预算充足时该分支预计获得更多访问。

早期采样次序取决于随机种子和扩展策略，不应虚构“第几轮必选哪条边”。搜索结束的常见根节点选择规则是：

a*=argmaxaN(s,a)

EQ 05 最终行动常按根节点访问次数最多选择；与按最高 Q 选择并非必然相同。

按最多访问数选择与按最大 Q 选择并不等价；二者在有限次数的模拟下可能给出不同动作。

09 · 2006 原论文提供了什么证据？

主论文 Bandit Based Monte-Carlo Planning 针对有环境生成模型的大状态空间规划，提出 UCT 并研究有限时域及折扣 MDP 的相合性和采样误差界。相关论证依赖具体条件，不能扩写为任意未知环境中“总能选到最优动作”。

证据设置可合理得出的结论
2006 · §2rollout-based planning，局部 UCB1在树内平衡探索/利用，并给出带条件的理论分析
2006 · §3人工树 P-games、sailing 规划；与 Monte Carlo 等基线比较在论文指定任务与预算下 UCT 展现效率优势
Browne et al. 2012 · §3方法学综述与四阶段标准流程解释不同 MCTS 变体的共同结构与差异

本教程不把论文图中的近似读数冒充精准实验表，也不把 P-game 或 sailing 的历史结果当成 AlphaZero、LLM 或现实机器人任务的基准。

10 · AlphaZero 之后：加入神经策略先验 P 的搜索

AlphaGo Zero / AlphaZero 等后续工作把神经网络引入树搜索：策略头估计各动作先验 P(s,a)，价值头估计叶状态价值；不再必须完全依赖随机终局 rollout。常见 PUCT-style 选择项可以写为：

PUCT(s,a)=Q(s,a)+cpuctP(s,a)N(s)1+N(s,a)

EQ 04 现代常见 PUCT-style 机制示意；不同 AlphaZero 系实现可有 c 的日程、噪声与其他细节，并非原始 2006 UCT 公式。

这里是帮助理解的代表性形式。具体 AlphaZero 系实现还会区分访问计数的定义、探索系数日程和根噪声。对照 DQN（学习动作价值）、PPO（通过轨迹更新策略）：MCTS 是在给定转移规则或模型下做当前时刻的前瞻决策，可与学习器组合，但不是其中任何一种训练目标。

11 · 用标准库代码验证，而不是只背流程图

仓库中 mini_mcts.py 提供两层单智能体树的可执行示例：树节点记录 parent、children、untried、visits、total；每次迭代扩展一个孩子，并使用固定 seed 的随机 rollout。

for simulation in range(budget):
    node = select_with_uct(root)
    child = expand_one_untried_action(node)
    reward = rollout(child)
    backpropagate(child, reward)

action = most_visited_root_child(root)

以上是控制流伪代码，非源文件的直接调用 API。可运行版本请使用：

python posts/reinforcement-learning/mcts/mini_mcts.py
python -m pytest -q tests/test_mcts.py

测试验证根访问次数等于模拟预算、所有根孩子访问次数之和一致、固定随机种子可复现，以及特制奖励树优先选择 R。没有训练神经网络，也没有复现 Go 棋力或其它论文基准。

12 · MCTS 不会自动修复错误的模型

模型偏差

模拟器如果错误，搜索越深也可能只是更努力地优化错误世界。

罕见陷阱

随机 rollout 很难遇见的低概率灾难分支，可能在很长预算下才被发现。

高分支数

动作过多会使扩展成本攀升；可考虑 progressive widening 或有依据的候选筛选。

双人视角

如果价值存储和行动方最大化方向不一致，对手就会被错误地当成你的合作者。

计算开销

每次 rollout 均需模拟。树复用、截断价值、并行化都要仔细定义统计一致性。

有隐藏信息、随机对手、非平稳环境或连续动作时，必须重新定义状态/信息集、模拟策略和有效的理论前提。

13 · 留下三条足够准确的心智模型

一，树是不断更新的采样账本：价值来自反复模拟及其路径记录，而非事先遍历所有可能。

二，UCT 不只相信最高均值：探索奖励让还未充分验证的分支继续保留机会。

三，网络引导搜索是后续路线：AlphaZero 的 PUCT 和价值网络重要，但不能被当成 2006 年原始 UCT 的必要条件。
