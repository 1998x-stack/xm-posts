Understanding NoisyNet

为什么让神经网络权重带上可学习的噪声，可能比每一步随机选动作更有探索性？从参数噪声的时间一致性到 Atari-57 原始实验的证据。

Fortunato et al. · ICLR 2018约 35 分钟Parameter Noise / DQN / Dueling / A3C

01 · 不是每步多投一次骰子，而是改变一整段决策的偏好

想象游戏角色必须连续数步向右才能走出走廊。ε-greedy 随机动作每步都独立，刚形成的行为很容易在下一步被打断。能否让一次随机扰动影响接下来一整段行为，同时仍然对不同状态采取不同动作？

Noisy Networks for Exploration（Fortunato et al., ICLR 2018）的核心，是在参数空间采样网络权重，而不是每一步都人为插入随机动作。一次权重采样产生一个随机的 Q 函数或策略；此函数在多状态间保持结构性相关，形成持续的状态依赖探索。

02 · DQN 与 NoisyNet：随机动作和随机价值函数的差别

普通 DQN 使用 Q(s,a) 估计动作价值，并通过 ε-greedy 在贪心动作与随机动作之间切换。NoisyNet-DQN 去掉这一 ε-greedy 启发式，在 带噪声的随机 Q 函数上贪心选动作；Replay Buffer、TD 目标与目标网络仍然保留。

论文另外考察 Dueling 和 A3C。Dueling 的 Value/Advantage 结构和 Double-DQN 目标不能直接当成 DQN；A3C 本身使用随机策略，其动作从 policy 分布采样而不是 argmax。统一的是“可学习参数噪声”，不是统一的动作采样机制。

03 · Noisy Linear：用 μ、σ、ε 重新参数化权重

普通全连接层 y=Wx+b。Noisy Linear 把 W 和 b 改写成均值参数 μ、尺度参数 σ 与一次噪声抽样 ε 的组合：μ 决定一般偏好，σ 决定对噪声的敏感程度，ε 由固定分布抽样且不需要训练。

y=(μ+σ⊙ε)x+b

此式是合并符号示意；完整层为 (μᵂ+σᵂ⊙εᵂ)x + μᵇ+σᵇ⊙εᵇ；μ、σ 为可学习张量，ε 是噪声抽样。论文 Eq. (9)。

完整形状为 x∈ℝᵖ，μᵂ、σᵂ、εᵂ∈ℝᵠˣᵖ，偏置相关向量∈ℝᵠ。可学习线性层参数大致翻倍，不代表每次训练都复制网络。参见论文 §3 Eqs. (8)–(9)。

04 · Independent 与 Factorised Gaussian：省的是什么？

如果每个权重和偏置都独立采样，高斯随机变量数量为 pq+q；如果每个输入和输出各抽一个高斯变量，然后用 f(εⱼ)f(εᵢ) 组合权重噪声、用 f(εⱼ) 作为偏置噪声，则只需 p+q 次抽样。原文选择 f(z)=sgn(z)√|z|。

εjiW=f(εj)f(εi)

其中 f(z)=sgn(z)√|z|，i 是输入索引，j 是输出索引；偏置噪声是 f(εⱼ)。论文 Eqs. (10)–(11)。

pq+qp+q

独立采样需要 pq+q 个高斯变量，因子化只需 p+q 个；可学习 μ 与 σ 参数数量并未减少。

若 p=512、q=18，独立随机量数为 9,234，因子化为 530。大幅降低的是随机数生成数量；矩阵乘法和逐权重的 μ/σ 参数依然存在。论文中 DQN/Dueling 采用因子化噪声，A3C 的主要实验使用独立噪声。

05 · 随机程度如何学出来：重参数化的梯度

把实际权重写作 θ=μ+σ⊙ε，对噪声求期望的损失仍可通过自动微分训练 μ 与 σ。论文使用单次 Monte Carlo 抽样估计梯度，即训练时不必枚举所有可能的噪声矩阵。

∇μ,σE[L]=E[∇μ,σL(μ+σ⊙ε)]

论文 §3 Eqs. (12)–(13) 使用一次样本近似期望梯度；符号中 E 的随机变量是 ε。

一维例子 y=(μ+σε)x、L=(y−t)²/2 对 σ 求导，得到 ∂L/∂σ=(y−t)εx。可见噪声尺度的更新方向依赖误差与 ε，并不保证自动趋零。这是期望损失上的可训练扰动，并非显式的贝叶斯后验近似。

06 · 初始化要按噪声类型分别看

原论文 §3.2 的 factorised 方案，μ 按 Uniform(−1/√p,+1/√p) 初始化，σ 每个元素初始化为 σ₀/√p，且 σ₀=0.5。独立噪声方案则使用以 √(3/p) 为界的 μ 初始化，以及 σ=0.017 的初值。

0.5 是因子化方案的初始系数，不是固定到训练结束的噪声强度；现代库的同名参数通常也只指定初始化，不要把它误当成探索概率 ε。

07 · NoisyNet-DQN 的噪声，究竟何时重采样？

原论文 §3.1 和 Appendix C.1 的 DQN / Dueling 使用 Factorised Gaussian Noise：去掉 ε-greedy，当前带噪 Q 网络以 argmax 选择动作。在一次 Replay Buffer 小批量的优化中，当前在线网络的噪声样本保持固定；优化结束后重采样，因 DQN 每个动作步通常对应一次更新，表现为动作前更新噪声。

z=r+(1−d)γmaxa′Q(s′,a′;ζ⁻,ε′)

这是以终止标志 d 扩写的 NoisyNet-DQN 目标，论文 Eq. (14) 还对独立的 online/target 网络噪声求期望。

目标网络 Q⁻ 的噪声 ε′、在线 TD 估计的 ε、行动时的 ε″ 应独立采样。论文特别指出，相关的在线/目标噪声会影响损失估计。终止状态时 (1−d) 项将 bootstrap 置零。

08 · NoisyNet-Dueling 与 NoisyNet-A3C 并非同一个配方

Dueling：网络架构和 bootstrap 规则不同

论文的 NoisyNet-Dueling 具有 Value / Advantage 分支，使用 Double-DQN 形式的目标：由在线网络选择下一动作，再由目标网络评估该动作（§3.1 Eqs. 15–16）。因此不能把 Dueling 一行当成只是把普通 DQN 的输出层改成 NoisyLinear。

A3C：仍从 policy 采样动作

NoisyNet-A3C 的主体实验使用 Independent Gaussian Noise，将 policy 相关全连接层改成带噪形式，并移除 entropy bonus。但 A3C 仍使用概率策略采动作，不是 DQN 那种贪心 Q 选择。同一个 n-step rollout 内使用相同噪声样本，优化后才重采样（论文 Eq. 17）。

Appendix D 另有 Factorised NoisyNet-A3C 比较，不能把该变体的结果和 Table 1 主体 A3C 行混为一谈。

09 · 动手改变噪声：为什么动作偏好会翻转？

这个两动作小实验使用基础价值 Q₀=(1.30,1.10)，并以 Q=Q₀+σε 演示不同噪声样本对 argmax 的影响。它是数学玩具，不是训练后的 Atari 网络。移动 σ，点击按钮在预设的四组可复算 ε 中循环。

此处用单个 σ 代替真正模型里的逐权重 σ 张量，以便直观看到选择边界。

在 σ=0 时，所有样本的 Q 都回到基础值；较大 σ 下，原本分数较低的动作 1 也可能被选中。真正的 NoisyNet 通过 RL 损失学习 σ，动作扰动也随状态变化。

11 · σ 必然下降到零吗？Figure 3 告诉我们没有

原论文 §4.2 / Figure 3 追踪五个 Atari 游戏的不同层平均绝对 σ。最后一层在示例游戏中总体下降，但倒数第二层只有部分游戏下降，其余游戏的噪声可能保持或增加。学到的探索强度并非固定退火日程。

更重要的是，原论文 Conclusion 承认性能改善可能同时来自探索机制和优化效应：改变损失期望的方式也会影响优化轨迹。数据支持 NoisyNet 整体替换方案在这些实验中的收益，不证明每一分提升全都来自探索本身。

12 · 四个常见误读与复现风险

其一：把 NoisyNet 当成向最终动作添加高斯噪声。DQN 中随机性来自 Q 网络参数；A3C 中策略本身仍然随机采样。其二：把 p+q 个随机量误以为只有 p+q 个可学习参数。μ、σ 仍是原始线性层对应大小的张量。

其三：在一个 replay batch 内逐样本重采在线 ε，或为在线/目标网络共用同一 ε。这样与原论文 §3.1 的采样时序不一致；A3C 同一 rollout 也应维持固定噪声。

其四：把早期 Atari no-op starts 的结果直接和现代 sticky-actions / 不同 emulator 设置的数据并排说成可比。需要核对环境版本、训练帧预算、评估种子、报告统计指标。

13 · 最小可执行代码：数学核验不是 Atari 复现

同目录 mini_noisynet.py 用 Python 标准库检查因子化 f(ε)、权重与偏置噪声形状、线性输出、梯度有限差分，以及 Table 1 的百分比计算。它仅提供确定性的数学核验；训练完整 Atari 系统还需要 ALE 环境、网络参数、目标更新与数亿交互帧。

from math import copysign, sqrt

def f(z):
    return copysign(sqrt(abs(z)), z) if z else 0.0

def factorised(eps_in, eps_out):
    u = [f(v) for v in eps_in]
    v = [f(v) for v in eps_out]
    return [[b * a for a in u] for b in v], v

noise_w, noise_b = factorised([1.0, 4.0], [9.0, -16.0])
assert noise_w == [[3.0, 6.0], [-4.0, -8.0]]
assert noise_b == [3.0, -4.0]

运行命令：python posts/reinforcement-learning/noisynet/mini_noisynet.py。测试集另外通过 tests/test_noisynet.py 直接执行断言。

14 · 三个心智模型、原论文与后续工作

第一，参数扰动带来跨时间相关的状态依赖策略变化；第二，噪声尺度由梯度学习，而非简单手工退火；第三，这是一种可叠加到不同 RL 算法的探索机制，但每种算法的采样时序和实验对照必须单独说明。
