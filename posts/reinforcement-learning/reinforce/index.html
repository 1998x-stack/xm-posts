PAPER STUDY / REINFORCEMENT LEARNING / POLICY GRADIENT

Understanding
REINFORCE

我们不知道环境的导数，却仍然能把「一次尝试之后的奖励」变成策略的梯度。关键不是猜出环境如何运作，而是问：刚才做出的随机选择，有多大程度是当前策略促成的？

Ronald J. Williams · 1992Policy Gradient / Score Function约 42 分钟

01 · 一次下注，如何教会一个概率？

想象一个两按钮机器。动作 1 的奖励为 +2，动作 0 的奖励为 0。你没有模型，也没有一个能对「机器」求导的公式；你只知道点了哪个按钮、得到了多少分。

最直接的想法是：得到好结果，就把刚才动作变得更可能。但如果策略随机选择，偶然一把赢了可能只是运气。REINFORCE 的精妙之处在于：用每次抽样的对数概率梯度乘以反馈；平均起来，它指向期望奖励的梯度。

这个小故事里「奖励函数不可微」不影响更新，因为我们不对奖励值的生成机制反向传播；策略本身给出了可微概率分布。

02 · 学的不是动作，而是动作分布

策略 πθ(a|s) 把状态 s 映射成动作分布。动作 a 由分布采样。对离散两动作问题，可用一维 logit θ 和 sigmoid 概率 p=σ(θ)；在一般状态输入下，θ 则是网络权重向量。

(1)J(θ)=𝔼τ∼pθ[R(τ)]

这里先固定有限时域、无折扣 γ=1；轨迹 τ 包含状态、动作、奖励。环境初始分布与转移核不依赖 θ。

区别在于：监督学习通常已知正确标签，而强化学习只在执行动作后收到反馈。对一批由当前策略采集的样本，REINFORCE 求的是性能目标关于策略参数的梯度，不是奖励关于环境状态的导数。

03 · 把不可微的环境绕过去：log-derivative trick

一条轨迹的概率可以拆成初始状态概率、环境转移概率、每一步的动作概率三部分。只要环境转移核本身不随策略参数 θ 改变，log 轨迹概率对 θ 的导数，就只留下动作 log-prob 之和。

(2)∇θJ=𝔼τ[R(τ)∑t=0T−1∇θlogπθ(at|st)]

对轨迹密度使用 ∇p=p∇log p。环境转移概率随 θ 不变，因而只对策略概率求导。

可以把这个信号理解为：成功动作的 log-prob 越值得增加，就朝增加它的方向走；差结果则反向调整。不过，单条样本不是目标真实梯度，只是随机估计。它可能与最终最优方向相反。

04 · Williams 1992：原始算法究竟证明了什么？

经典论文 Williams, Simple Statistical Gradient-Following Algorithms for Connectionist Reinforcement Learning (1992) 研究的是随机单元组成的 connectionist 网络，重点先是关联式、即时奖励问题，随后才讨论特定形式的回合式延迟奖励。

(3)Δwij=αij(r−bij)eij,eij=∂loggi∂wij

Williams (1992) §4，第 234 页。α 为非负学习率因子，b 不得依赖同次采样单元的输出；e 是 characteristic eligibility。

原文 Theorem 1 证明：在基线与学习率满足条件时，平均权重更新方向与期望奖励的梯度方向夹角不钝；共享正学习率因子 α 的特例，期望更新恰好等于 α 倍的梯度。注意，这不是「每一次抽样都改对」、不是「任意步长单调提升」、也不是全局收敛保证。

历史边界：现代教材常直接写「整条轨迹回报 × log π」的 Monte Carlo 版本。它继承了同一 score-function 思想，但不应把现在的通用算法伪称成原文唯一的算法设定。原论文 §5 是回合末单一强化信号与累积 eligibility，见 Eq. (11)、Theorem 2。

05 · 为什么伯努利策略只需要 a−p？

在两动作情况下，a=1 发生的概率是 p，a=0 的概率是 1−p；当 p=σ(θ) 时，把伯努利 log-likelihood 对 θ 求导，恰好等于 a−p。

(4)∂logπθ(a)∂θ=a−p,p=11+e−θ

当 a∈{0,1}、p=σ(θ) 时成立。若 θ 是线性权重向量，则对应梯度为 (a−p)x，与 Williams 原文 Eq. (7) 对应。

如果采到了本来就罕见的动作 1，那么 1−p 较大：这个样本更有力地推动其 logit；若采到了动作 0，则得分为 −p。乘上奖励减基线之后，两个动作都会影响预期更新。

(7)∂J∂θ=p(1−p)(r1−r0)=0.455

固定 p=0.35、r₁=2、r₀=0：J=0.7，但相对于 logit θ 的梯度是 0.455；不是 0.7。

这里必须区分两个量：**J=0.70 是期望奖励；0.455 是 J 对 logit θ 的梯度。** 不能拿期望奖励直接当梯度，更不能把 p 自身当作 θ。

06 · 从单步到轨迹：奖励该归功于谁？

想象一个三步回合，r₀=1、r₁=0、r₂=3。若把整条回合总回报 4 都附给 t=2 的动作，它就莫名其妙获得了 t=0 时已经发生的奖励。去掉「过去的奖励」并不会改变梯度期望，但能避免这种不相关的噪声。

(5)Gt=∑k=tT−1rk,∇θJ=𝔼τ[∑t=0T−1∇θlogπθ(at|st)Gt]

Reward-to-go 只使用时刻 t 及以后奖励。式中 γ=1，有限回合。对带折扣的性能目标应重新核对 γ 的时点权重，不能直接混用定义。

这叫 reward-to-go，在现代 VPG / REINFORCE 教学中很常见。它仍是完整轨迹采样后的 Monte Carlo 估计，不是 TD bootstrapping，也不是凭空估计 Q 值。原论文 §5 研究的「回合末给一次 r，累积 eligibility」是与它相关但不等同的时间分配形式。

若采用折扣 γ<1，则要明确正在优化的目标及时间权重。例如对于从起始时刻定义的折扣回报，不能在不核对推导的情况下只把每一步 Gₜ 换成折扣和、却遗漏外层的 γᵗ 因子。

07 · 减去一个基线，怎么还能无偏？

假设当前策略已经预期可以拿到 1 分：实际拿到 1 分不必大幅加码；拿到比预期更高的结果才值得额外强化。把一个不依赖当次动作的 b(s) 从回报中减去，就得到相对好坏的信号。

(6)𝔼a∼πθ[∇θlogπθ(a|s)b(s)]=b(s)∇θ∑a=01πθ(a|s)=0

归一化恒等式 ∑ₐπ(a|s)=1。基线不能查看当前被采样的动作；若基线可训练，Actor loss 中通常要阻断其梯度。

推导只用了动作概率总和为 1；因此无论基线取多少，**梯度估计的期望不变**。但它的方差通常改变。常见选项 b(s)≈Vπ(s) 可降低实践方差，然而并非对所有参数、所有任务必定是方差最优基线。

为什么不能让 b 看见当前动作？ 若 b=b(s,a)，就不能从求和中提出，原有零期望证明不再成立。对神经网络的 Actor loss，值函数估计也通常需要 detach 以免出现非预期的反向路径。

09 · 无偏不代表学得快：方差才是代价

REINFORCE 不需要训练环境模型，也不需要 Critic，但训练信号通常稀疏、方差可能很高，且必须用当前策略采样。远期回报还会夹杂许多随机事件。增加采样数量可以平滑估计，却带来环境交互成本。

10 · 现代 episodic REINFORCE 如何落成代码？

下面以γ=1 的有限回合、无基线版本为出发点。每轮从 πθ 采样 N 条完整 episode，倒序累计 reward-to-go，计算负的 log-prob 加权损失，做一次或少量对应当前数据的梯度更新；下一轮重新采集 on-policy 数据。

(8)Lactor(θ)=−1N∑i=1N∑t=0Ti−1logπθ(ait|sit)(Git−b(sit))

梯度下降负损失等价于策略梯度上升；每条 episode 采样时固定 θ，更新后重新收集数据。没有 Critic 时可取 b=0。

  1. 初始化随机策略 πθ；采样完整回合，保存动作 log-prob、奖励与终止标记。
  2. 每条回合倒序累计 Gₜ；如需减方差，引入只依赖状态的基线并在 Actor 目标中阻断其梯度。
  3. 以 −logπθ(aₜ|sₜ)(Gₜ−b(sₜ)) 的批次均值反向传播；优化器执行下降。
  4. 用新策略重新采样。不要把旧轨迹永久放进 replay buffer 并称为原始 on-policy REINFORCE。

文末仓库附有 mini_reinforce.py 与 test_mini_reinforce.py，演示不依赖第三方库的梯度枚举、方差最优常数基线、固定种子的 Monte Carlo 检查，以及 reward-to-go。它们是数学最小核验，不是完整环境训练。

def score(a, p):
    return a - p

def reward_to_go(rewards):
    running, out = 0.0, [0.0] * len(rewards)
    for t in range(len(rewards)-1, -1, -1):
        running += rewards[t]
        out[t] = running
    return out

def gradient_sample(a, p, reward, baseline=0.):
    return (reward-baseline) * score(a, p)

# p=.35, r1=2, r0=0, b=1.3
assert reward_to_go([1, 0, 3]) == [4, 3, 3]
assert gradient_sample(1, .35, 2., 1.3) == (2-1.3)*(.65)

11 · 折扣回报：两个 γ 不在同一个位置

若奖励 [1, 0, 3] 发生在三个时刻，γ=0.8，那么起点回报是 1+0.8²×3=2.92。时刻 1 的未来回报是 2.4，时刻 2 的是 3；但我们优化的是从起点衡量的总收益，而不是把每个时刻重新定义成起点。

(9)J=𝔼[∑k=0T−1γkrk],Gt=∑k=tT−1γk−trk

有限回合、固定初始分布和环境转移，rₖ 表示第 k 步动作后的奖励。

(10)∇θJ=𝔼[∑t=0T−1γtGtzt],zt=∇θlogπθ(at|st)

先对轨迹似然求导；对每个 zₜ 去掉 k<t 的奖励（条件期望为零），再将 γᵏ 分解为 γᵗγᵏ⁻ᵗ。

这并不是说所有代码都必须显式乘 γᵗ：折扣访问分布、采样权重或不同性能目标可能已承担这一因子。只有明确目标和采样分布，才能判断实现是否与式 (10) 对齐。截断并不自动等价于终止：若目标包含截断后的奖励，直接丢掉尾部会改变估计。

12 · 从环境动作到 LLM token：一次回答如何反传？

固定 prompt x，模型逐 token 生成 y，EOS 是有效终止动作，padding 不是动作。把整个回答看成一个 contextual bandit 的宏动作，也可展开成以 prefix 为状态的有限回合。Verifier 或 reward model 返回标量 R(x,y)，无需对 verifier 或采样 token 求导；只需对生成序列的 log probability 求导。以下先假定固定奖励函数、on-policy、有限最大长度和完整采样协议。

(11)logπθ(y|x)=∑t=1Tlogπθ(yt|x,y<t)

同一个序列概率是条件概率的乘积；取 log 后变成求和，T 是实际生成的有效 token 数。

(12)L=−1B∑i=1BAi∑t=1Tmitℓit

B 条回答，统一 padding 长度 T；m 为 0/1 生成 mask，ℓ 为对应 token log probability，Aᵢ 为已 detach 的回答级权重。

一次 terminal reward 不知道具体哪一 token 导致成功，因此同一权重作用于整个回答的 score 总和。这是正确的期望梯度，却可能让无关 token 产生噪声。使用每条回答的 token 平均代替 token 求和会引入 1/Tᵢ 的长度权重；全批 token 平均也改变缩放并可能与随机长度相关，不能直接视为同一个序列目标。

张量和训练端的责任

logits [B,L,V] 沿词表 V 执行 log_softmax，取下一 token 的索引后得到 [B,L−1]；注意 shift 与 completion_mask 对齐。采样端记录行为 logprob，训练端计算当前 logprob；奖励、优势、mask 都不应把梯度传回采样过程。

# PyTorch 示意；logits 为 teacher-forced 输出
logp = logits[:, :-1].log_softmax(dim=-1)
chosen = logp.gather(-1, ids[:, 1:, None]).squeeze(-1)
# completion_mask 已与 ids[:, 1:] 对齐
seq_logp = chosen.masked_fill(~completion_mask, 0).sum(-1)
loss = -(advantages.detach() * seq_logp).mean()
loss.backward()

如果加入参考策略 KL，目标可定义为 E[R−β log(πθ(y|x)/πref(y|x))]，即固定参考分布下的序列 forward KL 正则。对 θ 的显式导数还有 −β E[score]，在正则条件下为零；因此 on-policy 时可用 detach 后的正则化回报乘 score。若直接对随 θ 变化的权重反传、使用旧策略样本或换成其他 KL estimator，必须重新推导，不能把它们混为同一个损失。

13 · RLOO、GRPO 与 rollout mismatch：何时仍然无偏？

同一道题生成四次，奖励 [1,1,0,0]。与其给每个回答固定基线，能否让同题的其他答案告诉它相对表现？Ahmadian 等（ACL 2024） 将 REINFORCE 与 leave-one-out 基线用于 LLM 对齐。下图是独立教学算例，并非论文实验数据。

(13)bi=1K−1∑j≠iRj,Ai=Ri−bi

K≥2；同题独立采样，Rᵢ 为单条回答自身的固定奖励。基线与当前回答条件独立。

若用包含自身的组均值，记它为 R̄，便有 Aᵢ = K/(K−1) × (Rᵢ−R̄)。未标准化、未裁剪的组均值估计期望恰好是真梯度的 (K−1)/K；RLOO 恢复这一个比例。证明：对其他样本的奖励项，独立性与 E[score]=0 使期望为零；自身奖励项留下 1/K 的梯度。若奖励跨样本耦合、采样不是独立同分布，该结论未必成立。

精确枚举：组大小如何改变梯度缩放？

二元奖励，Bernoulli p=0.35；精确真梯度 0.2275。切换 K 查看包含自身的均值与 LOO 的期望（无标准差归一化）。

K = 4；组均值梯度 0.170625；RLOO 梯度 0.227500；缩放 0.750000。

GRPO 在 DeepSeekMath 2024 §4.1 中使用组相对优势、PPO 类概率比裁剪与参考 KL；outcome 版本还用组内标准差归一化。标准差取决于整组样本，因此不能仅用上述常数比例证明它无偏。全组同奖时优势为零（实现需处理零标准差）；这不证明模型已经最优。RLOO 与 GRPO 都可不训练 Critic，但并不因此等价。

从无偏估计到训练推理一致性

REINFORCE 的严格形式要求数据来自当前策略。若 rollout 由行为策略 μ 采样，而梯度在 πθ 上计算，则对固定 prompt 的完整序列，可在支持集覆盖且比率可计算的条件下使用 importance sampling：

(14)∇θJ=𝔼μ[πθ(y|x)μ(y|x)R∇θlogπθ(y|x)]

固定奖励下的完整序列比率；需要对所有 πθ 有正概率的序列，μ 也有正概率。actor surrogate 中比率用于加权 score 时应阻断其额外梯度。

比率是各 token 比率的乘积，长序列可能具有极高方差。仅用当前 token 比率、clip、截断、top-k 或 top-p 后的采样概率不等于完整序列 IS；这些方法有各自的目标和偏差。实践应记录生成时实际采样分布（包括温度与截断）、模型版本、tokenization、EOS、mask、每 token logprob，比较训练重算差异，并监控 ratio 分布、有效样本量与 KL。若截断导致支持集缺失，完整目标不能靠 IS 恢复。

算法选择应根据奖励稀疏性、组内多样性、回合长度、rollout 吞吐与策略陈旧程度决定。REINFORCE 没有 Critic 的内存负担，但仍需生成、奖励评估和 actor 训练，不代表它在任何任务上都比 PPO 高效或更稳定。

14 · 论文证据与现代教学版本要分开

Williams (1992) 论文核心贡献是提出一类规则并证明其在指定条件下的统计梯度方向；文章包含特定随机单元和模拟讨论，但没有现代深度强化学习论文常见的 Atari / MuJoCo 统一实验表。不可凭今天的算法表现反向给 1992 原文添实验指标。

15 · 它如何通向 Actor–Critic 与 PPO？

REINFORCE ↔ DQN

前者直接优化随机策略概率；DQN 学的是 Q 值并使用 Bellman 自举，通常还能用离策略 replay。二者采样、目标和偏差—方差权衡明显不同。

REINFORCE ↔ Actor–Critic / PPO

学得的 V(s) 可用作 baseline；Actor–Critic 常配 TD 或优势估计。PPO 则通过概率比与裁剪代理目标约束反复优化行为，不是简单把 REINFORCE 的 learning rate 调小。

阅读顺序建议：DQN（价值学习）→ 本文（纯策略梯度）→ PPO（策略更新稳定性）→ SAC（离策略最大熵 Actor–Critic）。

16 · 四个容易混淆的边界

  1. 无偏是期望性质：单次更新可能让策略表现更差；论文给出的期望梯度关系也不等于全局收敛。
  2. 基线不是万能降方差：它应独立于当次动作，且不恰当的基线数值可以提高方差。
  3. 回报定义决定公式：本文为了清楚验证统一 γ=1；折扣奖励、continuing objective、GAE 等应另行核对权重与偏差。
  4. 历史版本不能互换：Williams 的随机连接网络、后续 policy-gradient theorem、今天的神经网络 VPG/PPO 各有不同假设与实现。

原文 §9 还明确讨论了当时缺乏一般性收敛理论和局部错误最优等限制。正确的 takeaway 不是 REINFORCE 很强，而是它揭示了一个重要事实：只知道随机选择及其反馈，仍能产生有数学依据的学习方向。
