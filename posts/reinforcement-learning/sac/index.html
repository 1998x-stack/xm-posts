Understanding SAC

旧经验为什么还能教会新策略？从一次过早确定的动作出发，逐步理解离策略经验回放、最大熵 Bellman 备份、随机 Actor 与可学习温度。

Haarnoja et al. · ICML 2018 + 后续版本约 36 分钟Off-policy / Maximum Entropy / Actor–Critic

01 · 一次成功，要不要让机器永远重复？

机械臂在训练中偶然用「向左绕」取到了杯子。直接把这次动作的概率推向 100%，似乎合理；可下一次杯子换了位置，过早确定就会阻断探索。另一个困难是：环境交互昂贵，我们希望旧经验仍然能提供新梯度。

Soft Actor-Critic（SAC）将两件事接在一起：离策略 Replay 复用历史数据，最大熵目标让策略既追求奖励，也保留有意义的随机性。它与 PPO 最本质的差异不在名字里的 Actor–Critic，而在数据能否跨训练轮次继续复用，以及目标函数里熵所占的位置。ICML 2018 原论文将这两者结合。[S01]

02 · 从普通 RL 到 Maximum Entropy

设状态 s∈S、动作 a∈A（本文以连续有界动作为主）、奖励 r(s,a)、转移 p(s′|s,a)、折扣 0≤γ<1。普通强化学习最大化期望累计奖励；最大熵强化学习额外奖励策略在状态上的条件熵。

J(π)=𝔼π[∑t=0∞γt(rt−αlogπ(at|st))]

( 1 ) 这是用采样动作的负对数概率表示期望熵的折扣写法；原论文主文的熵记法与此等价于期望意义下。

定义 H(π(·|s)) = Ea∼π[−log π(a|s)]；α ≥ 0 是温度。α 趋近零时，目标趋近不带熵的期望回报；增大 α 则更重视多样的高回报动作。对连续动作来说它是微分熵，数值可以为负，不能把负熵误判为程序出错。[S02]

03 · Soft Policy Iteration：为什么会出现指数形式？

先暂时忽略神经网络：给定当前策略 π，策略评估计算带未来熵价值的 Qπ；策略改进寻找兼顾高 Q 与高熵的新动作分布。固定某状态 s 时，最大化 Ea∼π[Q(s,a)] + αH(π) 并满足概率归一化，拉格朗日一阶条件给出下式。[S03]

π*(a|s)∝exp(Q(s,a)α)

( 2 ) 有限动作、归一化可定义时的直观形式。连续空间的配分函数未必容易计算；SAC 用可采样、可计算密度的 Actor 近似。

这个表达式解释了「soft」的来源：高 Q 动作更可能发生，却未必独占全部概率。原论文的 soft policy iteration 收敛证明建立在其离散动作/策略族等假设下；不能把该定理直接当成深度神经网络训练会收敛的保证。[S03]

04 · Soft Bellman：在普通 TD 目标里多了什么？

普通 DQN 式备份会寻找未来价值；SAC 的核心不同是把下一动作的 log probability一起放进未来的 soft value。对现代无独立 V 的 SAC，一条 Replay 样本 (s,a,r,s′,d) 与当前策略在 s′ 上抽到的 a′，形成：

y=r+γ(1−d)[mini∈{1,2}Q̄i(s′,a′)−αlogπ(a′|s′)]

( 3 ) a′ 从当前策略采样；Q̄ 是缓慢更新的目标网络；d 只表示真实终止，时间截断要按环境语义处理。

两个 Critic 分别最小化 E[(Qi(s,a)−stopgrad(y))² / 2]。对目标 y 停止梯度回传，且使用 min(Q̄₁,Q̄₂) 抑制 Q 过估计。这里的 γ 负责长期回报折扣，d 仅在真正终止时切断 bootstrap；Gymnasium 中的 truncated 通常不能与 terminated 无条件合并。[S04][S10]

05 · Actor 为什么不是简单 argmax Q？

在连续动作空间逐点求 Q 最大值代价很高，而且确定性最大值会丢失最大熵目标。SAC 引入一个可以采样且能计算概率密度的 随机 Actor。Actor 最大化 Q − α logπ；实现时通常把负号翻转，做下面的损失最小化。

Jπ(θ)=𝔼s∼𝒟,ε∼𝒩[αlogπθ(aθ|s)−mini=1,2Qi(s,aθ)]

( 4 ) aθ = tanh(μθ(s) + σθ(s) ⊙ ε)，μ/σ 与动作同维；Actor 的梯度要能经过动作回传到参数。

重参数化技巧使随机性来自独立噪声 ε，输出动作仍是网络 μ、σ 的可微函数。对 Actor 进行反向传播时，通常冻结 Critic 的参数更新，但必须保留 Critic 对动作的梯度；否则 Q 对「该选哪种动作」的指导就会断开。[S05][S10]

06 · 读 SAC 必须先分清两个版本

很多教程直接写成「两个目标 Q，没有 V 网络」。这描述的是广泛使用的后续版本，而不是 ICML 2018 首篇论文的全部结构。

ICML 2018 原版

使用随机 Actor、两个 Q 网络、独立 V 网络与目标 V。Q 目标通过目标 V 备份，V 拟合 Q − log π；原文 Eq. (5)–(13) 和 Algorithm 1 是主要依据。原文常以奖励尺度等方式处理熵与奖励的相对权重。[S06]

2018 后续 / 现代 SAC

后续论文以 Q 与策略直接估计 soft value，去掉独立的 V 网络；Twin Q 各有缓慢更新的目标副本，允许学习温度 α。Spinning Up 所述也是现代这一脉络，但其示例使用固定 α。[S07][S10]

这种差异会影响伪代码、目标网络数量、损失函数和源码阅读。本文公式 (3)–(6) 按现代常用 SAC 表述；引用原论文实验时明确指向ICML 2018 原版。

07 · Tanh 高斯策略：为什么 log π 不能直接用高斯密度？

Actor 输出每维 μ(s)、logσ(s)，采样 u=μ+σ⊙ε，再取 a=tanh(u) 把动作压入 (−1,1)。但 tanh 改变了概率密度：如果仍以 log N(u;μ,σ) 作为 log π(a|s)，熵项就不对。

logπ(a|s)=log𝒩(u;μ,σ)−∑j=1dlog(1−tanh2uj)

( 5 ) 对每一动作维求和，a=tanh(u)。若动作经额外仿射映射到环境区间，还需计入相应 Jacobian 常数。

对高斯 squashing，雅可比修正等价于逐维减去 2(log 2 − u − softplus(−2u))。这不仅影响 Actor loss，也会进入 Critic 的 bootstrap 和自动温度更新。[S08][S10]

08 · 自动温度：如何在训练中控制探索程度？

固定 α 需要对任务奖励尺度仔细调参。后续论文将平均策略熵的目标写为约束，通过对偶变量 α 自动调整。目标是总体平均熵，不是每个状态必须恰好达到同一熵。[S07]

Jα(α)=𝔼a∼π[−αlogπ(a|s)−αH¯]

( 6 ) 后续论文 Eq. (18)；目标熵 H̄ 与当前状态分布的平均策略熵比较，最小化 Jα，且 α ≥ 0。

如果观察到的平均熵低于目标，优化过程倾向提高 α，从而增加熵项权重；高于目标则倾向降低。许多实现优化 log α 以保证 α 为正；它的梯度尺度和直接优化 α 并不完全相同，应查看代码实现。[S07][S10]

09 · 亲手调 α：同一组 Q 值会如何改变选择？

这是一个离散动作、单状态的 Boltzmann 教学模型：三个动作的 Q 分别为 3、2、0，令 pi ∝ exp(Qi/α)。它只演示软策略改进的温度趋势，不是连续动作 SAC 训练，也不是策略网络输出。可切换 α 对比偏好的变化。

α = 0.50；动作概率约 87.9% / 11.9% / 0.2%（初始示意；点击按钮重新计算）。

10 · 把一次更新写成可核验的训练顺序

01 · 收集

按照当前随机 Actor 在环境中行动，将 (s,a,r,s′,terminated) 存入 Replay。可先随机探索并等待缓冲区积累数据。

02 · 抽样

从历史 Replay 独立抽 mini-batch；这就是离策略的样本复用，不要求所有记录来自当前参数。

03 · Q 更新

下一状态重新采样 a′ 与 logπ′，用目标 Q 的最小值减去 αlogπ′ 生成 soft target，回归两个 Q。

04 · Actor 更新

对 Replay 的状态重新采样可微动作，最小化 αlogπ−minQ。保留 Critic 对动作的导数。

05 · 温度与目标网络

若使用自动温度，另做 α 更新；然后按 Polyak/EMA 缓慢更新目标 Q 参数，继续采样与训练。

关键形状：状态 mini-batch [B, obs_dim]、动作 [B, act_dim]，两个 Q 和 logπ 的约定输出均可规整为 [B]。必须确认 logπ 已按动作维求和，否则目标中的广播会悄悄改变损失。[S09][S10]

11 · 最小可运行代码：只验证数学，不冒充完整 SAC

仓库的 mini_sac.py 不依赖深度学习框架，提供软目标、Actor 损失、数值稳定的 tanh log-density 和温度目标；另有确定性测试 tests/test_sac.py。它不训练环境、不复现 ICML 实验。

from math import exp, log, log1p, pi, tanh
def soft_target(r, gamma, terminal, q1, q2, logp, alpha):
    return r if terminal else r + gamma*(min(q1,q2)-alpha*logp)
def actor_loss(logp, q1, q2, alpha):
    return alpha*logp-min(q1,q2)
def softplus(x):
    return max(x,0)+log1p(exp(-abs(x)))
def tanh_gaussian_logp(u, mu, sigma):
    gaussian=-.5*((u-mu)/sigma)**2-log(sigma)-.5*log(2*pi)
    return gaussian-2*(log(2)-u-softplus(-2*u))
assert abs(soft_target(1,.9,False,5,3,-.5,.2)-3.79)<1e-12
assert soft_target(1,.9,True,5,3,-.5,.2)==1
assert abs(tanh_gaussian_logp(0,0,1)+.5*log(2*pi))<1e-12

注意：target 的精确结果为 3.79，因为 1+0.9×(3−0.2×(−0.5))=3.79；terminal 应直接返回 reward；u=0 时 tanh 的 Jacobian 修正恰好为 0。

12 · 原论文究竟证明了什么，没证明什么？

ICML 2018 的 Figure 1 报告 Hopper、Walker2d、HalfCheetah、Ant、Humanoid 等连续控制环境上的学习曲线，并对照 DDPG、PPO、SQL 与并行工作的 TD3。该文 Figure 1 图注讨论 SAC 在困难任务上的表现；方法与超参数对照必须结合 Figure 1 与 Appendix D 阅读。[S11]

论文 Figure 2 展示 Humanoid (rllab) 上 SAC 随机策略与确定性变体跨不同种子的差异；作者将随机策略与熵最大化联系到更稳定的表现。Figure 3 讨论评估方式、奖励尺度和目标平滑参数的敏感性；不能据此声称任意环境、任意奖励尺度都稳健。[S12]

后续 Algorithms and Applications 讨论自动温度的扩展与额外任务；它并非 ICML 2018 同一实验表格的简单复刻。本文不录入缺乏统一协议的二手分数，也不把代码单测写成强化学习性能复现。[S07]

13 · SAC / DDPG / TD3 / PPO：到底差在哪？

方法交互数据Actor关键优化思想
PPOOn-policy通常随机旧/新策略比的 clipped surrogate
DDPGOff-policy确定性Q 引导确定性策略梯度，外加探索噪声
TD3Off-policy确定性双 Q、延迟策略更新与目标平滑
SACOff-policy随机最大熵目标、soft Q、双 Critic

这是一张算法族特征对照，不是哪一个「必然更好」的普遍排序。SAC 主线关注连续控制；离散 SAC 等扩展要另行声明动作分布与数学形式，不能直接照搬连续 tanh-Gaussian 的 log-density。

14 · 诊断常见失效，而不是只盯奖励曲线

负熵值

连续动作微分熵可以为负；先看单位、动作缩放和 tanh Jacobian，不能用离散熵直觉判断。

α 飙升或归零

先核对目标熵符号、logπ 计算、奖励尺度以及 α/ logα 的更新方向。

Q 值虚高

确认双 Critic 最小值、target detach、目标网络 EMA、终止 mask 与 reward scale。

Actor 没学到

确认每维 logπ 汇总为 [B]，且 Actor 步允许 Q 对动作求导，而不是只让熵项产生梯度。

样本效率差

检查环境步与梯度更新比、Replay 热启动、评估协议、随机种子以及是否混入旧环境 reward 定义。

带走一个因果链：旧经验可复用 → 双 Q 建立可信的软价值 → 随机 Actor 找到高 Q 且有熵的动作 → tanh 密度修正保证目标正确 → 温度调节维持长期探索。
