Understanding TD3

为什么让一个 Critic 少犯错还不够？从 DDPG 的「高估—策略追逐」闭环，理解双 Q 截断、延迟策略更新与目标策略平滑如何协同稳定连续控制。

Fujimoto · van Hoof · Meger，ICML 2018约 38 分钟论文：PMLR 80:1587–1596

01 · 为什么 DDPG 会被自己的 Critic 误导？

连续控制里，Actor 不必枚举所有动作，而是直接沿 Critic 给出的价值梯度移动。但如果 Critic 的函数逼近在某处出现虚假的高峰，Actor 就会认真地朝错误方向优化；反过来，这些被偏爱的动作又进入 bootstrap 目标，误差可能继续扩大。

原论文 §4.1 讨论确定性策略梯度中的高估现象，Figure 1–2 对比不同 Actor–Critic 变体的估值偏差。不要把所有错误都归因于 max 运算：连续动作的 Actor 用梯度最大化近似 Q，同样可能主动寻求估计偏差。

TD3 的目标不是让 Q 永远精确，而是压低高估造成的反馈增益，并减少高噪声估计对下一次策略更新的破坏。

02 · 基线：DDPG 的一个 Actor 与一个 Critic

先固定名词：状态 s ∈ ℝᵈˢ、动作 a ∈ ℝᵈᵃ；确定性 Actor πφ(s) 将一个 batch [B,dₛ] 映射成 [B,dₐ]，Critic Qθ(s,a) 把它们映射成 [B,1]。DDPG 从经验回放 𝔅 抽取转移，用目标网络为 Q 提供监督，再通过 Q 对动作的导数更新 Actor。

DDPG 的优势

不需要在连续空间里做显式 argmax；可以离策略复用历史交互，并用 Polyak 目标网络缓和训练的移动靶问题。

DDPG 的隐患

单 Critic 的估计误差可能被 Actor 利用；Actor 和 Critic 同步频繁更新时，错误监督与策略会相互放大。

TD3 保留了单一确定性 Actor、经验回放、目标网络，改造的是价值目标、更新节奏、目标动作附近的估值方式。这不是 PPO 的 clip surrogate，也不是 SAC 的熵正则策略。

03 · 第一处改造：双 Critic 与截断双 Q

用两套独立初始化并分别训练的 Critic Qθ₁、Qθ₂ 评估同一个目标动作。它们都朝同一个较小值 Bellman target 回归，Actor 仍只沿 Qθ₁ 的动作梯度更新。

y=r+γ(1−d)mini∈{1,2}Qθ′i(s′,a~)
Eq 01论文 §6 Eq.(15) 的最小目标，加上现代实现中明确的真正终止掩码 d。tilde a 是目标策略平滑动作，非当前行为策略动作。

最小运算倾向于抑制高估，但允许低估。只有两个 Critic 就并不意味着误差独立或消除偏差；若二者同时高估、都依赖相同经验，取最小值依旧可能高估。论文 §4.2 Eq.(10) 先建立 clipped double Q 的形式，§6 将其装入完整 TD3。

04 · 第二处改造：延迟 Actor 更新

如果 Critic 还没学稳就立即让 Actor 爬升，下一次 Critic 又得追着移动的策略学习。TD3 把两种更新分到不同频率：Critic 每次训练，Actor 与全部目标网络每隔 d 次 Critic 更新才训练一次。论文实验取 d = 2。

J(φ)=𝔼s∼𝔅[Qθ1(s,πφ(s))]
Eq 02实际以 J 的负值作为 actor loss 做梯度下降；Critic 参数在 Actor 更新步骤中固定。

这里的两时间尺度不是对训练稳定性的数学保证。d 太大使策略更新次数不足；d = 2 是论文实验选择，不是所有环境的最优超参。

05 · 第三处改造：目标策略平滑

真实连续控制通常希望相近动作有相近的合理价值。若后继 Critic 恰好在 π′(s′) 出现很窄的尖峰，单点 bootstrap 会放大不可靠的估计。TD3 在目标 Actor 的动作加小幅截断高斯噪声，再让双目标 Critic 评估它。

a~=πφ′(s′)+clip(ε,−c,c)
Eq 03论文 §5.3 Eq.(14)、Algorithm 1；ε 从均值为零的高斯分布采样。实际实现通常再把 ã 限制到合法动作区间。

请区分两种噪声：行为探索噪声加在与环境交互的当前 Actor 动作上，用于探索；目标策略平滑噪声只在构造 TD target 时作用于目标 Actor，影响 Critic 的训练监督。原论文 §6.1 的行为探索采用独立高斯噪声，而非原始 DDPG 常用的 OU 噪声。

06 · 把三处改造拼成一张计算图

每条转移 (s,a,r,s′,d) 一次训练同时影响两个 Q 网络；只有满足延迟条件时才更新 Actor。目标网络在此之后进行缓慢追踪，并且计算 y 时停止梯度，不对目标网络反向传播。

Li=1B∑j=1B(Qθi(sj,aj)−yj)2
Eq 04i∈{1,2}；B 是 batch 大小。两个 critic 分别优化，但监督 target y 相同。
θ′←τθ+(1−τ)θ′
Eq 05每个 target critic 和 target actor 都使用此形式；原论文取 τ=0.005，采用较小 τ 乘在线参数的定义。

张量形状：对 batch B，π′(s′) 是 [B,dₐ]，两套目标 Q 的输出都是 [B,1]，按元素取 min 仍是 [B,1]；奖励与终止掩码应先整理为 [B,1] 再计算，不得与 [B] 意外广播成 [B,B]。

07 · 训练循环：每一步谁更新、何时更新？

01 · 收集

用当前确定性 Actor 加行为探索噪声与环境交互，将有效动作与转移写入 Replay Buffer。

02 · 采样

从 Replay 均匀抽样；每个 batch 用目标 Actor 构造带截断噪声的下一动作。

03 · 估值

从两个目标 Critic 取最小值，用奖励、折扣和终止掩码产生 y。

04 · 更新 Q

每一步分别最小化两个 Critic 的 MSE；detach 目标分支。

05 · 延迟更新

当计数满足 t % d == 0，让 Actor 最大化 Q₁(s,π(s))，然后同步软更新三个 target 网络。

这正是论文 Algorithm 1 的核心顺序。采集与更新的比率、并行环境数，以及时间限制截断的处理策略属于具体工程实现，需要在实验配置中注明。

09 · 为什么「目标噪声」不等于「探索噪声」？

收集数据时

动作取 clip(π(s)+η, action bounds)，η 是行为探索噪声；原论文 §6.1 在热身后选 Gaussian N(0,0.1)，前 1000 或 10000 步随机探索。

学习目标时

动作取 clip(π′(s′)+clip(ε,-c,c), bounds)；目标平滑参数实验取标准差 0.2，噪声裁剪 ±0.5。

当评估部署好的确定性 Actor，通常不给它额外的探索噪声。TD3 不需要把随机分布作为 Actor 的输出；它与 SAC 的最大熵随机策略有本质区别。

原论文 Table 2 衡量最后 10 次评估回报的平均值，跨 10 trials，与上一节 Table 1 的最大平均回报是不同指标。对比完整 TD3 与分别移除组件的版本：

Walker2d 的 −DP 在这份表上反而比完整 TD3 略高，说明「每个组件在每个任务必有正收益」是不成立的。总体而言，三项机制的联合作用有价值，改善的大小随任务而变。请勿把 Table 1、Table 2 混用得出因果结论。

13 · 可执行的最小数学核验

仓库附有无第三方依赖的 mini_td3.py，用标量样例检查 min-target、终止掩码、动作边界、截断噪声、软更新及延迟调度。它不是完整 MuJoCo trainer，不能复现实验回报。运行 python posts/reinforcement-learning/td3/mini_td3.py 或 pytest tests/test_td3.py。

# 目标值：两套目标 Critic 共用一个 label
noise = clip(gaussian, -noise_clip, noise_clip)
next_action = clip(actor_target(next_state) + noise, low, high)
target_q = reward + gamma * (1 - terminated) * min(
    q1_target(next_state, next_action),
    q2_target(next_state, next_action),
)
# 每步都优化两套 Q；每 policy_delay 步更新 actor & targets
if step % policy_delay == 0:
    actor_loss = -q1(state, actor(state)).mean()
    polyak_update_targets(tau=0.005)

尤其要检查 terminated 与 truncated 的区别，Critic loss 的数组形状、target 路径是否 detach、以及 actor loss 是否意外经过 Q₂。

14 · 容易混淆的边界与失败模式

双 Q 不是无偏

取 min 降低单侧高估风险，却可能向下偏，尤其当两个 Critic 都不准或高度相关时。

Actor 只有一个

两个 Critic 不是「两个 actor」；论文 §4.2 讨论了双 actor 的 Double Q 变体，但最终 TD3 使用单 Actor。

目标网络并非每步同步

标准 TD3 中，Actor 与目标网络一起延迟软更新，而不是每次 Critic 梯度步后立即更新所有 targets。

噪声来自不同路径

行为探索 noise 与 target policy smoothing 的使用位置和含义不同；测试时通常关闭两者。

运行代码不是论文复现

标量断言只证实局部数学关系，完整复现还需要精确环境、奖励、随机性、网络和训练预算。

15 · 与 DDPG、SAC 的研究脉络

DDPG 给出确定性连续控制的深度 Actor–Critic 基线；TD3（2018）专门处理估值误差、更新耦合和目标策略附近尖峰；SAC 通过最大熵目标与随机策略建立另一条稳定连续控制路线。它们都可使用 Replay Buffer，但策略目标和训练细节并不相同。

阅读顺序建议：先理解 DPG 的链式导数，再理解 DDPG 的 Replay/Target，随后对照 TD3 的 clipped double Q、delay、smoothing，最后考察 SAC 的 soft Bellman backup；不要把后来的 SAC twin-Q 版本倒灌到 2018 原始 SAC 论文中。
