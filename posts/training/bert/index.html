Understanding BERT

让每个 token 读懂左右上下文。为什么 MLM 能训练深层双向 Encoder？NSP 的真实证据是什么？下游任务如何只换一个输出头？

BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding原论文 + 后续研究边界预计阅读 34 分钟

01 · 先想一个悖论：为什么需要右侧的词？

“bank” 的意思会随 “river” 或 “credit card” 改变。假如一个位置只能阅读左边，右侧证据尚未进入它的隐藏表示。BERT 的主张不是“模型更会生成文本”，而是让所有层的 token 表示同时融合左右上下文，再用有监督任务验证迁移效果。

在 GPT-1 中，因果 Mask 保护“预测下一个 token”的任务定义；BERT 不用这套因果输入约束，而是以 Masked Language Modeling（MLM）制造预测缺口（Devlin et al., §1–3）。

一个看似细小却关键的区别：只有先让原词从部分输入中消失，才能要求模型真正从上下文推断它。否则带着答案预测答案，会退化成复制练习。

02 · 它与 Transformer、GPT-1、ELMo 是什么关系？

原论文 BERT 复用了 Transformer Encoder 结构：多头 Self-Attention、前馈层、残差与 LayerNorm，参数通过预训练任务学习。它并不是完整翻译用 Encoder–Decoder，也不等于今天的 Decoder-only 对话模型。

GPT-1Decoder-only。因果可见性，用自回归 LM 预测下一 token。
BERTEncoder-only。每层双向可见性，预训练 MLM + NSP，微调下游任务。
ELMo分别训练左右两个语言模型再拼接特征，而非同一网络中逐层双向融合。

这是原论文 Figure 3 与 Appendix A.4 的历史对照，不意味着 GPT-1 和 BERT 的训练语料、调参与下游设置完全相同。详细 Encoder 结构可与 Understanding Transformer 并读。

04 · BERT 的输入为什么要加三种嵌入？

原始英文 BERT 采用 30,000 个 WordPiece token 的词表。每个序列开头有 [CLS]，两个片段之间用 [SEP] 分隔，再附加段 A/B 的可学习标识。这些片段可以长于一个自然句子。

ei=Etoken(xi)+Esegment(si)+Eposition(i)

xᵢ 是 token，sᵢ 是 A/B，i 是位置；三个分量均为 H 维。此式是 Figure 2 的教学记号。

WordPiece 与 BPE 不是完全相同的 tokenizer 训练算法；不能把 GPT-2 的 byte-level BPE 细节反向写进 BERT。

05 · 双向 Self-Attention 怎样传播信息？

对输入隐藏矩阵投影出 Q/K/V 后，每个位置利用所有非 padding 位置的键计算相似度，再按 softmax 权重加权值向量；双向意味着没有强制的“未来不可见”下三角 Mask。

Attention(Q,K,V)=softmax(QK⊤dk+M)V

Q,K∈R^(T×dₖ)，V∈R^(T×dᵥ)；M 对有效位置为 0，对 padding 为负无穷。该公式来自 Transformer 基础，不是 BERT 首创。

这里每个位置确实可能注意到自身，因此 MLM 的输入替换是任务设计的必要组成部分；不要将“全向可见”误解成“监督目标可以直接留在输入里而毫无代价”。

06 · MLM：15% 抽样，不代表 15% 都变成 [MASK]

先抽取约 15% 的 WordPiece 位置参与预测。在被抽中的位置中：80% 替换为 [MASK]，10% 替换为随机词，10% 保持原词；三种分支都预测替换前的原词，其余约 85% 的位置不计入 MLM 目标。

ℒMLM=−1|𝓜|∑i∈𝓜logpθ(xi|x~)

𝓜 为监督位置集合，xᵢ 是原词，x 上波浪号为处理后输入；这是 §3.1 损失的数学展开，并非论文原印刷 Eq.编号。

换成全序列比例，期望约为 12% [MASK] + 1.5% random + 1.5% unchanged。单个序列因随机抽样、长度与边界效应，不必恰好满足这些百分比。

07 · Next Sentence Prediction 到底预测什么？

NSP 从两个文本片段构造二分类：B 有 50% 的概率是 A 的实际后续片段（IsNext），另 50% 从语料随机抽取（NotNext）。由最后一层 [CLS] 向量承担分类。它不是判断“这两句话语义是否相似”或“能否蕴含”的标注任务。

ℒpre=ℒMLM+ℒNSP

这里采用最小化负对数似然的约定；原文 Appendix A.2 说的是两个平均 log likelihood 的联合优化。

论文报告该目标在特定训练条件下改善某些句对任务，但是否必须保留 NSP，后来成为独立研究问题，不能直接从一张消融表推出普适结论。

08 · 历史训练配方：为什么短序列先跑 90%？

原论文 Appendix A.2：BooksCorpus（约 800M words）加英文 Wikipedia（约 2,500M words），batch 为 256 sequences，总计 1,000,000 steps，Adam 峰值学习率 1e−4，前 10,000 steps warmup 后线性衰减，GELU 激活、dropout 0.1。

一个真正影响训练成本的选择

前 90% 的更新用最大长度 128，后 10% 才用 512，以降低 attention 随长度增长的平方成本，并继续训练长位置。论文报告的 TPU 集群训练天数属于特定硬件配置，不应拿来当现代 CPU/GPU 的性能预测。

原始 BERT 的静态 masking、NSP 和分片策略是历史版本描述；RoBERTa 等后续方法会改变这些条件。

09 · 不同下游任务到底改动哪些输出层？

同一份预训练参数初始化不同任务的模型，各自端到端微调。分类用 [CLS] 的最终向量；NER 对每个 token 分类；抽取式问答在每个 token 上计算起点和终点得分。

pstart(i)=eS⊤Ti∑jeS⊤Tj

Tᵢ∈R^H 是第 i 个位置输出，S∈R^H 为可学习起点向量，终点向量 E 同理。来自 §4.2 的概率分解。

Appendix A.3 的微调搜索范围：batch 16/32，LR 5e−5、3e−5、2e−5，epoch 2–4。模型并不自动包含语义检索专训目标。

13 · 最小复现：只证明什么，不证明什么？

仓库提供 mini_bert_objectives.py 的标准库数值断言与 tests/test_bert_objectives.py。它检查 80/10/10 条件分支、原始 token 标签不变、双向与因果可见位置区别、被选中位置的交叉熵。这不是完整的 BERT 实现，更不是 GLUE/SQuAD 复现。

python posts/training/bert/mini_bert_objectives.py
python -m pytest tests/test_bert_objectives.py -q

进一步读代码可参考 google-research/bert 官方实现；运行历史模型还需要语料处理、分布式训练、数据许可证与基准复现协议。

14 · 这篇论文做到了什么，还有什么没解决？

第一，MLM 学得可迁移的双向上下文表征，却不直接给出 GPT 式逐 token 生成的自回归概率分解。第二，原论文 [CLS] 主要被 NSP 和监督分类头使用，不能因为它“汇总序列”就推断它天然是高质量句向量。第三，512 token 是原始 BERT 预训练长度上限；全局注意力存在随长度增长的二次开销。

后来 RoBERTa 检验训练配方与 NSP；Sentence-BERT 专门研究更适合句向量相似性的结构与训练。与 GPT-1 并读，可以把“预训练目标”与“模型主干类型”拆开理解。
