Improving Language Understanding by Generative Pre-Training2018 原论文预计阅读 30 分钟

01 · 只预测下一个 token，为什么能帮助读懂问题？

2018 年的 NLP 系统常常为文本分类、句子推断、阅读理解分别搭建网络，而高质量任务标签并不丰富。GPT-1 改变了学习顺序：先从大量未标注文本中预训练一个通用模型，再让这个模型完成不同任务的有监督微调。

“生成式”指第一阶段用语言模型的下一 token 预测目标训练，不代表当时已经有现代指令聊天接口。论文问题是：从文本中学习的参数，能否在不同任务间转移？参考 原论文 §1、§3。

02 · 它比词向量迁移多做了什么？

只把 Word2Vec 等词嵌入当成特征，可以迁移词汇层信息，但不直接迁移整个上下文计算过程。GPT-1 将嵌入、注意力、前馈网络和跨层表示整体作为训练好的初始化点；微调时，不是冻结所有主干只训练线性头。

GPT-1 之前已经有半监督序列学习、LSTM 语言模型预训练等研究。它的突破应具体归于：因果 Transformer 的大规模预训练、几乎不改变主干的任务输入改造、跨任务实验验证，而不是“第一个预训练模型”。原论文 §2 明确讨论了这些前史。

03 · 还原 2018 年的原始架构

论文使用 12 个 Decoder-only Transformer block，768 维隐藏状态，12 个注意力头（每头 64 维），前馈中间维 3072，训练序列长 512。将 token 嵌入与可学习位置嵌入相加，逐层经过 masked self-attention 和 FFN，再由词预测分布输出下一 token。

12blocks
768hidden
12 × 64heads × dim
3072FFN inner

数据张量从 token IDs [B,T] 转为隐藏状态 [B,T,768]，每个头的 Q/K/V 形状为 [B,T,64]。GPT-1 不是双向 BERT，也没有 Encoder–Decoder Cross-Attention；不要把 GPT-2 的 Pre-LN 修改倒灌回这一版本。依据原论文 §3.1、§4.1、Figure 1。

04 · 因果注意力究竟屏蔽什么？

对于序列位置 i，只有 j≤i 的 token 可以成为 Key/Value 来源。训练可并行求出整段序列所有位置的损失，但每个位置都无法窥视未来标签；推理时则自回归逐步产生 token。

A=softmax(QK⊤dk+M)V

每个头 Q、K 的最后一维为 dₖ=64；因果 Mask 中 j>i 的元素为 −∞，其余为 0。

上式是对论文 masked multi-head self-attention 的标准教学展开，不是额外声称原文逐字印出了这一矩阵公式。对角线保留当前位置；softmax 在允许的历史位置上归一化。

05 · 预训练数学：用密集信号学习表示

令 U=(u₁,…,uₙ) 为无标签语料中的 token 序列，k 为上下文长度；模型最大化每个 token 在此前上下文条件下的概率。与针对整句仅提供一个标签不同，它为序列中的大量位置同时产生学习信号。

L1(U)=∑i=1NlogP(ui|ui−k,…ui−1;Θ)

式 (1)。U 是 token 语料；k 为上下文窗口；Θ 为模型参数。论文最大化 L₁，优化器实现常最小化其负值。

原论文 Eq. (2) 还使用嵌入权重转置投影到词表分布，并以 Transformer block 递推隐藏层。最小化交叉熵时使用负的 log-likelihood；符号正负不应混淆。

06 · GPT-1 原论文训练配方

BooksCorpus 含超过 7,000 本未出版书籍，长段落相邻文本保留跨句上下文；它并不是 GPT-2 的 WebText。论文报告在该语料上的 token-level perplexity 为 18.4，但这一数字不可脱离语料与分词口径横向排名。

环节原论文 §4.1
序列与批大小512 tokens、batch 64
训练时长100 epochs
BPE40,000 merges（不等于恰好 40k 词表项）
优化Adam；峰值学习率 2.5×10⁻⁴
调度前 2,000 updates 线性 warm-up，之后余弦退火至 0
网络细节GELU、可学习位置嵌入、权重初始化 N(0,0.02)
正则Embedding / residual / attention dropout 0.1，另有修改的 L₂ 正则

相比简化“117M GPT”标签，这些可直接在 §4.1 找到的数字才是对训练设定最可靠的还原。

07 · 怎样将语言模型改造成分类器？

将一段任务输入送入已经预训练的 causal Transformer，抽取末尾 token 的最终隐藏向量 h_last，并增加权重矩阵 Wᵧ 的线性分类头；在 supervised 数据集 C 上最大化标签概率。除分类头和分隔 token 嵌入外，论文无需为各任务引入大量新的专属模块。

P(y|x)=softmax(hlastWy)

h_last∈ℝ⁷⁶⁸；类别数为 C 时，Wᵧ∈ℝ⁷⁶⁸×ᶜ。该符号写法是对原论文式 (3) 的简化。

作者同时采用一个辅助 LM 目标，尝试改善泛化和微调速度；在最大化记号下按正权重相加，而不是从监督损失中随意减去 LM 惩罚。

L3(C)=L2(C)+λ·L1(C)

原论文 Eq. (5) 的 λ=0.5；L₂ 是标签对数似然，L₁(C) 是在标注文本上的辅助语言模型对数似然。

常用微调设置是学习率 6.25×10⁻⁵、batch 32、多数任务 3 epochs、warm-up 0.2% 训练步数；分类头 dropout 0.1。具体任务可能有例外。来源：§3.2、§4.1。

08 · 多种任务的输入为何能共享同一网络？

Task-specific input transformations 是另一核心创新。分类用起始/结束标记包裹文本；文本蕴含按“前提 $ 假设”拼接；多项选择为每个候选答案分别构造“背景、问题、候选”序列并打分。

语义相似任务没有固定顺序，论文把 A/B 与 B/A 分别编码后逐元素相加，再用同一个分类头。不要把 2018 年这种判别式选择题流程误写成现代 Chat 模型自由生成答案。来源：§3.3、Figure 1。
